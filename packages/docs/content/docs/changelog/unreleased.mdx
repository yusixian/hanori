本候选尚未发布。定时任务新增自然语言提案与管理员确认卡、一次性和固定间隔调度、按时区的周/月/季计划、独立任务 Agent，以及聊天和面板中的管理与执行记录。

启用持久任务服务后，`set_timer` 生成待审批计划，批准后才会执行。旧定时器保留原管理入口；升级需要应用新增数据库迁移。

具体权限、月末与夏令时规则、重启恢复和失败处理见[持久定时任务指南](/docs/guides/automation#持久定时任务)。本地测试不代表真实 Telegram、数据库重启或生产功能验收已完成。
