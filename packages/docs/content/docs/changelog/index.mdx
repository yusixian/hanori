- [v0.21.1（未发布候选）：仓库发现与诊断可靠性](/docs/changelog/v0.21.1)
- [v0.21.0：插件、生图与自动化更新](/docs/changelog/v0.21.0)

v0.21.1 候选还包含图片 MCP 平台的页面配置：填写一个域名即可配置三个图片供应商，无需新增环境变量。

本候选新增通用 yt-dlp 插件，将视频元信息、章节、字幕与可选后台下载扩展至 yt-dlp 支持的站点；升级包含视频下载任务迁移，需单独安装并启用插件。字幕可按语言和来源筛选、折叠自动翻译，并直接读取推荐原轨；失效引用会提示重新查询。配置页面也补充了入门步骤和 Cookies 教程。
