## 待发布候选

- [v0.29.1（未发布候选）：生图确认修复](/docs/changelog/v0.29.1) — 修复 Telegram 生图确认后未提交的问题，补齐确认卡参数预览，GitHub 工具直接使用已授权仓库，新增 GHCR 预构建镜像部署和 Shell 初始化脚本，将图片分类改为可选、直连默认端口改为 `43100`，并移除飞书 Webhook Bot 与邮件转发。
  此版本也调整了桌面工作区间距、日志行密度和生成详情页的预览布局。

## 已发布版本

- [v0.29.0：模型重试与备用模型](/docs/changelog/v0.29.0) — 模型请求自动重试与备用模型配置，支持全局设置和群聊覆盖。
- [v0.28.1：语录父预览与布局](/docs/changelog/v0.28.1) — 修复 `/q r` 父消息恢复与长句宽度布局。
- [v0.28.0：语录贴纸与配色](/docs/changelog/v0.28.0) — 新增 `/q`、`/qcolor` 与 AI 语录工具，支持中文、Emoji、图片和长文 PNG。
- [v0.27.1：Telegram 内容接收补漏](/docs/changelog/v0.27.1) — 补齐 Story、投票、联系人、位置、清单和富文本等消息上下文。
- [v0.27.0：媒体上下文与局部引用](/docs/changelog/v0.27.0) — 保留视频、动图、音频的说明文字与转发来源，识别局部引用并隔离论坛话题上下文。
- [v0.26.1：自定义总结格式优先级](/docs/changelog/v0.26.1) — 修正群聊总结自定义格式的生效优先级。
- [v0.26.0：范围受限的总结工具与预览](/docs/changelog/v0.26.0) — 新增总结工具与不外发消息的预览模式。
- [v0.25.1：修复干净环境声明构建](/docs/changelog/v0.25.1) — 修复生产镜像构建时的类型声明竞态。
- [v0.25.0：定时任务手动运行与协议兼容](/docs/changelog/v0.25.0) — 支持手动立即运行定时任务，修复推理模型与工具接口兼容问题。
- [v0.24.0：提示词版本与回合快照](/docs/changelog/v0.24.0) — 新增提示词版本管理、快照对比与一键回滚。
- [v0.23.0：持久定时任务与管理员审批](/docs/changelog/v0.23.0) — 新增带管理员审批的持久定时任务与独立任务 Agent。
