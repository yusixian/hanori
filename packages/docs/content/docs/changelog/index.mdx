v0.28.0 新增 `/q`、`/qcolor` 与本轮原文受限的 AI 语录工具，支持中文、彩色 Emoji、图片和长文 PNG。升级需同步重建默认离线渲染服务，详见[版本说明](/docs/changelog/v0.28.0)。

v0.27.1 补齐 Story、投票、联系人、位置、清单、富文本等用户内容的聊天上下文，并为入口日志补充明确的内容类型。未解析媒体保持诚实占位，不扩大服务事件准入。

v0.27.0 保留视频、动图和音频消息的说明文字与转发来源，并识别 Telegram 局部引用。媒体占位明确标注未解析；论坛上下文按话题隔离。

v0.26.0新增聊天与定时任务总结工具，以及不发送消息的总结预览。历史覆盖按实际查询判断，达到数量上限才报告截断；采集覆盖未知不再被标成确定缺失。

v0.25.1 修复生产镜像的声明构建竞态，并将干净生产构建纳入 CI。v0.25.0 首次自动部署失败；升级应使用此修复版本。

v0.25.0 新增已批准任务的立即运行、最近执行状态与持续刷新的记录详情，修复推理模型与工具的接口兼容问题。升级需应用新增运行记录迁移。

v0.24.0 新增[提示词版本管理](/docs/guides/ai-chat#提示词版本)，支持独立草稿、内容快照、比较与启用恢复。保存不会启用，新回合使用当前版本，执行中回合保持原快照。升级需应用新增迁移。
