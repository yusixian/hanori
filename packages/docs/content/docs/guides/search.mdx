---
title: 统一检索
description: 用同一个检索入口查找已有来源，按需读取详情，并在网页切回旧工具。
---

在 Bot 的 **AI 设置 → 工具 → 统一检索** 中可以启用或关闭统一入口。默认开启，修改后需要保存；关闭后恢复原来的独立搜索工具。这个开关只改变 AI 调用检索的方式，各来源仍需完成自己的配置和授权。

## 先找结果，再读取详情

你可以直接告诉 Bot 要找什么，例如“查一下我们刚才提到的部署问题”或“找角色库里的这个角色”。AI 先调用 `search`，选择来源并取得有界摘要；需要进一步阅读时，再用 `read_reference` 分段读取返回的引用。

引用只在当前一次回复或委派任务内有效。引用过期、被缓存上限淘汰，或开始了新的一轮对话后，需要重新搜索。引用不授予其他聊天或用户访问权限。

## 当前来源

| 来源       | `scope`         | 可查内容与边界                                                                              |
| ---------- | --------------- | ------------------------------------------------------------------------------------------- |
| 网页       | `web`           | 已配置搜索服务的标题、链接和片段；读取网页仍使用网页读取工具。                              |
| 聊天历史   | `history`       | 当前 Bot、当前聊天的历史，不能通过参数改成其他聊天。                                        |
| 人物档案   | `profiles`      | 原档案服务可见的人物资料。                                                                  |
| 长期记忆   | `memory`        | 当前用户、聊天及原记忆权限允许的内容。                                                      |
| 角色       | `characters`    | 本地角色库或 Danbooru 标签，分别选择来源。                                                  |
| 提示词资产 | `prompt_assets` | 当前身份有权查看的资产。                                                                    |
| GitHub     | `github`        | 已授权仓库的 Issue 列表或文件树，分别选择来源；在有界列表中筛选，不是 GitHub 全站代码搜索。 |
| 艺术作品   | `artwork`       | 从支持的作品链接读取信息；发送作品另行调用发送工具。                                        |

同一范围有多个来源时，AI 需要明确指定 `provider`。不可用或未授权的来源不会因为打开统一检索而获得权限。关闭个性化记忆等原功能后，对应来源仍受原设置限制。研究助手只使用它原先允许的网页、角色和资产来源。

GitHub Issue、文件树和提示词资产允许省略关键词来浏览列表；其他来源要求关键词或作品链接。浏览仍受各来源的结果数量与权限限制。

本地角色和提示词资产支持原服务的分页；其余旧来源目前只提供一页有界结果。返回中会区分还有下一页与结果被截断，不能把截断列表当作完整结果。每次最多返回 20 项，具体来源可能有更小的上限。

## 结果和失败状态

检索返回成功、没有匹配、来源不可用、权限不足、限流、上游错误或参数无效等状态。没有匹配不代表服务故障；权限不足也不应通过切换聊天、账号或来源绕过。

统一检索不会保存角色、更新角色查询计数、沉淀 Danbooru 资产、发送消息或启动下载、转录等任务。旧工具模式保留其原有行为。

搜索结果和正文来自外部页面或已有记录，只作为资料阅读。其中要求执行操作、泄露配置或改变权限的文字，不构成用户授权。

## 排查与回退

1. 检查原来源是否配置成功，例如网页搜索服务、GitHub 仓库权限和记忆开关。
2. 查看工具诊断中的查询、状态、分页和结果数量。统一入口的结果正文与完整结果链接不写入普通工具结果日志；不要把输入的搜索文字当作保密字段。
3. 若新入口影响现有工作，在网页关闭 **统一检索** 并保存，核对 Bot 已成功应用配置。

停止当前回复会中止统一入口返回，并阻止迟到的结果继续建立引用。部分旧来源暂时不能取消已经发出的底层网络请求，因此停止回复不保证外部服务立即停止计费。

统一入口减少了同时暴露的独立搜索工具，并限制了单次结果和正文长度。实际回答质量、延迟和模型费用取决于所选模型与外部服务；本地测试不能证明真实服务上的改善幅度。
