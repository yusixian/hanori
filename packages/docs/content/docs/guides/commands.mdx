Bot 的 `/help` 和 Telegram 命令菜单由共享命令目录与运行时注册表动态生成，**`/help` 是当前实例可用命令的最终依据**。下表列出完整目录，部分命令会因 Bot 配置、聊天类型、角色或功能开关而隐藏。

## 基础和对话

| 命令       | 作用                                    | 常见范围   |
| ---------- | --------------------------------------- | ---------- |
| `/start`   | 显示欢迎信息                            | 公开       |
| `/help`    | 显示当前可用命令                        | 公开       |
| `/panel`   | 打开已启用的 Bot 帮助或管理面板         | 公开       |
| `/md2tg`   | 把 Markdown 转成 Telegram 富文本        | 公开       |
| `/clear`   | 清除当前聊天的对话历史                  | 按聊天类型 |
| `/privacy` | 查看/切换个人化模式，或发起个人数据删除 | 公开       |

## AI 和运行控制

| 命令                | 作用                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| `/provider`         | 查看、切换或重置当前聊天的 Provider                                  |
| `/model`            | 查看、切换或重置当前聊天的模型                                       |
| `/replymode`        | 切换回复模式                                                         |
| `/richtext`         | 切换 AI 富文本增强                                                   |
| `/stop` / `/resume` | 停止或恢复 AI 回复                                                   |
| `/quota`            | 查看 AI 与图片用量                                                   |
| `/summary`          | 总结当前聊天/话题的消息（支持条数、小时、today/yesterday）并发送结果 |

## 图片和媒体

| 命令        | 作用                         |
| ----------- | ---------------------------- |
| `/imagegen` | 切换群组图片生成权限         |
| `/image`    | 查看图片预设、查询或取消任务 |
| `/draw`     | 按预设发起生图               |

## 管理和集成

| 命令             | 作用                                | 备注               |
| ---------------- | ----------------------------------- | ------------------ |
| `/status`        | 查看 Bot 运行状态                   | 管理员             |
| `/restart`       | 重启 Bot                            | 管理员             |
| `/backup`        | 创建数据库备份                      | 管理员             |
| `/clearreceived` | 清理收到的文件缓存                  | 管理员             |
| `/timers`        | 查看或管理活跃定时器                | 管理员             |
| `/mcp`           | 查看或管理 MCP 服务器               | 管理员             |
| `/apikey`        | 在私聊中更新 Web 或图片工具 API Key | 管理员；参数会脱敏 |
| `/cosinside`     | 从管理员私聊向配置的群发送消息      | 管理员；有副作用   |

## 参数示例

```text
/provider
/provider reset
/model 1
/model reset
/summary 6h
/summary 200
/privacy status
/privacy forget
/privacy forget confirm
```

切勿把 API Key、Token 或私密内容作为参数发到群里。`/apikey` 和 `/cosinside` 仅应在私聊中使用；服务端始终会独立校验权限。

## 命令不显示时

先发 `/help`，再逐项检查：

1. 当前聊天类型是否匹配命令范围。
2. Bot 是否开启了对应功能（图片、MCP、总结等）。
3. 当前用户是否为管理员，或已被授予对应治理权限。
4. Bot 最近重启后是否完成了命令注册与配置同步。

## 语录贴纸 / Quote stickers

开启语录渲染服务后，回复一条消息发送 `/q` 即可生成静态贴纸（不调用语言模型，AI 关闭时同样可用）。选中原消息片段后回复 `/q` 可只引选段。

常用参数（可自由组合，如 `/q -3 r purple`）：

- `/q 3` / `/q -3`：从被回复消息向后或向前连引 3 条（含本条，最多 10 条），按时间正序排列。
- `/q r`：附带一层父消息预览。
- `/q light`（或 `ai`、`purple`、`dark`、`blue`、`#RRGGBB`）：仅覆盖本次配色。
- `/qcolor <配色|reset>`：保存或重置当前聊天默认配色（群内需群管理员或 Bot 管理员，私聊本人可设）。

使用边界：

- **连引与父预览**：只读取当前 Bot 在同聊天、同话题下已保存的本地消息，不抓取 Telegram 全历史；单条直接回复不依赖历史。Telegram 不递归返回父消息，若本地缺回复关系、父消息不可读或受隐私限制，会省略预览并说明原因，不靠文本猜测。
- **渲染与格式**：支持图片和静态贴纸，相邻同作者合并显示并保留各自父预览；超长内容自动改发 PNG 文件，避免字小看不清。英文 Telegram 界面会显示英文帮助和提示。
- **隐私与冲突**：受保护内容、隐私 `off` 用户以及已生成的语录贴纸不可再做语录；Spoiler 文字遮盖，剧透图片不下载，匿名转发不反查身份，无头像用彩色占位。若被引用作者正忙于其他 AI 回合或隐私操作，会直接提示稍后重试而不排队；发送结果不明时先检查聊天再决定是否重发。

**English quick reference:** Reply with `/q`; select text first for an exact excerpt. `/q 3` quotes forward and `/q -3` backward, including the replied message (1–10 local messages). Add `r` for one parent preview and a color preset or `#RRGGBB` for a one-off theme. `/qcolor <color|reset>` persists the chat default (group changes require an admin). Quotes respect privacy, protected content, and topic boundaries. Long quotes are sent as readable PNG documents. If an author is busy in another AI turn or privacy operation, the request fails promptly without sending; try again later.
