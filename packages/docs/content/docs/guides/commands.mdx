Bot 会从共享命令目录和运行时注册表生成帮助与 Telegram 命令菜单，因此 `/help` 是当前实例可用性的最终依据。下面列的是产品目录中的命令；某些命令可能因为 Bot 配置、聊天类型、角色或功能开关而隐藏。

## 基础和对话

| 命令       | 作用                                       | 常见范围   |
| ---------- | ------------------------------------------ | ---------- |
| `/start`   | 显示欢迎信息。                             | 公开       |
| `/help`    | 显示当前可用命令。                         | 公开       |
| `/panel`   | 打开已启用的 Bot 帮助或管理面板。          | 公开       |
| `/md2tg`   | 把 Markdown 转成 Telegram 富文本。         | 公开       |
| `/clear`   | 清除当前聊天的对话历史。                   | 按聊天类型 |
| `/privacy` | 查看或切换个人化模式，或发起个人数据删除。 | 公开       |

## AI 和运行控制

| 命令                | 作用                                                                      |
| ------------------- | ------------------------------------------------------------------------- |
| `/provider`         | 查看、切换或重置当前聊天的 Provider。                                     |
| `/model`            | 查看、切换或重置当前聊天的模型。                                          |
| `/replymode`        | 切换回复模式。                                                            |
| `/richtext`         | 切换 AI 富文本增强。                                                      |
| `/stop` / `/resume` | 停止或恢复 AI 回复。                                                      |
| `/quota`            | 查看 AI 与图片用量。                                                      |
| `/summary`          | 总结当前聊天/话题的可用消息，支持最近条数、小时、今天或昨天；会发送结果。 |

## 图片和媒体

| 命令        | 作用                           |
| ----------- | ------------------------------ |
| `/imagegen` | 切换群组图片生成权限。         |
| `/image`    | 查看图片预设、任务或取消任务。 |
| `/draw`     | 按图片预设发起生成。           |

## 管理和集成

| 命令             | 作用                                  | 备注                       |
| ---------------- | ------------------------------------- | -------------------------- |
| `/status`        | 查看 Bot 运行状态。                   | 管理员                     |
| `/restart`       | 重启 Bot。                            | 管理员                     |
| `/backup`        | 创建数据库备份。                      | 管理员                     |
| `/clearreceived` | 清理收到的文件缓存。                  | 管理员                     |
| `/timers`        | 查看或管理活跃定时器。                | 管理员                     |
| `/mcp`           | 查看或管理 MCP 服务器。               | 管理员                     |
| `/apikey`        | 在私聊中更新 Web 或图片工具 API Key。 | 管理员；参数会脱敏         |
| `/cosinside`     | 从管理员私聊向配置的群发送消息。      | 管理员；内容属于副作用操作 |

## 参数示例

```text
/provider
/provider reset
/model 1
/model reset
/summary 6h
/summary 200
/privacy status
/privacy forget
/privacy forget confirm
```

不要把 API Key、Token 或私密消息作为命令参数发到群里。`/apikey` 和 `/cosinside` 只应在 Bot 明确提示的私聊场景中使用；即使命令目录标记为管理员，服务端仍会再次校验权限。

## 命令不显示时

先发送 `/help`，再检查：

1. 当前聊天是否符合命令的访问范围。
2. Bot 是否启用了对应能力，例如图片、MCP 或总结。
3. 当前用户是否为管理员或被授予 Mini App/治理范围。
4. Bot 是否在最近重启后完成了注册和配置同步。

命令菜单只表达元数据和当前注册结果，不代表外部 Provider 或 Telegram API 一定可用。

## 语录贴纸 / Quote stickers

启用语录渲染服务后，回复一条消息发送 `/q` 即可制作静态贴纸；此命令不调用语言模型，AI 关闭时也可用。在 Telegram 选中原文后回复 `/q` 可只引用选段。`/q 3` 从被回复消息向后取三条，`/q -3` 向前取三条（均含被回复消息，最多十条），最后按时间顺序排列。`/q r` 加一层父消息预览；参数可组合，例如 `/q -3 r purple`。

连引只读取本 Bot 在当前聊天、当前话题可用的本地消息，不抓取 Telegram 全历史。单条直接回复不依赖历史；连引不足会明确显示实际条数。关闭历史采集、隐私限制、清理或重启前未保存的记录可能无法连引。图片与静态贴纸可加入语录，相邻同作者合并显示；长内容会作为 PNG 文件发送，避免缩成无法阅读的小字。

`/qcolor ai|purple|dark|light|blue|#RRGGBB` 保存当前聊天默认配色，`/qcolor reset` 恢复默认深色。群内持久修改限群管理员或 Bot 管理员，私聊本人可设置；普通成员仍可用 `/q light` 指定本次颜色。英文 Telegram 界面提供英文命令帮助和操作提示。

受保护内容与隐私 `off` 用户不能生成语录；引用作者的隐私设置也会再次校验。Spoiler 文字被遮盖，剧透图片不会下载；匿名转发不会反查真实身份。已生成的语录不能再次套入语录。头像不可用时使用彩色占位。引用作者的其他 AI 回合或隐私操作正忙时，会立即提示稍后重试，不排队等待；此时尚未发送语录。发送结果未知时先检查聊天，不要立即重复操作。

**English quick reference:** Reply with `/q`; use a Telegram text selection for an exact excerpt. `/q 3` quotes forward and `/q -3` backward, including the replied message (1–10 local messages). Add `r` for one parent preview and a color preset or `#RRGGBB` for a one-off theme. `/qcolor <color|reset>` persists the chat default; group changes require an administrator. Quotes respect privacy, protected content and topic boundaries. Long quotes are delivered as readable PNG documents. If an author is busy in another AI turn or privacy operation, the request fails promptly without sending; try again later.
