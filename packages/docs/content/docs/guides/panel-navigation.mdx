title: 管理面板导航
description: 按任务找到 Bot 设置、内容和全局管理入口。
---

管理面板提供全局管理和单个 Bot 工作区。进入 Bot 后，侧栏按任务分组，顶部搜索可以快速找到页面。桌面侧栏和手机顶部会显示当前 Bot 名称，切换 Bot 后随之更新。

登录页提供语言切换和公开文档入口，切换语言会保留已经输入的邮箱和密码。樱花角色插画是花织的品牌展示；实际聊天角色和回复方式由各个 Bot 的 AI 设置决定。

## 浏览与管理 Bot

Bot 列表集中显示名称、运行状态、运行时长和启停操作。输入名称可在全部 Bot 中查找，匹配总数和分页会随搜索更新；按 Enter 可立即查找，清空搜索可返回完整列表。未搜索时按创建顺序排列，使用底部分页浏览其他 Bot；总数来自服务端，不会把当前页数量当作全部 Bot 数量。点击名称进入概览，连接凭据的脱敏信息仍可在概览查看。

列表或概览加载失败时，页面会显示错误和 **重试**。若自动刷新失败，已经读取的内容会继续保留，并提示当前状态可能不是最新结果；恢复后再确认运行状态。搜索无结果时可以换一个名称或清空搜索；真正没有 Bot 时才会显示创建首个 Bot 的引导。

概览提供当前平台适用的常用入口：Telegram Bot 可进入 **AI 设置**、**对话** 和 **日志**，Lark Bot 可进入 **编辑 Bot** 和 **日志**。手机上也能直接使用这些入口，无需先打开侧栏。

AI 设置顶部保留搜索、分类和保存反馈。宽屏下可以直接切换分类；内容区域较窄时使用分类下拉框，为设置表单留出空间。高度较小的横屏窗口中，顶部工具栏会随页面滚动。手机上的眼睛图标打开提示词预览；切换分类和预览都不会提交当前草稿。

## 在 Bot 工作区找到入口

| 分组       | 常用入口                                   |
| ---------- | ------------------------------------------ |
| 常用       | 概览、AI 设置、对话                        |
| 内容与记忆 | 人物档案、记忆、生成素材库、生成记录、文件 |
| 自动化     | Skills、RSS、群聊总结                      |
| 管理与诊断 | 编辑、用量与生图、调试器、导出、日志       |

例如，修改回复方式进入 **AI 设置**；检查 Bot 为什么没有回复，进入 **调试器** 或 **日志**；复查生成图片，进入 **生成记录**。

人物档案和记忆列表加载失败时可直接重试；创建、编辑失败会保留当前输入。提交成功与刷新失败会分别提示，便于确认操作结果。具体用法见[在面板维护档案与记忆](/docs/guides/privacy-memory#在面板维护档案与记忆)。

人物档案搜索会显示全部匹配结果的真实总数，并可继续翻页。人物卡中的 **查看记忆** 会直接打开该人物的记忆范围；记忆页的范围、分类、内容搜索和页码保存在 URL 中，刷新、复制链接或使用浏览器前进/后退后仍可恢复。

## 记忆与生成素材库

**记忆** 页先显示添加入口、筛选和记忆列表，**历史完全重复记忆** 检查位于列表之后。空列表会说明如何开始；筛选没有结果时，调整条件或使用 **清除筛选** 即可返回。重复检查仍先展示预览，确认后才执行清理。

**生成素材库** 默认收起 **素材库设置**，先浏览角色和提示词资产。展开设置可调整可用类别、自动注入和 NSFW 选项；收起后再展开、切换界面语言都会保留当前输入，点击 **保存** 才提交。角色与提示词资产可用方向键切换，Home/End 跳到首尾分类。

搜索和筛选保留可见标签，长名称与操作按钮在手机上分行显示。素材列表读取失败时显示 **重试**，已有内容会保留；失败不会显示为没有素材。Danbooru 元数据仍只读，工作区角色权限不变。

## RSS 与群聊总结

第一次进入 **RSS** 或 **群聊总结** 时，页面会说明用途并提供创建入口。RSS 集合可用键盘 Enter 或空格展开，查看订阅源与设置；长名称和操作按钮会在手机上换行。

没有总结历史与 Chat ID 筛选无结果会显示不同提示，清空筛选可回到全部记录。点击 **查看** 可在弹窗中阅读总结，使用关闭按钮或 Escape 返回原记录。读取集合、总结配置或历史失败时会显示 **重试**，不会把失败显示成暂无内容。

## 查看与清理对话

在 **对话** 页输入完整 **Chat ID** 或聊天记录中的部分参与者名称，按 Enter 或点击 **搜索对话**，即可在所有会话中查找；用 **清除搜索** 返回全部会话。搜索结果按最近活动排序，选择后查看完整消息和压缩摘要。列表与详情加载失败时都有就地重试；已有内容刷新失败时会保留并标明可能过期。手机用详情左上角的返回按钮回到列表。

删除结果无法确认时，先使用 **刷新并核对**；已删除但刷新失败会单独提示。核对只重新读取数据，不自动再次删除。具体说明见[在面板查看与清理对话](/docs/guides/privacy-memory#在面板查看与清理对话)。

## 查看与清理生成记录

进入 **生成记录**，按任务 ID、Prompt、预设或 Provider 搜索，并组合状态、来源和日期筛选。读取失败可重试；已有内容刷新失败时会标明可能过期。

删除失败或删除后的读取失败都有明确状态，使用 **刷新并核对** 确认结果，避免重复提交。来源、图片保留和删除范围见[生成记录与问题恢复](/docs/guides/generation-records)。

## 搜索导航

在侧栏搜索框输入页面名称，菜单会立即显示匹配入口。处于 Bot 工作区时，结果同时包含当前 Bot 和全局管理页面，并显示所属范围。

此搜索用于定位页面，不搜索聊天正文、人物档案或日志内容。进入对应页面后，再使用页面内的搜索和筛选。

没有匹配结果时，清空搜索即可恢复菜单。

## 从 Bot 进入全局管理

展开侧栏的 **全局管理**，可以直接进入用量统计、MCP、定时任务、数据、备份等页面，无需先返回 Bot 列表。全局日志与当前 Bot 的日志入口分开显示。

点击侧栏顶部的 **返回 Bot 列表** 可以选择另一个 Bot。页面链接与访问权限保持原有规则；导航搜索不会扩大账号权限。

## 查看用量与统计范围

全局 **用量** 页先显示所选时间和 Bot 的核心指标、用量趋势与模型明细，再显示缓存诊断和年度活跃度。Bot 下拉菜单会读取全部可用分页；加载失败时可重试，不会把只有前 100 个 Bot 的列表当作完整结果。

- 顶部选择 **7 天、30 天或 90 天** 与某个 Bot，汇总、用量趋势、模型明细和缓存诊断跟随这两个条件。
- **按模型** 会完整显示模型 ID、Token 总量以及输入和输出 Token；分段条按列表中最高的输入加输出用量比较。
- **全部 Bot 对比** 始终比较全部 Bot，只跟随时间范围，方便定位用量来源；选中单个 Bot 后也会保留这个全局对比。
- **活跃度 · 最近 365 天** 固定显示最近 365 天，只跟随 Bot 选择，切换顶部天数不会改变年度视图。
- 切换条件时会重新加载相应用量，失败后显示错误和重试；不要把加载失败当成零用量。年度活跃度可单独重试。

缓存指标未上报时显示 `—`，与明确报告零不同。具体含义见 [AI 对话与模型](/docs/guides/ai-chat#缓存用量的含义)。

## 检索和清理日志

从 Bot 工作区进入 **日志** 时，只查看该 Bot；全局日志可以选择某个 Bot，或查看全部 Bot。打开全局 Bot 筛选后可按名称查找，数量超过 100 时也能直接找到后续 Bot；清空选择返回全部 Bot。若选项加载失败，可在菜单内或筛选处重试。浏览器后退、前进会同步日志的 Bot 范围。Bot 名称查找只筛选选择菜单，不搜索日志内容，也不改变清理范围。

- 输入文本搜索消息和详情，也可以按级别、群聊 ID、关联 ID 组合筛选。
- 群聊 ID 支持负数。关联 ID 用于找到同一次请求或任务的相关记录；历史列表和实时日志使用相同的筛选条件。
- 搜索与关联 ID 会忽略首尾空格，纯空白等同于未筛选。输入中文时，搜索会在完成输入后应用。
- **暂停实时更新** 可以暂时固定实时记录，方便阅读；需要继续观察时点击 **继续实时更新**。

手机上每条日志先显示级别，再用卡片宽度展示消息与时间、关联信息；点击该条记录可展开完整详情并复制 JSON。全局日志和 Bot 工作区日志使用相同的记录布局。

**清空日志** 按 Bot 范围执行，不按文本、级别、群聊 ID 或关联 ID 筛选结果删除。选择某个 Bot 后，确认框会写明 Bot 名称；未选择 Bot 时会清空全部日志。清空失败会显示错误并保留当前列表，可以检查权限或连接后重试。

分享诊断信息前请移除凭据和消息原文，详见[隐私、历史与记忆](/docs/guides/privacy-memory)。

## 小屏幕与键盘

账户菜单中的 **设置** 按 **登录与安全**、**一起使用花织** 和 **工作区** 分区。桌面使用左侧分区链接定位，手机可以横向浏览分区链接；跳转分区不会清空已经输入的表单。

所有成员都可以修改自己的密码，管理员和所有者可以管理成员与邀请，完整角色权限及成员密码重置由所有者管理。修改密码和生成邀请链接时，按钮会显示提交状态；失败会保留当前输入。浏览器不能复制到剪贴板时，页面会显示生成的链接，供手动复制。

- 桌面可以收起侧栏；需要搜索或查看完整标签时再展开。
- 手机上用顶部菜单按钮打开导航，选择页面后自动关闭；也可使用关闭按钮或 Escape。
- 侧栏底部的账户入口可打开设置、语言切换、文档、更新说明和退出登录；手机上收起这些次要操作，为页面导航留出更多空间。退出登录前，未保存的 AI 设置仍会提示确认。

首次配置 Bot 请继续阅读[快速开始](/docs/getting-started/quickstart)，模型和回复相关选项见[AI 对话与模型](/docs/guides/ai-chat)。

工作台的导航、控件和展开的 AI 设置使用统一的樱花粉配色。对话中的粉蓝和浅紫用于区分角色；成功、警告和错误仍保留各自的提示颜色。桌面与手机使用同一套控件，手机输入框也保留易读的字号。
