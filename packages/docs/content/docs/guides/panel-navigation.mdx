title: 管理面板导航
description: 快速定位 Bot 设置、内容管理、日志诊断与全局管理入口。

管理面板分为**全局管理**和**单个 Bot 工作区**。进入 Bot 后，侧栏按任务分组，桌面侧栏和手机顶部都会显示当前 Bot 名称。

登录页支持切换语言和跳转公开文档，切换语言不会清空已输入的邮箱和密码。页面上的樱花角色插画仅作花织品牌视觉，实际聊天人设和风格由各 Bot 的 AI 设置决定。

## 浏览与管理 Bot

Bot 列表显示名称、运行状态、运行时长和启停开关。

- **查找与翻页**：输入名称可在全部 Bot 中搜索，按 Enter 立即查询，清空搜索恢复完整列表。未搜索时按创建时间排序，总数为服务端真实数量，不局限于当前页。点击名称进入概览，脱敏后的连接凭据也可在概览查看。
- **异常与空态**：列表或概览加载失败会提示错误和**重试**；自动刷新失败时保留已加载内容并提示可能过期。只有在确实没有任何 Bot 时才显示创建引导，搜索无结果会单独提示。
- **概览快捷入口**：概览页直接提供 **AI 设置**、**对话** 和 **日志** 入口，手机端无需先展开侧栏。
- **AI 设置工具栏**：顶部固定搜索、分类切换和保存反馈（窄屏折叠为下拉框，矮横屏随页面滚动）。手机端点击眼睛图标可预览提示词；切换分类和预览都不会提交草稿。

## 在 Bot 工作区找到入口

| 分组       | 常用入口                                   |
| ---------- | ------------------------------------------ |
| 常用       | 概览、AI 设置、对话                        |
| 内容与记忆 | 人物档案、记忆、生成素材库、生成记录、文件 |
| 自动化     | Skills、RSS、群聊总结                      |
| 管理与诊断 | 编辑、用量与生图、调试器、导出、日志       |

调回复风格去 **AI 设置**，查不回复原因去 **调试器** 或 **日志**，看历史生图去 **生成记录**。

人物档案搜索显示服务端真实总数并支持翻页；点击人物卡中的 **查看记忆** 会直接带入该人物范围。记忆页的范围、分类、关键词和页码同步到 URL，刷新或前进/后退可恢复。详细操作见[在面板维护档案与记忆](/docs/guides/privacy-memory#在面板维护档案与记忆)。

## 下载 Bot 文件

在 **内容与记忆 → 文件** 中可下载单文件，或将目录打包为 ZIP：

- 支持中文、空格及 `%`、`#`、`?` 等字符的文件名；目录打包按所选目录命名（嵌套路径分隔符转为下划线），仅包含受支持的文件类型。取消下载会立即释放文件句柄；打包途中读文件失败会中断下载。
- 读取目录时会跳过并发消失的条目。单文件预览、下载和 AI 读取上限均为 **20 MiB**，读取途中文件超限会直接拒绝，不返回截断内容。
- 标记为可注入的 Markdown 文件会进入 Bot 系统提示词。单文件读取失败不影响其余可读文件按原优先级和总大小限制加载，不完整结果不会写入缓存；提示词预览始终实时读盘。
- 初始化模板只创建缺失文件，不覆盖已有文件或符号链接。
- 单删、批删及 AI 删除工具都会按真实路径校验并保护注入列表中的文件（`./`、`..` 等路径变形无法绕过）；如需删除，请先移出注入列表。AI 删除工具删完目标文件即返回成功，附带的空父目录清理失败时不会影响结果。

## 记忆与生成素材库

- **记忆**：顶部为添加、筛选和列表，**历史完全重复记忆** 检查在列表下方（先预览，确认后再清理）。筛选无结果时可用 **清除筛选** 恢复。
- **生成素材库**：默认收起 **素材库设置**，优先展示角色与提示词资产。展开可调可用类别、自动注入和 NSFW 选项；收起或切换语言保留草稿，点 **保存** 才提交。资产列表支持方向键和 Home/End 切换。Danbooru 元数据只读。加载失败时保留已有内容并显示 **重试**。

## RSS 与群聊总结

首次进入 **RSS** 或 **群聊总结** 会展示用途说明和创建入口。RSS 集合支持键盘 Enter/空格展开；总结记录区分“暂无历史”与“Chat ID 筛选无结果”，点击 **查看** 弹窗阅读（按 Escape 或关闭按钮返回）。加载失败均显示 **重试**，不误报为空态。

## 查看与清理对话

在 **对话** 页输入完整 **Chat ID** 或参与者名称片段，按 Enter 或点 **搜索对话** 即可检索全部会话；点 **清除搜索** 返回全部列表。结果按最近活动排序，选中后可看完整消息和压缩摘要，手机端用左上角返回按钮回到列表。

加载失败支持就地重试，刷新失败保留已有内容并标记可能过期。删除结果不确定时点 **刷新并核对**（仅重读数据，不重发删除）；已删除但刷新失败会单独提示。详见[在面板查看与清理对话](/docs/guides/privacy-memory#在面板查看与清理对话)。

## 查看运行事件

**调试器** 通过实时连接展示 Bot Run 事件。关闭页面、切换详情或认证前断开都会立即停止后续推送。任务取消与完成并发发生时，保留已写入的完成状态和原因；已完成或已删除的运行不再返回取消成功。

后台事件或终态写入失败时只记录脱敏错误，不重发模型请求。若数据库故障导致运行停留在“运行中”，服务重启后的恢复流程会将其标为已中断。

## 查看与清理生成记录

在 **生成记录** 中可按任务 ID、Prompt、预设或 Provider 搜索，并组合状态、来源和日期筛选。读取或删除异常时用 **刷新并核对** 确认服务端状态，避免重复提交。详见[生成记录与问题恢复](/docs/guides/generation-records)。

## 搜索导航

侧栏顶部的搜索框用于快速定位页面（不搜索聊天正文、档案或日志内容）。在 Bot 工作区内搜索时，结果会同时列出当前 Bot 页面和全局管理页面，并标明归属。清空输入即恢复完整菜单。

## 从 Bot 进入全局管理

展开侧栏的 **全局管理**，可直接跳转用量统计、MCP、定时任务、数据、备份等全局页面，无需先回 Bot 列表；全局日志与当前 Bot 日志入口分开。点侧栏顶部的 **返回 Bot 列表** 可切换其他 Bot。导航搜索不会越权展示或打开无权限页面。

## 查看用量与统计范围

全局 **用量** 页依次展示核心指标、用量趋势、模型明细、缓存诊断和年度活跃度。Bot 下拉框会拉取全部可用分页（超过 100 个也能完整加载），失败可重试。

- 顶部选 **7 天、30 天或 90 天** 和某个 Bot 时，汇总、趋势、模型明细和缓存诊断同步更新。
- **按模型** 显示完整模型 ID、总 Token 及输入/输出分布，进度条按列表中最高总量归一化。
- **全部 Bot 对比** 始终对比全部 Bot，只跟随时间范围，选中单个 Bot 时也会保留。
- **活跃度 · 最近 365 天** 固定展示近 365 天，只跟随 Bot 选择，不受顶部天数影响，支持单独重试。
- 加载失败会提示错误并支持重试，不会误显示为零用量。缓存未上报时显示 `—`（区别于 `0`），详见[AI 对话与模型](/docs/guides/ai-chat#缓存用量的含义)。

## 检索和清理日志

Bot 工作区内的 **日志** 仅限当前 Bot；全局日志可筛选单个 Bot（支持按名称搜索，超过 100 个同样可用）或查看全部，并与浏览器前进/后退同步。

- 支持文本搜索（匹配消息和详情）以及级别、群聊 ID（支持负数）、关联 ID 组合筛选，历史与实时日志共用同一套条件。
- 搜索词与关联 ID 自动忽略首尾空格，中文输入法组合完成后生效。
- 点击 **暂停实时更新** 可冻结列表方便阅读，点击 **继续实时更新** 恢复；连接断开后服务端立即停止推送。
- 手机端以卡片形式展示级别、消息、时间和关联信息，点击可展开完整详情并复制 JSON。

**清空日志** 按 Bot 范围执行，不受文本、级别、群聊 ID 或关联 ID 筛选影响：选中单个 Bot 只清该 Bot，未选则清空全部。诊断日志中的错误名称、消息及全局未捕获异常均会做凭据脱敏和长度截断，二进制数据仅记录类型与字节数。外发日志前请按[隐私、历史与记忆](/docs/guides/privacy-memory)再次核对。

## 小屏幕与键盘

- **桌面端**：可收起侧栏以腾出内容空间。
- **手机端**：用顶部菜单按钮开关导航（选页后自动收起，也支持 Escape 关闭）；账户菜单收纳了设置、语言切换、文档、更新说明和退出登录，退出前如有未保存的 AI 设置会弹出确认。
- **账户设置**：按 **登录与安全**、**一起使用花织**、**工作区** 分区（手机端横向切换，不丢表单输入）。所有成员可改自己密码，管理员和所有者可管成员与邀请，完整角色权限和重置成员密码仅限所有者。剪贴板不可用时会直接展示邀请链接供手动复制。
- **配色约定**：导航、控件和 AI 设置采用统一樱花粉主题，对话中的粉蓝与浅紫用于区分角色，状态提示保留语义色。

首次配置 Bot 见[快速开始](/docs/getting-started/quickstart)，模型与回复设置见[AI 对话与模型](/docs/guides/ai-chat)。
