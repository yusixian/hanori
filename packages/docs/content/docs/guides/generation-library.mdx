角色库记录“画谁”，提示词资产库记录“怎么画”。把原创角色「小葵」和「柔和水彩」画风分别存好后，以后生图直接引用即可，不必每次重写。

## 入口与前提

在管理面板选中目标 Bot，进入「生成素材库」。上方是「素材库设置」，下方分「角色」和「提示词资产」两页。素材按 Bot 隔离，不跨 Bot 共享。

整理素材不要求先配置生图，但实际生图还需配好图片 Provider、路由和权限，见[图片、贴纸与媒体](/docs/guides/media)。

## 权限与开关

后台 owner/admin 可读写素材库，editor 仅可查看。Telegram 中，普通用户在权限和隐私允许时可管理自己的原创角色和绑定；共享提示词资产由 Bot 管理员维护。

| 设置           | 默认状态 | 用途                                         |
| -------------- | -------- | -------------------------------------------- |
| 启用角色       | 开启     | 允许检索、选择角色，并沉淀 Danbooru 查询结果 |
| 启用提示词资产 | 开启     | 允许检索和选择提示词资产                     |
| 自动注入       | 关闭     | 自动加入符合条件的置顶资产                   |
| 允许 NSFW 资产 | 关闭     | 允许在本次明确使用 NSFW 模式时选用对应资产   |

改完开关记得点「保存」。**关闭自动注入只停止自动加入置顶资产**，手动点名仍可用；想本次完全不用素材库，需明确要求跳过。

## 第一步：保存一个角色

### 保存原创角色

1. 在「角色」页点击「添加原创角色」。
2. 填写必填项「名称」和「外观」，按需补充别名（英文逗号分隔）、默认服装、所属作品和备注。
3. 如需归属某位群友，在「绑定群友档案」选择已有档案（留空为管理员维护）。注意这里只定归属，**不会自动设为该群友的默认代表形象**。
4. 点击「保存」。

参考示例：

| 字段     | 示例                                 |
| -------- | ------------------------------------ |
| 名称     | 小葵                                 |
| 别名     | Aoi, 葵                              |
| 外观     | 黑色短发，绿色眼睛，左侧有向日葵发夹 |
| 默认服装 | 白色衬衫，深蓝色背带裙               |
| 备注     | 发夹是固定特征，服装可随场景变化     |

也可以在 Telegram 里直接让 Bot 保存（需开启 AI 与对应工具）：

```text
请记住我的原创角色“小葵”：黑色短发、绿色眼睛，左侧有向日葵发夹。
默认穿白色衬衫和深蓝色背带裙。请保存到角色库。
```

普通闲聊提到角色不会自动建档，同名角色也不会自动合并；更新时先让 Bot 查出目标记录再修改。角色库目前只存文字设定，不存参考图——外观写稳定特征，临时服装和场景留到生图时再说。

### 从缓存头像整理外貌

开启人物档案记忆且回复模型支持视觉输入时，可让 AI 分析当前 Bot 已缓存的头像：

```text
反推一下柠柠的头像，整理成纯英文自然语言外貌提示词。
```

AI 会先确认人物与 Telegram ID，再调用 `get_profile_avatar` 读取缓存图（单次最多 3 个；同名先确认，不靠 `hasAvatar` 盲猜，也不会临时去 Telegram 拉图）。

档案和缓存按 Bot 隔离，不限于当前聊天。请求者关闭个人化时不可用；目标用户为 `normal` 时可读，`isolated` 仅本人可读，`off` 拒绝读取，详见[隐私、历史与记忆](/docs/guides/privacy-memory)。

头像图仅用于本次请求，日志和历史只记状态，不存图片二进制或链接。缓存版本未必是刚换的新头像：正常观察用户时默认每 24 小时检查一次，刷新失败后 5 分钟可重试，档案重建后立即刷新；后台下载上限 5 MB，超限保留旧图。

| 读取状态            | 含义与处理                                               |
| ------------------- | -------------------------------------------------------- |
| `not_found`         | 当前 Bot 无此档案，先核对人物和 ID                       |
| `no_avatar`         | 暂无缓存头像，请用户直接发图                             |
| `cache_unavailable` | 缓存文件缺失、无效或不可安全读取，请发图或等下次正常刷新 |
| `forbidden`         | 隐私设置禁止读取                                         |
| `unavailable`       | 临时读取失败，稍后重试                                   |

**分析头像与保存角色是两步。** 如需入库需另行要求；读取他人头像不会授予角色或绑定的编辑权。

### 沉淀 Danbooru 角色

在 Telegram 让 Bot 查询角色标签，例如：

```text
帮我查找初音未来的 Danbooru 角色标签，并列出候选供我确认。
```

开启角色功能时，查询工具返回的结果会自动按规范 tag 入库，可在「角色」页按来源筛选「Danbooru」查看（只在消息里提角色名不会触发入库）。上游 tag、别名和元数据只读，管理员可补充本地外观、默认服装或备注。来源缓存有效期 12 小时；列表中的查询次数统计的是工具返回次数（含缓存命中），不是生图次数。

## 第二步：设置自己的代表形象

想以后说“画一下我”就自动用小葵，需要建立人物与角色的默认绑定。

Telegram 方式：

```text
请查找刚保存的“小葵”，将她绑定为我的代表形象，并设为默认。
```

面板方式：进入 Bot 的「人物档案」→ 找到目标群友 → 点「管理角色绑定」→ 搜索角色 → 关系选「代表形象」并勾选「设为默认代表形象」→「添加」，确认列表出现「默认」标记。

一人可绑多个角色，但默认代表形象最多一个；「喜爱角色」不会用于代表本人。普通用户只能改自己的绑定，绑定他人维护的角色不会获得该角色的编辑权。

## 第三步：保存一项画风资产

1. 切到「提示词资产」→「添加提示词资产」。
2. 填名称（如「柔和水彩」），选类型（画风、画师串、服装、特征、构图）。
3. 在「提示词内容」填入 `soft watercolor, delicate brush strokes, warm daylight`（真正参与生图的是这里，备注不参与生成）。
4. 「安全分类」必选 `Safe` 或 `NSFW`，先不勾选「置顶」，保存。

Bot 管理员也可在 Telegram 直接要求保存：

```text
请保存提示词资产“柔和水彩”，类型为画风，分类为 safe，
内容是 soft watercolor, delicate brush strokes, warm daylight。暂时不要置顶。
```

普通群友不能修改共享提示词资产或全 Bot 默认画风。

## 第四步：在生图中使用

- **明确指定**：`用角色库中的“小葵”和提示词资产“柔和水彩”，画她坐在窗边读书。`
- **用默认代表形象**：`用我的默认代表形象画一下我，使用“柔和水彩”，背景是清晨的花园。`
- **临时换装**：`画角色库里的“小葵”，这次穿黄色雨衣，不使用角色保存的默认服装。保留原本的发夹和外貌，背景是雨后的街道。`

单次请求的服装或场景不会改写角色档案；显式指定的角色优先于默认代表形象。任务提交后去[生成记录与问题恢复](/docs/guides/generation-records)确认最终状态和排错。

## 让置顶资产自动使用

1. 编辑已验证的资产，勾选「置顶」并保存。
2. 在「素材库设置」同时开启「启用提示词资产」和「自动注入」并保存。
3. 在测试聊天试画一次确认效果。

置顶是全 Bot 共享的默认项，显式选择与置顶命中同一资产时只注入一次。需要临时覆盖时可直接说明：

- **不用置顶**：“这次不要使用任何置顶资产，只用我明确指定的素材。”
- **排除单项**：“这次不要自动加入置顶的‘柔和水彩’。”
- **完全跳过**：“这次跳过整个素材库，只按我这段提示词生成。”（同时跳过角色与显式资产）
- **关闭自动注入**：在「素材库设置」关掉并保存，已有素材和历史不受影响。

NSFW 资产必须同时满足“管理员开启允许 NSFW 资产”且“本次明确用 NSFW 模式”；仅置顶不会绕过校验，Safe 请求也不会自动带入 NSFW 资产。

## 查看次数、编辑与删除

资产的成功使用次数按成功保存产物的任务计（每任务每资产 +1，多图不重复加，失败/取消/重试投递不计）。

生成任务会保存当时的素材快照，后续编辑或删除不影响旧任务。删角色会解除所有关联的人物绑定（确认框会提示数量）；仅移绑定不删角色。导出绑定时需一并导出关联的人物档案与角色，导入时会自动重分配 ID 并转换关联，缺依赖则报错回滚。

### Telegram 保存资产失败时

新建资产时 `save_prompt_asset` 的 `id` 可省略或传 `null`；更新须先检索确认已有 `id`。省略备注或置顶时默认为空和不置顶。若遇到存储异常、写入结果未知，先按名称检索核对后再决定是否重试，避免重复创建；具体原因可在脱敏运行日志中查看。

## 常见问题

| 现象                           | 检查与处理                                                                 |
| ------------------------------ | -------------------------------------------------------------------------- |
| 看得到记录但没有编辑/保存按钮  | 确认后台账号为 owner/admin；普通成员通过 Telegram 管理自己的原创角色与绑定 |
| 查过角色但列表找不到           | 确认同一个 Bot、已启用角色、确实调用了查询工具；清空筛选刷新               |
| 建角色时找不到群友档案         | 面板仅列出已有档案；可先由本人在 Telegram 明确保存角色和绑定               |
| “画一下我”找不到形象           | 检查是否设了默认「代表形象」；「喜爱角色」和角色归属不替代默认绑定         |
| 置顶画风未自动生效             | 确认「启用提示词资产」和「自动注入」均已保存；检查分类及本次是否跳过/排除  |
| 提示素材不可用或不存在         | 检查是否已删除、属其他 Bot 或受隐私限制，重新检索确认                      |
| 提示词过长或素材过多           | 精简素材和置顶项；超限会直接报错，不会静默截断                             |
| 素材库暂时不可用               | 修复后重试，或明确要求本次完全跳过素材库                                   |
| 成功使用次数与收到图片数对不上 | 次数按成功保存产物的任务计，与多图数量和 Telegram 投递口径不同             |
