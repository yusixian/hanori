Hanori · 花织是一个自托管的 Telegram AI 伙伴，既能在私聊和群聊里自然对话、记住上下文、调用外部工具和画图，也带有一套 Web 管理面板和 Telegram Mini App，方便管理多个 Bot、模型、权限与自动化任务。

## 快速入口

- [快速开始](/docs/getting-started/quickstart)：登录面板、连上第一个 Bot 并发消息测试。
- [开始使用](/docs/getting-started)：了解 Bot、聊天、用户与面板的基本概念。
- [AI 对话与模型](/docs/guides/ai-chat)：配置 Provider、模型、系统提示词和备用模型。
- [群聊行为与参与控制](/docs/guides/group-behavior)：调整群里怎么触发、怎么接话、怎么限流。
- [角色与提示词资产库](/docs/guides/generation-library)：维护角色卡、绑定形象与复用画风。
- [自托管总览](/docs/self-hosting)：用 Docker 部署自己的实例。

## 主要功能

- **对话与记忆**：按聊天切换模型和 Provider；在授权范围内检索历史、维护人物档案与长期记忆。群成员可随时用 `/privacy` 调整个人化设置或申请清除个人数据。
- **工具与媒体**：支持网页检索、RSS、图片与贴纸生成、语录贴纸、媒体理解，以及 MCP 服务器、插件和 GitHub / 编码任务集成。
- **管理面板与自动化**：集中管理多个 Bot 的启停、模型、用量、日志、备份，以及 RSS 订阅、群聊总结和定时任务。
- **Telegram Mini App**：在 Telegram 内直接打开轻量管理页，基于 WebView 签名校验身份与群组权限。

## 几点提醒

- Token、API Key、OAuth 密钥和加密密钥只填在环境变量或面板凭据栏里，不要贴进群聊、截图或公开 Issue。
- 群聊是共享空间：关闭个人化不会撤回已经发出的群消息或已发布的群总结。
- 有外部副作用的工具（代发消息、生图、改配置、GitHub 写入等）默认受权限和用量策略约束，启用前建议先确认范围。
