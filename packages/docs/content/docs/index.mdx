Hanori · 花织是一个以 Telegram 为主要入口的自托管 AI 伙伴：聊聊日常、留下记忆，也一起把灵感画出来。它可以在私聊和群聊中对话、在授权范围内读取上下文和调用工具，并通过工作台配置 Bot、模型、用量和自动化任务。

这份文档面向已经在使用某个实例的成员，以及准备为自己部署实例的管理员。使用已有实例时，从快速开始入手；自托管时，取得维护者提供的发行源码，按部署指南准备独立的数据库和配置，再逐步启用需要的能力。

## 这个实例能做什么

### 对话和记忆

Bot 可在 Telegram 私聊或群聊中回复消息，使用按聊天选择的 AI Provider 和模型。它可以在得到授权的范围内搜索历史、维护人物档案和长期记忆；个人可以用 `/privacy` 查看或调整个人化范围，必要时请求删除可直接归属于自己的数据。

### 工具和媒体

根据管理员配置，Bot 可以访问网页、RSS、图片生成、艺术作品检索、Telegram 操作、MCP 服务器或 GitHub 工具。图片任务会记录状态和回执；贴纸、图片和部分视频媒体也可以进入理解流程。每个工具仍受 Bot、聊天、用户和用量策略约束。

### 管理和自动化

管理面板提供 Bot 生命周期、AI 选择、治理策略、对话和记忆查看、日志、备份、RSS 集合、群聊总结、定时器、MCP 服务器以及数据导出等入口。Telegram 命令和面板是同一个配置面的两种入口，具体可用项以当前实例的权限和 `/help` 为准。

### Telegram Mini App

启用后，Bot 可以从 Telegram 打开一个轻量管理界面。Mini App 使用 Telegram WebView 的签名初始化数据建立会话，再根据管理员、操作员或查看者角色授予群组范围。直接把 Mini App URL 粘到普通浏览器中，不能证明真实 Telegram 登录流程可用。

## 重要的安全边界

- Token、API Key、OAuth 密钥和加密密钥只应写入实例的受保护配置或面板凭据字段，不要放进聊天、截图或公开文档。
- 群聊是共享空间。关闭个人化不会从群历史或已经发布的群总结中撤回消息。
- 管理员工具可能产生外部副作用，例如发送消息、创建图片任务或修改 Bot 设置；先查看权限和用量策略，再启用它们。
- GitHub 和编码任务是可选能力。GitHub 安装授权限定仓库范围，隔离 worker 不应持有 GitHub 写入凭据。
