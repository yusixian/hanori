Hanori 有两个主要入口：

- **Telegram Bot**：日常私聊、群聊互动和快捷命令。
- **Web 管理面板**：配置 Bot、模型、权限、自动化任务，以及查看日志和备份。

## 使用前准备

**如果你使用别人维护的实例：**

1. 拿到面板地址和登录账号（或加入已有 Bot 的 Telegram 群）。
2. 确认 Bot 已入群且具备读取、发送消息的权限。
3. 确认管理员已经配好至少一个可用的 AI Provider 与模型；没配 Provider 时，`/help` 等基础命令仍可用，但无法进行 AI 对话。

**如果你要自己部署：**

需要 PostgreSQL、一组固定的认证与加密密钥，以及 Telegram Bot Token。直接从 [自托管总览](/docs/self-hosting) 开始即可。

## 核心概念

| 概念     | 说明                                                               |
| -------- | ------------------------------------------------------------------ |
| Bot      | 单个 Telegram Bot 实例，独立配置 Token、状态、AI 参数和可用工具。  |
| Chat     | 私聊、群组或超级群组；模型、回复策略和总结配置均可按聊天单独覆盖。 |
| 用户     | 按 Telegram ID 区分的成员，拥有独立的个人化模式、档案和长期记忆。  |
| 面板成员 | 登录 Web 面板的账号，按工作区角色分配管理权限。                    |
| 自动化   | RSS 订阅集合、群聊总结任务以及定时提醒/执行任务的统一管理单元。    |
