---
title: 快速开始
description: 几分钟完成首次登录、Bot 配置和 Telegram 连通性测试。
---

本页假设实例已经部署好且你有面板权限。如果要从零搭建，请先看 [自托管总览](/docs/self-hosting)。

## 1. 登录面板

打开面板地址，用邮箱和初始密码登录。建议第一时间去「设置」修改密码，并确认账号在正确的工作区下。

部署者使用 owner 账号登录后，Bot 列表首页会显示「首次部署引导」。修改初始密码并从 `.env` 删除 `PANEL_PASSWORD` 后，勾选「我已完成」。清单会自动检查是否有 Bot 为当前 Provider 保存了 API 密钥，以及是否有 Bot 已启用或正在运行。可随时折叠清单；关闭引导后，同一浏览器将记住你的选择。

如果启用了 Google 登录，需同时满足 Google OAuth 后台的允许范围和当前工作区的邀请状态。

## 2. 新建或检查 Bot

在 Bot 列表中点开已有 Bot 或新建一个，确认几项基本配置：

- Telegram Bot Token 完整无误（注意不要把 Token 截图发到公开场合）；
- Bot 已处于启用状态；
- 已选好默认 AI Provider 与模型。

图片生成、RSS、群聊总结、MCP、Mini App 等功能都可以等基础对话跑通后再逐项打开。

## 3. 检查模型并测试切换

在 Bot 的 AI 设置里选好 Provider 与模型并保存。随后在 Telegram 里发送：

```text
/provider
/model
```

这两个命令会列出当前聊天的模型选择和可切换项，支持按编号或名称切换，也支持 `reset` 恢复默认。能否在聊天里修改取决于管理员的访问策略。

## 4. 私聊验证

在 Bot 私聊中依次发送 `/start`、`/help`，再随便发一条普通消息。如果没有回复，按顺序排查：

1. 面板里确认 Bot 处于运行状态且 AI 已开启；
2. 管理员发 `/status` 或直接看面板日志；
3. 检查当前聊天是不是覆盖了一个不可用的 Provider 或模型；
4. 刚改过配置的话，稍等 Bot 重载后再试。

## 5. 群聊验证

把 Bot 拉进测试群后，先只用 `@Bot` 或直接回复它的消息来验证收发是否正常。确认没问题再开随机接话、触发词、群总结或 JEV，避免一进群就刷屏。细节见 [群聊行为与参与控制](/docs/guides/group-behavior)。
