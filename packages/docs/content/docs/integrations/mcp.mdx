---
title: MCP 服务器
description: 添加和管理 Model Context Protocol 服务器，了解凭据与工具边界。
---

MCP（Model Context Protocol）服务器为 Bot 接入外部工具或资源。Hanori 在服务端统一管理连接，按 Bot、聊天、用户和管理员身份组装工具；浏览器不直接持有 MCP 凭据。

## 添加服务器

在面板的 **MCP Servers** 页面填写：

- 显示名称和远端连接地址；
- 传输方式与授权信息；
- 启用状态及允许使用的 Bot；
- 工具或资源过滤策略（可选）。

保存后先点测试/连接确认能拉取能力列表。服务器已配置不代表所有聊天都能看到全部工具。

通过 Bot 的 MCP 管理工具启用或移除服务器后，运行中的实例会在最后一次修改约 2 秒后合并重启以应用变更。手动停止或重启会取消待执行的延迟重启；服务关停会等待已开始的延迟重建完成。

## 凭据和权限

凭据由服务端加密保存，切勿将 OAuth 令牌或 API Key 写入系统提示词、RSS、Telegram 消息或文档。仅具备集成管理权限的角色可查看状态或修改配置。

带凭据的工具默认只对管理员或显式授权的聊天开放；涉及写入、发送、删除、建任务或访问私有数据的工具具有外部副作用，权限校验必须在服务端执行。

## Telegram 链接读取

需要通过用户账号读取 Telegram 频道或消息链接时，见 [Telegram 链接读取](/docs/integrations/telegram-reader)。该集成依赖独立 Reader 的 OAuth 流程，不能直接把 URL 填进通用 MCP Servers 启用。

## 图片 MCP

图片生成对接专用的图片 MCP 平台，通常仅允许 owner 发起 OAuth 授权，其他管理员可查看和使用已连接状态。OAuth 回调地址须与 `BETTER_AUTH_URL` 的公开 origin 一致。

### 配置平台地址

部署好 MCP Platform 后，以 owner 身份打开任意 Bot 的 **用量与生图治理 → 图片 MCP 平台**，填写平台域名（如 `mcp.example.com` 或 `https://mcp.example.com`）并点击 **保存平台地址**。无需改环境变量或重启。

- 地址存入数据库并由所有 Bot 共享，系统自动走 HTTPS 并分别连接 `/mcp/pixai`、`/mcp/openai-image`、`/mcp/gemini-image`。
- 只填域名，不要附带路径、凭据、查询参数或 `#` 片段。清空保存会关闭三个图片 MCP 连接，不影响通用 MCP 服务器。
- 在 MCP Platform 配好供应商凭据后，回到 Hanori 三个连接卡片分别完成 OAuth 授权（Hanori 不需要 Platform 的主密钥、数据库或供应商 API Key）。回调路径均在 `BETTER_AUTH_URL` 下：
  - PixAI：`/api/image-mcp/oauth/callback`
  - GPT：`/api/image-mcp-openai/oauth/callback`
  - Gemini：`/api/image-mcp-gemini/oauth/callback`

### 兼容、更换与断开

- 旧部署在首次保存页面地址前继续读取 `PIXAI_MCP_URL`、`OPENAI_IMAGE_MCP_URL`、`GEMINI_IMAGE_MCP_URL`。一旦在页面保存，三个连接统一改用页面地址（清空不会回退到旧环境变量）；完整接口地址未变的连接会保留原授权。
- 更换地址前先等已有生图任务完成。凭据绑定完整 MCP 地址，更换会清除受影响连接的旧授权；从固定地址旧版升级时，需显式填写原地址并由 owner 重新授权。
- 断开或重授权后，旧回调与刷新令牌立即失效，不会覆盖新状态；已提交到远端的生图任务不会自动撤销。
- owner 授权期间，已有任务的后台查询可能短暂提示未连接，授权成功后自动恢复。
- 连好图片 MCP 后，仍需按[图片、贴纸与媒体](/docs/guides/media)配置路由、用量和内容安全检查，并在测试聊天验证。

### GPT / Gemini 的动态生图参数

在 MCP Platform 为 GPT、Gemini 配置供应商连接（协议、Base URL、API key、默认模型）并在 Hanori 授权后，即可不建预设直接使用：

- `create_image` 的可选 `parameters` 中，GPT 支持 `model`、`size`、`quality`；Gemini 支持 `model`、`size`、`aspectRatio`、`imageSize`，省略项用平台默认值（AI 可从路由 `backendCapabilities` 读取默认值和说明，实际支持范围以供应商为准）。预设仍可作为快捷配置，显式覆盖遵循平台审批策略；PixAI 沿用原有预设流程。
- 两个用途可分别设默认供应商（动漫默认 PixAI）。用户明确要求 GPT 或 Gemini 时仅本次生效，失败不自动切供应商；默认 preset key 留空即使用连接默认值。

## 重连、取消与结果核对

以下规则适用于通用 MCP 服务器：

- **自动重连**：首次失败后最多重试 10 次，退避时间从 1 秒指数增长至上限 5 分钟；每次握手与工具发现合计上限 30 秒，成功后清零计数。重试耗尽后需修复远端并在面板手动重连。停用、删除或关停会取消计划中的重连，旧连接的晚到结果不会覆盖新连接。
- **取消与超时**：停止回复或停止 Bot 时会向执行中的 MCP 请求发送取消信号；单次调用上限 10 分钟，取消不影响共用连接的其他请求。**取消不等于撤销**，远端可能已完成写入或忽略取消。
- **状态分类**：发送前取消为 `cancelled`；未连接或远端明确报错为 `failed`（保留脱敏并截断后的诊断文本）；已发送但因断线、取消或超时未获确定回执为 `unknown`（结果待核对）。诊断信息带请求 ID 和工具调用 ID。
- **写操作防重**：同一轮对话内，出现 `unknown` 写操作后会阻止该 MCP 服务后续的自动写入（含模型换参数重试）；带 `readOnlyHint` 的只读查询仍可用于核对。遇到超时请先到远端核对，再由用户明确重发，切勿让模型自动补发。目前不提供远端撤销、跨进程去重或自动对账。

## 排错

1. **连接失败**：检查 URL、TLS、网络出口和服务端日志，不必先重填密钥。
2. **能连但无工具**：核对服务器能力列表、工具过滤规则和当前聊天权限。
3. **调用超时**：检查远端可用性、请求上限和重试策略。
4. **返回泄露秘密**：立即在公开群停用该工具，检查服务器返回与日志脱敏后再决定是否恢复。
