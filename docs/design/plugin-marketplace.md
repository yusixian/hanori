## 目标

第三方开发者通过插件声明与实现扩展 Hanori。管理者在网页浏览、安装、启停、配置和检查插件；网易云音乐、B 站作为首批插件验证开发流程。插件的 Cookie、Token、API Key 在服务端加密存储，公开接口只返回是否已配置。

`search` 汇总经过权限绑定的检索 provider，并通过当前调用上下文中的引用按需读取详情。下载、转录、发送、写入不由检索隐式触发。旧工具保留兼容路径，便于逐步迁移和回退。

## 分层与接口方向

1. **插件声明**：版本化 manifest、插件 ID、名称/版本/作者、配置字段、提供的检索能力与动作。配置声明生成网页表单，服务端使用同一规则校验。
2. **安装记录**：实例级保存来源与不可变版本；按 Bot 启用及保存配置。安装、启用、配置保存、运行状态分别展示。
3. **运行管理**：检查版本、拒绝工具名称冲突、按 Bot/actor 分配执行上下文，统一取消与停用清理。插件错误不能被报告成成功。
4. **检索**：`SearchProvider` 接受有界查询与 AbortSignal；返回摘要、来源、结构化字段与可分页正文。可见 provider 随权限决定；无任意工具名调度。
5. **媒体任务**：单独的创建/状态/取消/结果接口，持久阶段、租约、预算与通知状态。请求中断后核对既有操作，避免重复计费；字幕与 ASR 来源明确区分。
6. **网页**：复用现有布局、鉴权与 Hono RPC。配置页支持启停、字段校验、保存冲突、已保存但应用失败、连接检测与显式凭据清除；覆盖中英文与移动视口。

首批配置字段为字符串、长文本、数值、整数、布尔和选择项，敏感标记仅允许文本字段。凭据不设置默认值；空更新保留，`null` 明确清除。普通字段的 `null` 恢复默认值，没有默认值则移除。草稿可不完整，启用前验证必填字段。

- search 不扩大原有 Bot、聊天、用户、私有仓库与资产权限；无写操作、无隐式 ASR。
- 插件配置无明文凭据回传、日志泄漏或跨 Bot 共享；清除、替换、并发保存与重启生效可验证。升级后字段从 secret 变成普通字段时，不得直接公开原有秘密；存储层保留秘密字段归属并要求显式清除或迁移。
- 安装绑定确切版本，路径与来源检查、失败恢复、禁用后取消、卸载后资源回收有测试；信任假设在管理界面与文档一致。
- 媒体链接逐跳校验，凭据不向无关主机转发，下载/转码/ASR 有时长、字节、并发和费用上限。
- ASR 的取消、重启恢复、去重、结果分页、导出及清理用合成内容验证；没有真实第三方凭据的部分明确报告验证限制。
- 对用户可见的说明与开发指南写入公开文档，保留旧配置/旧工具的兼容与回滚说明。
- 完成前不能将配置协议或静态页面称为完整插件市场，也不能将本地测试称为线上验证。
