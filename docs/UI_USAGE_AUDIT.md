# 用量页操作与信息层级复核

## 基线与范围

2026-09-22，基于 v0.8.0 后 main `5fca6df071a4bd8e354dfc9193295c4e2d2e7098`，使用隔离生产预览和合成 API 数据。桌面 1440×900、手机 390×844；没有连接生产数据库或真实模型。

基线证据位于 `.acceptance/ui-efficiency/usage-baseline/`，脚本 `verify-usage.mjs`。

## 已确认问题

| 操作               | 当前问题                                                                | 本轮改进                             |
| ------------------ | ----------------------------------------------------------------------- | ------------------------------------ |
| 查看近期用量       | 趋势标题在桌面 y1093 / 手机 y1365，先经过八个指标、年度热力图与缓存趋势 | 核心指标与用量趋势前置               |
| 选择较晚创建的 Bot | 125 个 Bot 的夹具仅出现 100 个 Bot 选项，Bot 125 无法选择               | 顺序加载全部分页；失败不提交部分选项 |
| 理解统计范围       | 选择某个 Bot 后 Bot 对比仍为全局，年度图也不跟随7/30/90天，页面缺少解释 | 当前范围与例外范围明确展示           |

热力图复核另确认：原网格固定53周，却从今天回退370天后再向前对齐周日，周日到周五会漏掉当前周已经发生的日期（含今天）。修复从本周周日起回退52周，让最后一列包含本周（包括标记为 future 的未来日期）。

现有请求 active 保护与独立错误重试已经存在，本轮保留；历史竞态记录不作为新缺陷。

## 验收要求

1. 核心用量趋势位于缓存诊断和年度视图之前，桌面及手机首屏可找到。
2. 125 Bot 完整读取，第125个可选；后续页失败明确报错并可恢复，不展示半成品选项。
3. 汇总、用量趋势、模型与缓存诊断按 Bot 和时间；全 Bot 对比只按时间；年度按 Bot 固定365天。
4. 当前加载、空、错误重试、旧响应保护保持；键盘可选择，手机无横向溢出。
5. 公共指南与 v0.9.0 版本页同步，发布前仔细审查与 CI。

- 热力图：基线5项日期测试中4项失败（只有周六通过）；修复后6项回归通过，包含仅今天非零的组件渲染。
- 文档：类型与生产构建通过，匿名访问/深链/搜索/导航共14项桌面手机检查通过。证据 `.acceptance/ui-efficiency/docs-v0.9.0-final/`。
- 主代理预审修复：独立全Bot请求仍被主统计的渲染条件隐藏，现已解耦并在生产预览复验。
