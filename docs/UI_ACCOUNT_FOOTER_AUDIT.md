# 侧栏账户区与手机底部占用验收

## 基线与用户旅程

基线为 v0.13.1 发布提交 `72909dab037332d7ec5514c879afba78b340d5a2`。用户提供的 2026-09-23 Android Chrome 截图显示：Bot 工作区侧栏底部固定展示语言选择器、文档、更新说明、设置与退出登录；其中「退出登录」占一个完整的常驻操作位，底部固定区域挤占可滚动的导航。当前源码的页脚为 `shrink-0`，语言控件一行加两行链接/按钮。截图是用户真实设备上的当前界面基线，不据此推断新实现已经在该设备可用。

另在旧生产构建预览用合成账户/Bot 测得：1440×900 和 390×844 两档的侧栏固定页脚均为 153 CSS px，页面无脚本异常或横向溢出。测量和截图位于 `.acceptance/ui-efficiency/account-footer-baseline/`；这是模拟浏览器基线，与用户提供的实机截图分开记录。

用户希望用传统 SaaS 的账户头像入口打开设置，并把退出登录收进菜单；更广义的目标是缩小侧栏底部固定区域，给导航留更多高度。

## 本轮验收条件

- 侧栏底部常驻部分压缩为一行清晰可辨的账户入口；展开后仍能找到设置、语言、文档、更新说明和退出登录。账户资料未加载时有诚实的回退，不展示伪造头像。
- Bot 与全局侧栏、桌面展开/折叠、390px 手机均保持可用；手机抽屉关闭和重开、导航搜索、当前页面标记不回归。检查底部安全区与窄屏横向溢出。
- 键盘能打开/关闭账户菜单并访问每个操作，Escape 与移动抽屉的焦点回归明确；中英文文案齐全。
- 退出仍经过现有未保存草稿确认、Better Auth 登出和失败恢复。打开账户菜单、查看设置/文档或更换语言不执行登出。
- 使用合成身份与本地浏览器验证，不操作生产账户或真实 Bot。

## 实现与证据

- 侧栏底部常驻区改为头像/名称/展开箭头一行；账户菜单在侧栏 DOM 内向上展开，包含设置、语言、文档、更新说明和退出。头像优先使用会话用户名首字，资料不可用时回退到通用用户图标与「账户」文案。退出仍沿用 `useLogout` 与 `requestLogout` 的草稿确认路径。
- 聚焦面板浏览器测试最终 14/14、Panel 类型检查、i18n 2438 keys、局部 lint/format 与生产构建通过。浏览器回归包含移动抽屉焦点、桌面折叠、语言选择浮层，以及 AI 设置未保存草稿的取消/退出失败/再次成功。
- 生产构建预览使用合成账户/Bot：1440×900 中文、390×844 中文和英文，固定页脚均为 69 CSS px；相对旧预览 153px 减少 84px。菜单内设置和退出可见，Escape 回到头像入口；桌面折叠侧栏为 68px 宽并只显示头像。三档均无脚本异常或页面横向溢出。截图和测量位于 `.acceptance/ui-efficiency/account-footer-final/`。
- 主代理补测发现：原候选在手机菜单展开后，从头像入口按 Shift+Tab 会聚焦被菜单遮住的「全局管理」。已在菜单展开时暂时移出搜索/主导航的焦点顺序；最终中文/英文生产预览里 Shift+Tab 均到可见的抽屉关闭按钮，`covered=false`。Lody 独立窄复核未发现该修复引入的新 P1/P2。
- 继续补测发现：语言 Select 浮层按 Escape 关闭后焦点会短暂落到 `BODY`，导致第二下 Escape 不关闭账户菜单。现已在浮层关闭后回焦可见的语言触发器，并为 `BODY` 目标保留账户菜单的下一层 Escape。最终生产预览在中英文 390px 验证第一次 Escape 关闭语言选项并回焦、第二次关闭账户菜单并回焦；聚焦浏览器用例还覆盖第三次关闭手机抽屉。
- Lody 独立只读审查查看代码和中英文/折叠截图，初轮及两次窄复核均未发现剩余可复现 P1/P2；最后一次在当前树复跑聚焦 Chromium 14/14。原截图位于本次会话附件，不复制到公开文档或 Git 仓库。完整 CI 与 GitHub Release 仍待完成。

## 边界

本轮仅调整侧栏账户入口和常驻底部占用；不改变服务端认证、权限、登出语义、文档路由或 Bot 导航结构。此前全局日志 Bot 菜单的可见名称查找仍是后续独立候选。
