# AI 日志排查

管理面板的 Bot 日志和全局日志共用可展开详情。搜索同时匹配消息和已保存的 metadata；可以用 chatId 限定群聊，或用 correlationId 查看同一次 AI 执行的请求、工具调用、回复、交付和错误。暂停实时更新后可稳定阅读长详情，复制 JSON 可保留完整的已存储记录。

普通 AI 回复及事件续聊记录模型、供应商、输入消息、输出、Token 用量和耗时。工具调用保留参数、结果、调用 ID；上游失败保留 Error 类型、message、stack、cause、HTTP 状态和响应体等实际提供的字段。SDK 后续产生通用的 `No output generated` 时，首次 provider 错误仍单独记录，避免根因被覆盖。没有上游提供的数据不会虚构。

日志中保留普通诊断正文；凭据、Authorization、token、Cookie 等仍脱敏，Token 数量不会被当作凭据隐藏。二进制使用摘要，大文本、深层结构和大集合带明确的截断标记。页面完整展示已保存内容，无法恢复升级前未采集或已截断的字段。隐私 off 的普通回复不记录输入和回复正文。

JEV 决策日志记录模式、建议、实际准入、置信度、概率、原因、版本、耗时与费用。其上下文正文只保留在接话样本中，遵循样本的到期清除和“忘记我”规则，不在普通日志中额外复制。

数据库日志包含 debug 记录；终端输出仍遵循现有 Pino 日志级别。日志清理仍遵循部署中已有的普通/错误日志保留配置。本次修改不改变保留期限，也不启用真实服务调用。
