# v0.8.0 — AI 读取缓存头像

AI 可在明确请求下读取人物档案中已缓存的头像进行视觉分析，不必再因为只拿到 `hasAvatar` 而向用户反复要图。

## 更新内容

- **新增 `get_profile_avatar` 工具**：按指定 Telegram 用户 ID 读取当前 Bot 的缓存头像，普通回复与续聊均可用。
- **原生图像输入**：头像以图像消息直接进入模型上下文，兼容当前 OpenAI 兼容与 Google 适配器，单次请求最多读取 3 个头像。
- **复用个人化隐私规则**：请求者关闭个人化时不可用，目标用户设为 `off` 时拒绝，`isolated` 头像仅本人可读；档案与缓存按 Bot 隔离。
- **清晰状态与安全边界**：区分无档案、无头像、缓存不可用、权限拒绝与临时故障，不向模型暴露文件路径、存储凭据或永久公开 URL。
- **日志与权限不变**：工具日志和持久历史仅记录状态，图片只留在当次模型请求；读取头像不赋予修改他人角色形象或绑定的权限。

详见文档站「角色与提示词资产库 — 从缓存头像整理外貌」及「隐私、历史与记忆」。

## 升级说明

- 无需数据库迁移或新增配置；需开启人物档案记忆，并使用支持视觉输入的回复模型。
- 仅读取本地已有缓存，不会临时向 Telegram 拉取头像；缓存过期、缺失或损坏时需由用户发图或等待正常刷新。
- 文档站需随应用重新构建部署。

## 验证范围

已通过头像缓存、Bot 隔离、本人／他人隐私、工具状态、普通回复／续聊接线及适配器出图（模拟 HTTP 响应）测试，同步验证文档构建与版本页。未调用真实模型、读取真实头像或发送 Telegram 消息。
