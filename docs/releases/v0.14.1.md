# v0.14.1 — 按名称查找日志中的 Bot

全局日志页的 Bot 筛选支持在菜单中输入名称。管理多个 Bot 时，可以直接找到目标并查看对应日志，无需从长列表逐项滚动。

## 改进

- 在完整 Bot 选项中按名称查找，并保留清除选择、键盘操作和手机布局。
- 保留跨页加载；加载失败时可在选择菜单中重试，不显示未完成的选项列表。
- 浏览器后退或前进时，所选 Bot 与地址、历史日志、实时连接和清理确认范围同步。名称查找只缩小菜单候选，不改变日志内容搜索或清理范围。

## 使用与升级

- 无配置或数据库迁移。更新面板后进入全局 **日志**，打开 Bot 筛选并输入名称。
- 回滚到上一版本的应用构建即可；服务端日志接口和已存日志不变。

## 验证边界

桌面和手机浏览器检查使用合成 Bot 与模拟日志 API。没有读取或删除生产日志，也没有执行生产部署。文档构建与 GitHub Release 不会自动更新运行中的实例。
