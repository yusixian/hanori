# v0.14.1 — 按名称查找日志中的 Bot

全局日志页的 Bot 筛选菜单支持按名称搜索，多 Bot 场景下可直接定位目标，不用在长下拉里翻找。

## 改进

- 支持在完整 Bot 选项中按名称过滤，保留清除选择、键盘操作与移动端适配。
- 维持跨页全量加载；加载失败可在菜单内重试，不展示不完整列表。
- 浏览器前进／后退时，选中 Bot 与 URL、历史日志、实时连接及清理确认范围保持同步；名称过滤仅收窄下拉候选，不改变日志搜索或清理范围。

## 使用与升级

- 无需配置或数据库迁移，更新面板后在全局 **日志** 页打开 Bot 筛选输入名称即可。
- 回滚切回上一版应用构建即可，日志接口与已存日志不变。

## 验证边界

桌面与移动端浏览器测试基于合成 Bot 与模拟日志 API，未读取或清理生产日志，未执行线上部署。
