# v0.29.1 — 群友印象回顾与生图确认修复

Telegram 生图确认卡展示待提交的提示词、负面提示词与生成参数（长提示词显示预览及总字数）；确认后沿用卡片任务 ID，重复确认同一张卡仅提交一次。

## 群友印象与回顾

管理员可以让 Bot 定期从群友明确的本人发言里提炼兴趣和习惯。默认每 12 小时整理一次，每轮最多 4 次模型调用。频率、模型、调用上限和个人记忆保留期限均可配置。手动回顾支持选择群和时间范围，也可以从已有日报进入。面板显示整理结果和 Token 用量。

## 面板首次部署引导

Owner 登录后，可在 Bot 列表首页确认账号安全、配置 AI Provider 并启用首个 Telegram Bot。清单显示三步进度，支持折叠，并在当前浏览器记住安全确认和关闭选择。

## 使用与升级

连接 GitHub App 的 Bot 默认使用最近一次同步的全部授权仓库。已有 Bot 的管理员同样可以访问该列表中的全部仓库。如需缩小范围，在 GitHub 安装设置中选择指定仓库，再回到面板点击「同步授权仓库」。旧版个人 Token 继续使用原来的仓库列表。

全新 Docker 实例可从 `.env.selfhost.example` 手动配置。启动前运行 `pnpm deploy:env:check`，检查必填项、认证地址、GitHub App 配置和已启用的 worker 密钥。输出只包含配置项名称和处理建议。

桌面管理面板在侧栏和工作区之间留出间距。宽屏日志按列显示时间、级别、事件和工具名，手机上可展开记录查看完整标识。生成详情页将作品预览与参数并排展示，窄屏按顺序阅读。

升级前应用数据库迁移 `0076`，保留现有整理游标和证据。此前已结束的任务保持原状态，需重新生成请发起新请求。

- **GHCR 预构建镜像**：发布流程为 Linux amd64 和 arm64 构建应用与 worker 镜像。使用同版本的 `docker-compose.prebuilt.yml` 即可安装或升级。
- **一键安装与平台模板**：`scripts/install.sh` 可下载预构建部署文件并生成私有 `.env`，重复执行保留已有配置。新增 Coolify、1Panel 模板及 Dokploy 部署说明。
- **Docker 初始化和图片分类**：新安装可用 `./scripts/init-env.sh` 生成 Docker 环境文件。升级时如需继续使用内置图片分类服务，将 `nsfw` 加入 `COMPOSE_PROFILES`。直连默认宿主机端口改为 `43100`，仍使用旧端口的代理可在 `.env` 显式设置 `PORT=9600`。
- **Dokploy 部署**：升级前将当前 app 的 `traefik.docker.network` 标签值填入 `TRAEFIK_DOCKER_NETWORK`（默认 `dokploy-network`），保留原 Compose 项目名与数据卷。
- **本地 Mini App 开发**：在根目录 `.env` 设置 `COS_TOOL_BOT_MINI_APP_ORIGIN` 为已有 HTTPS 域名后运行 `pnpm dev:mini-app`。
- 新增中英文 README、Caddy 和 Nginx 反向代理示例，以及自托管排错指南和 Issue 模板。公开文档的搜索和移动导航在页面完成加载后可用。PR 在 GitHub 托管的 Ubuntu runner 上检查，main 检查通过后触发部署。

## 飞书机器人下线

移除飞书 Webhook Bot、邮件转发及对应面板入口，升级后仅启动 Telegram Bot。原有飞书数据保留在数据库中不删表，Bot JSON 导出会自动剔除旧 Webhook 与邮箱配置，导入旧飞书 Bot 将返回不支持的平台错误。飞书功能下线本身无需额外迁移。

## 诊断与备份隐私

- 所有者和管理员可从账户设置打开「系统诊断与健康中心」，刷新部署、认证、Mini App 和可选服务状态。
- 工具日志与调试运行记录统一脱敏数据库密码、加密密钥和代理凭据。
- 面板备份以私有权限创建归档，并通过临时密码文件执行数据库导出；WebDAV 备份记录省略查询参数与远端错误正文。
- Bot JSON 导入与导出自动剥离模型服务商和互动配置中的密钥。
