# v0.29.1 — 生图确认修复（未发布候选）

Telegram 生图确认卡展示即将提交的提示词、负面提示词和生成参数。长提示词会显示预览和完整字符数。确认后沿用卡片上的任务 ID；同一张卡重复确认只会提交一次。

## 使用与升级

本次修复无需数据库迁移。此前已结束的任务保留原状态，需要重新生成时请发起新请求。

- Dokploy 部署升级前，将当前 app 的 `traefik.docker.network` 标签值填入 `TRAEFIK_DOCKER_NETWORK`。默认值为 `dokploy-network`。沿用原 Compose 项目名和卷。
- 本地 Mini App 开发在仓库根目录的 `.env` 里设置 `COS_TOOL_BOT_MINI_APP_ORIGIN` 为已有 HTTPS 域名后，继续运行 `pnpm dev:mini-app`。
- 源码、文档和贡献流程统一在仓库根目录维护，PR 使用 GitHub 托管的 Ubuntu runner 运行检查。

## 飞书机器人下线

本版移除飞书 Webhook Bot、邮件转发及面板配置入口。升级后仅启动 Telegram Bot。已有飞书配置保留在原数据库中，Bot JSON 导出会剔除旧 Webhook 和邮箱配置，导入旧飞书 Bot 会返回不支持的平台错误。无需数据库迁移。

## 诊断与备份隐私

工具日志和调试运行记录统一遮盖数据库密码、加密密钥和代理认证信息。面板备份以私有权限创建归档，并通过临时密码文件运行数据库导出。WebDAV 备份记录省略查询参数和远端错误正文。Bot JSON 导出和导入会移除模型服务商与互动配置中的密钥。
