# v0.13.0 — 在全部 Bot 中按名称查找

Bot 列表现在可以按名称查找全部 Bot，无需记住目标在哪一页。匹配数量和分页随搜索结果更新，手机与桌面均可直接使用。

## 改进

- 在 Bot 列表输入部分名称即可搜索，按 Enter 可立即提交；清空搜索返回完整列表。
- 搜索由服务端在分页前执行，匹配总数也按相同条件计算。名称匹配不区分大小写，`%` 和 `_` 按普通字符处理。
- 无匹配结果、没有 Bot 和加载失败分别显示对应状态；搜索后仍可重试加载。
- 页码输入框提供可读的辅助技术名称。

## 使用与升级

- 无配置或数据库迁移。更新面板后打开 Bot 列表，使用「查找 Bot」输入框即可。
- 回滚到上一版本的应用构建即可；旧客户端继续使用原有未筛选列表接口。

## 验证边界

桌面和手机浏览器检查使用 125 个合成 Bot 的 API 夹具，覆盖跨页查找、多页结果、无匹配、清空、错误恢复和键盘操作；路由测试核对了查询 SQL 与分页总数，没有读取真实 Bot 数据或执行生产部署。文档构建与 GitHub Release 不会自动更新运行中的实例。
