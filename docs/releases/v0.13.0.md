# v0.13.0 — 在全部 Bot 中按名称查找

Bot 列表新增服务端名称搜索，不必记住目标 Bot 在第几页，桌面与手机均支持按部分名称检索全部 Bot。

## 改进

- 在 Bot 列表输入部分名称即可搜索，按 Enter 立即提交，清空恢复完整列表。
- 搜索在服务端分页前执行并重新计算匹配总数；匹配不区分大小写，`%` 与 `_` 按普通字符处理。
- 明确区分无匹配、暂无 Bot 与加载失败状态，搜索失败后可就地重试。
- 为页码输入框补齐辅助技术可读名称。

## 使用与升级

- 无需配置或数据库迁移，更新面板后在 Bot 列表使用「查找 Bot」即可。
- 回滚切回上一版应用构建即可；旧客户端继续兼容原有未筛选列表接口。

## 验证边界

桌面与移动端浏览器测试基于 125 个合成 Bot 夹具，覆盖跨页查找、多页结果、无匹配、清空、错误恢复与键盘操作；路由测试校验了查询 SQL 与分页总数。未接入真实 Bot 数据或生产部署。
