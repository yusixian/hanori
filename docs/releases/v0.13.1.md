# v0.13.1 — 全局日志可筛选全部 Bot

修复全局日志页 Bot 筛选下拉只加载前 100 项的问题，Bot 数量超过 100 时也能正常选中后续 Bot 查看日志。

## 修复

- Bot 筛选下拉改为跨页拉取全量列表，不再截断在前 100 个。
- 选项加载失败时显示错误并支持重试，不再把不完整列表当成全部 Bot。
- 保留原有按 Bot ID 筛选、日志内容展示与清理范围。

## 使用与升级

- 无需配置或数据库迁移，更新面板后进入全局「日志」页即可使用。
- 回滚切回上一版应用构建即可，日志数据与接口不变。

## 验证边界

桌面与移动端浏览器测试基于 125 个合成 Bot 与模拟日志 API，验证了第 100 项之后的选择、筛选参数、失败恢复与键盘操作；未涉及真实日志、清理操作或生产部署。

Bot 数量较多时下拉菜单仍需滚动查找，筛选框内名称检索将在后续版本独立补齐。
