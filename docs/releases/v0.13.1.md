# v0.13.1 — 全局日志可筛选全部 Bot

全局日志页的 Bot 筛选现在会读取完整 Bot 列表。Bot 数量超过 100 时，也能从筛选框选择后续 Bot 查看其日志。

## 修复

- Bot 筛选选项跨页读取，避免只显示前 100 个 Bot。
- 选项加载失败时显示错误和重试，不将不完整的列表当作全部 Bot。
- 保留按 Bot ID 的日志筛选、已有日志内容和日志清理范围。

## 使用与升级

- 无配置或数据库迁移。更新面板后进入全局「日志」页，选择目标 Bot 即可。
- 回滚到上一版本的应用构建即可；日志数据和服务端接口没有改变。

## 验证边界

桌面和手机浏览器检查使用 125 个合成 Bot 与模拟日志 API，验证了后续 Bot 可选择、筛选参数、失败恢复和键盘操作；没有读取真实日志或执行生产部署、日志清理与消息发送。文档构建与 GitHub Release 不会自动更新运行中的实例。

大量 Bot 的筛选菜单仍需滚动查找名称；可见的名称查找入口计划在后续独立改进中验收。
