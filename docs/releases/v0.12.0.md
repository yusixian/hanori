# v0.12.0 — JEV 接话调参与决策诊断

细化 JEV 接话门槛配置并补全决策诊断字段，让「模型主动沉默」「置信度不足」和「冷却限制」一眼分清。

## 功能

- **细粒度接话门槛**：智能群聊接话新增「直接招呼置信度」「延续对话置信度」和「续聊窗口」配置，支持 Bot 默认与按群覆盖；续聊窗口设为 `0` 可关闭延续对话的冷却豁免。
- **偏好示例与边界**：补充接话偏好提供可预览、手动应用的示例，并将 JEV 接话偏好与回复模型的群聊提示词分开说明，避免混用。
- **原始建议与路由分离**：新决策记录同时保存原始参与建议及其置信度，与经门槛裁决后的参与路由分别展示；历史记录缺失字段直接标为缺失，不反推。
- **按版本与格式评估**：决策列表支持按配置版本与决策格式筛选；人工评估分开展示两阶段判断与旧版三分类样本，避免混算误插话率或漏回复率。

## 使用与升级

- 既有配置默认沿用原行为（新参与门槛 `0.8`，续聊窗口 `120` 秒），不会自动改动门槛、偏好或运行模式。
- 本版本新增可空的决策记录列，启动时按现有流程自动迁移；升级前请备份数据库，历史样本与标注保留不变。
- 「是否回复」与「参与方式」仍独立判定：调低参与门槛不会把模型主动沉默改成回复，置信度也不等同于回复概率或实测准确率。
- 建议先在单个群调参，再按同一配置版本复核新样本；人工标注仅用于评估，不会训练模型或自动调参。
- 回滚只需将参与门槛恢复为 `0.8`、续聊窗口恢复为 `120` 秒并还原偏好（或关闭该群 JEV），无需删列或清理历史。

## 验证边界

自动化测试使用模拟分类响应与隔离数据，不代表真实 JEV 的中文接话质量、Telegram 发送成功率或线上延迟。文档站与面板需重新构建部署后生效。
