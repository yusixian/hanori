# v0.12.0 — JEV 接话调参与决策诊断

这次更新让 JEV 的接话设置和决策记录更容易对应起来：可以分别调整直接招呼、延续对话的门槛，并分清模型主动沉默、回复置信度不足和后续冷却限制。

## 功能

- 智能群聊接话增加直接招呼置信度、延续对话置信度和续聊窗口配置，支持 Bot 默认值及群组覆盖。续聊窗口设为 0 可关闭延续对话的主动插话冷却豁免。
- 补充接话偏好提供可预览、显式应用的示例。JEV 接话偏好与回复模型的群聊提示词分开说明，避免把回复风格要求误认为接话准入条件。
- 新决策记录保存原始参与建议及其置信度，和经过门槛后的参与路由分别展示。历史记录没有保存的字段显示缺失状态，不从概率反推。
- 决策列表支持按配置版本和决策格式筛选；人工评估分别展示两阶段判断与历史三分类样本，避免旧标签混成当前算法的误插话或漏回复率。

## 使用与升级

- 已有配置保持原有行为：缺失的新参与门槛均为 0.8，续聊窗口为 120 秒。不会自动降低回复门槛、填入偏好或切换运行模式。
- 新增可空的参与判断记录字段，服务启动时按现有流程运行数据库迁移。升级前按部署指南备份数据库；历史样本与标签继续保留。
- 判断是否回复和参与方式仍然独立。降低参与门槛不会让模型已经选择沉默的记录变成回复，置信度也不等于回复概率或实测准确率。
- 建议先在单个群调整接话偏好，再按同一配置版本复核新样本；人工标注不会训练模型或自动调参。
- 回滚接话设置可恢复参与门槛 0.8、续聊窗口 120 秒及原有偏好，或关闭该群 JEV。无需删除新列或历史记录。

## 验证边界

自动化验证使用模拟分类响应与隔离数据，不能证明真实 JEV 的中文接话质量、Telegram 发送成功率或线上延迟。文档站构建与 GitHub Release 发布不会自动更新正在运行的实例；部署后才能使用新面板和公开版本页。
