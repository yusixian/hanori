# v0.12.1 — 模型用量明细可读性

用量页「按模型」明细改为可换行展示，长模型 ID 不再被图表坐标轴截断，桌面与手机都能直接看清输入／输出 Token 数值与占比。

## 改进

- 「按模型」改为可换行明细行，完整显示长模型 ID。
- 每行直接展示总 Token、输入与输出 Token，分段条按当前列表最大总用量等比对照。
- 保留时间／Bot 筛选、独立错误重试及其余用量图表。

## 使用与升级

- 无需配置或数据库迁移，更新面板后在全局「用量」页即可生效；模型明细继续跟随时间与 Bot 筛选。
- 回滚只需切回上一版应用构建，数据与接口无变化。

## 验证边界

桌面与移动端浏览器测试使用合成 API 数据，验证了长模型 ID 换行、数值展示、筛选与错误恢复；未读取生产用量或执行线上部署。
