# v0.12.1 — 模型用量明细可读性

管理面板的用量页现在完整显示模型 ID。手机和桌面上都能直接查看每个模型的 Token 总量，以及输入与输出的数值和比例，不再依赖图表轴标签或悬停提示。

## 改进

- 「按模型」改为可换行的明细行，较长的模型 ID 不会被左侧坐标轴裁切。
- 每行显示 Token 总量、输入和输出 Token；分段条按当前列表中最高的输入加输出用量比较。
- 保留时间与 Bot 筛选、独立错误重试和其他用量图表。

## 使用与升级

- 无配置或数据库迁移。更新面板后打开全局「用量」页即可查看；切换时间或 Bot 后，模型明细仍随当前筛选更新。
- 若需回滚，使用上一版本的应用构建即可；用量数据与接口没有改变。

## 验证边界

桌面和手机浏览器检查使用隔离的合成 API 数据，验证了长模型 ID 换行、数值显示、筛选和错误恢复；没有读取真实用量或执行生产部署。文档站构建与 GitHub Release 不会自动更新运行中的实例。
