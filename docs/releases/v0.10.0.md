# v0.10.0 — 人物检索与记忆筛选

人物档案搜索改为服务端分页，打通人物卡到长期记忆的直达入口，并把记忆筛选条件持久化到 URL。

## 更新内容

- **人物搜索服务端分页**：突破 10 条上限，支持翻页与真实总数，按最近出现时间与档案 ID 稳定排序。（AI 工具内部的人物搜索仍保持最多 10 条。）
- **人物直达记忆**：人物卡新增 **查看记忆**，直接跳转当前 Bot 下该 Telegram 用户的记忆列表。
- **记忆组合筛选**：支持范围（全部／仅通用／指定用户）、分类与内容搜索组合；修改后点击 **搜索** 生效，清除筛选回到第 1 页。
- **筛选状态同步 URL**：已应用的范围、分类、搜索词与页码写入 URL，支持刷新、分享链接与浏览器前进／后退。编辑或写入结果未确认时，新 URL 会延后生效，避免状态错乱。
- **新建记忆预填**：从人物卡进入指定用户范围后，新建表单自动预填该用户 ID，提交前可修改或清空。
- **编辑与草稿保护**：写入或刷新失败继续保留草稿；切换筛选前需先保存或取消正在编辑的记忆。

## 升级说明

- 无需数据库迁移或新增配置，读写权限不变。
- `GET /api/bots/:botId/memories` 的 `telegramId` 参数现在仅接受空值、`general` 或安全十进制整数；原先静默忽略的非法值改为返回 HTTP 400，自研客户端请先检查入参。
- 页面错误恢复会保留当前草稿，但离开、关闭或刷新页面不保留未提交内容。
- 文档站需随应用重新构建部署。

## 验证范围

已通过人物档案（26 项）与记忆（24 项）浏览器回归、后端分页与参数契约（43 项）测试、临时 PostgreSQL 17 分页／排序／Bot 隔离验证、桌面／移动端生产构建抽检及公开文档检查。未覆盖真实生产环境、真实头像与 Telegram 消息。
