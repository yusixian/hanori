# v0.9.1 — 档案与记忆管理错误恢复

理清人物档案与记忆管理页的加载失败、提交失败和刷新失败，避免误判无数据或重复提交。

## 修复内容

- **区分加载失败与空列表**：列表加载失败展示错误与重试按钮；同条件下刷新失败保留已有数据并标出状态，不再误显无记录。
- **严格校验写入结果**：创建、编辑、删除同时校验 HTTP 状态与业务结果；结果未确认时保留草稿或列表并提供刷新入口，确认成功后才关闭表单。
- **提交期防重**：提交中禁用相关输入与操作，避免连点以及迟到响应冲掉新草稿。
- **隔离过期响应**：切换 Bot、搜索或筛选后丢弃旧请求结果；切换 Bot 时重置当前页表单状态。
- **拆分写入与刷新提示**：操作成功但随后的列表刷新失败时分开提示，不把刷新失败当成写入失败。

详见文档站「隐私、历史与记忆 — 在面板维护档案与记忆」。

## 升级说明

- 无需数据库迁移或新增配置；接口、权限与个人化规则不变，未新增搜索或筛选维度。
- 草稿仅存于当前页面（无离开确认或持久化），网络中断后请先刷新列表再决定是否重提。
- 文档站需随应用重新构建部署。

## 验证范围

已验证档案与记忆的加载／增删改失败恢复、提交锁定、过期请求拦截、Bot 切换、桌面／移动端布局及公开文档。浏览器使用模拟 API，未修改生产数据或发送 Telegram 消息。
