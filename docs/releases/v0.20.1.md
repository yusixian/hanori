# v0.20.1 — 运行可靠性与架构维护（待发布）

> 待发布草稿：记录当前候选改动，版本号以正式发布为准。此页面不表示 GitHub Release 已发布或实例已部署。

## 功能补齐

- 全局定时群总结开始生效：在 Bot 总结时区的配置时间，为没有逐群配置且最近 24 小时至少有 5 条符合角色过滤的消息的已知群执行总结。排除私聊、频道、退群和迁移旧群，沿用默认窗口、模型和提示词；逐群配置（包括关闭）优先。
- 全局调度使用独立持久执行记录，多个实例与重启共享 23 小时冷却；失败不自动补发，不创建隐式逐群配置。正常关停等待已接纳的总结和发送。

## 修复

### Bot 交互、权限与模型能力

- 系统提示注入文件逐项隔离读取失败，单个文件不可读不再清空其他有效身份与设定内容；不缓存不完整读取结果，文件恢复后可在下一次加载重新读取，保留原优先级、预算和正常缓存规则。
- AI 选择按钮校验原聊天、原消息及有效选项索引，拒绝跨消息和异常选项回调；被拒绝的异常回调不会消耗原选择。
- 定时器取消按钮重新校验点击者的管理员身份，避免其他群成员操作管理员展示的按钮；AI 取消工具仅操作当前聊天的任务，管理员仍可通过 `/timers` 管理其他聊天的定时器。
- 取消 AI 定时器会等待持久化成功，数据库失败不再误报成功；失败时保留本地任务供重试，取消与触发串行协调。已开始的投递不会被宣称撤销，AI 工具与面板使用一致的成功边界。
- 定时群总结按聊天隔离配置读取和执行异常，避免单个聊天失败阻断同批其他聊天；保留已登记任务的冷却，不自动重试或补发。
- 修复模型能力目录的解析层级，正确读取供应商下的模型数据；同名模型能力冲突时保留名称回退，图片能力优先依据输入模态，异常或空目录不会清空上次有效缓存。已有模型的手动能力配置保持不变。
- 模型能力目录返回 HTTP 错误时释放未读取的响应正文，继续保留上次有效缓存；正文释放失败不会掩盖原始 HTTP 状态。
- Telegram 头像下载按分块执行 5 MB 上限，超限或 HTTP 错误立即取消读取并保留已有头像，避免缺失或低报 Content-Length 时先把整个响应读入内存；复用现有图片限量读取逻辑。
- 管理员确认动作已登记但尚未开始执行时，关闭 Bot 不再调起其执行回调；统一 AI 任务与管理员动作的限时结束等待，保留已执行任务的取消与超时结果。

### MCP 连接与授权

- 通用 MCP 服务连接失败后保留连续重试次数，以指数退避最多自动重试 10 次；连接成功后重置，手动重连可开启新一轮。完整握手与工具发现限制为 30 秒，停用或删除服务后，过期连接结果不会重新激活服务。
- MCP 请求取消或超时后，区分未发送、明确失败与结果未知。对于可能已执行的写操作，同一轮对话停止向该服务自动发送后续写入，仍允许只读核对；保留请求关联信息和脱敏后的远端错误原因。
- 图片 MCP 断开或重新授权后，旧 OAuth 回调和令牌刷新不能重新写入凭据、恢复旧连接或覆盖新的授权状态。
- Bot 的 MCP 配置变更延迟重启绑定当前运行实例，连续修改合并处理；停止、显式重启和服务关停会收尾旧请求，避免旧任务再次影响新实例。重启尝试失败后，仍运行的实例可继续响应后续配置刷新。

以上 MCP 规则适用于面板中添加的通用 MCP 服务。取消请求不等于远端操作已撤销；结果未知时应先核对远端状态。此保护不提供跨进程去重或自动对账。

### 正常关停与后台维护

- Bot Run 后台事件或终态写入失败时，由任务入口捕获并记录脱敏应用日志，避免未处理拒绝触发整个服务退出；不自动重试模型请求，也不保证数据库故障期间可写入终态，保留启动恢复处理。

- 修复 Bot Run 取消等待期间任务已完成时，旧请求仍覆盖完成状态、原因和时间的问题；无活动控制器时仅取消数据库中仍在运行的记录，已完成或已删除的运行不再误报取消成功。取消检查复用轻量状态查询，不再加载完整事件历史。

- 日志和 Bot Run 实时连接在认证等待期间断开时，认证结束后直接退出，不再创建事件流或启动其数据查询；保留原权限检查顺序。
- 已建立的实时连接断开后，停止推送迟到结果和同批剩余记录，已发出的查询返回后退出；保留日志范围与游标、Bot Run 事件续传及正常完成通知。任务取消仍由原操作控制。
- `SIGINT` 与 `SIGTERM` 先后到达时共用同一次正常关停，避免重复停止服务和关闭数据库；保留原有关闭顺序。单个清理步骤失败后继续清理剩余服务，等待并行收尾全部结束，记录脱敏诊断并以非零状态退出。
- 定时提醒在正常关停时停止调度，等待投递结果和在途数据库操作后再关闭 AI 工具依赖，避免失败回调重新挂载重试；尚未发出的恢复提醒保留可恢复状态。
- 插件正常关停补齐应用自身的数据库准备与授权校验等待，避免活动会话登记前的查询在数据库关闭后继续；保留插件调用超时、晚到结果清理和已接纳配置修改的收尾。
- 群聊总结正常关停时停止接纳新任务，等待已有定时／手动总结（包括 Telegram `/summary` 成功回复）的执行和发送后关闭依赖；保留原有冷却、失败结果和暂停后恢复调度行为。
- RSS 正常关停会等待已有抓取、摘要投递和检查点写入，并在此之前保留 AI 工具依赖；停止接纳新工作和后续调度。抓取超时、HTTP 错误及重定向不再遗留请求，保留现有 Feed 解析行为。
- 图片生成服务正常关停时停止接纳新的执行和供应商查询，取消后续轮询，并在关闭依赖前等待已接纳任务及其快照、投递回执收尾；管理员删除记录及随后的本地文件清理也纳入等待，关停后拒绝新的删除。后台数据库异常会被记录，避免未处理的 Promise 拒绝；关停不作为远端取消、退款或重发依据。
- 日志、Bot Run、非活跃记忆与互动样本上下文的定期清理在正常关停时等待已启动的数据库查询完成，避免数据库先关闭导致清理中断；保留周期和删除条件不变。
- 记忆整合在关停时不再开始处理下一 Bot，等待当前 Bot 的模型结果、用量结算、记忆及向量写入、租约释放后再关闭依赖。
- 图片保留清理在关停时等待文件删除、清理标记及其他仍在执行的并行查询，避免单项查询失败导致提前关闭数据库。
- 用量维护定时任务统一管理生命周期，关停时等待已启动的明细清理及预留回收，保持原周期和额度规则。
- 过期额度回收逐条隔离失败，避免已删除记录或单次事务异常阻塞同批其他预留；批次结束仍汇总报错，保留退款事务和幂等规则。
- 记忆整理的启动和定时查询失败会记录错误，后续周期继续重试，避免数据库暂时不可用导致未处理异常。
- 日志、记忆、图片和 Bot Run 清理器重复启动时不再产生遗留定时器，停止后可重新启动；应用关闭时同步停止 Bot Run 清理调度。
- 自动清理过期图片时，权限或存储故障会保留文件引用供后续重试，避免误记为已清理；其他记录仍继续处理。
- RSS 调度停止时取消尚未触发的首次抓取；重复启动不再遗留重复定时器，停止后重新启动使用新的首次抓取延迟。
- RSS 过期条目清理失败后在下一次正常轮询重试，不再误入一天的成功清理冷却；已成功清理时仍保留每日节流。
- RSS 定时摘要按集合隔离异常，单个集合失败不再中断同批其他到期集合；日志记录失败集合 ID，保留原有时间、冷却和触发规则。

### 备份与文件管理

- 面板单文件、批量删除及 AI 文件工具统一按解析后的路径保护注入文件，修复相对路径或重复分隔符绕过保护的问题；AI 工具不再误拦截其他目录中同名普通文件的删除。
- 初始化 Bot 文件模板时以独占创建保留已有文件，避免检查后并发创建的内容被默认模板覆盖；已有符号链接不写入，其他写入错误仍报告失败。
- AI 文件删除工具以目标文件删除结果为准，父目录清理失败不再误报文件删除失败；并发新增文件会保留。
- 文件预览、下载和 AI 读取工具按实际读取字节执行大小限制，避免文件在预检查后增长时绕过上限；保留原有超限提示，文本接口返回实际字节数。
- 文件列表跳过读取期间已消失的条目，避免单个文件不存在导致整个目录误显示为空；保留其他文件、目录排序和注入配置。
- 数据库备份改为流式导出，移除子进程额外的 512 MiB 输出缓存上限；导出或写盘失败时回收进程并清理部分归档，避免残留任务和无效文件。
- 已完成的备份不再因后续保留策略读取或清理查询失败而误报失败、生成重复失败记录；清理异常写入日志，远端上传错误仍保留在备份记录中。
- 保留策略清理单条旧备份失败时记录备份 ID 和错误，便于定位并重试；继续清理其他旧备份，新备份仍保持完成状态。
- 删除本地备份时，权限或文件系统错误会保留记录并停止后续删除，避免文件残留后失去重试入口；文件已不存在时仍可正常清理记录。
- 备份文件名前缀禁止路径分隔符和控制字符，创建、下载、删除统一拒绝越界或异常文件名；中文和空格前缀继续支持，下载响应保留 UTF-8 原文件名。
- WebDAV 上传与删除正确编码文件名中的 `#`、`?` 和百分号，保留已编码目录与查询参数，避免文件名被误作 URL 结构。
- WebDAV 备份上传、删除及连接测试会释放未使用的响应正文；上传失败时关闭本地文件流，避免连接和文件资源滞留。
- 备份下载在认证、查询期间断开后不再启动文件读取，下载中取消也会关闭文件句柄；与目录 ZIP 共用认证前的取消信号初始化，保留原有下载内容、文件名和长度。
- 目录 ZIP 下载取消或读取失败时关闭正在读取的文件，停止打开后续文件；认证或目录扫描阶段已断开的请求也不会在之后启动文件读取。扫描失败不会遗留已启动的读流，文件并发删除产生的错误由下载流接管。保留原有文件筛选、内容、时间和权限元数据。
- 文件编辑接口对 `null` 等无效 JSON 内容返回明确的 400，避免误报服务器异常；校验失败不会写入文件。
- 修复文件页中含 `%`、`#`、`?` 等字符的文件无法读取、下载、编辑或删除的问题；按 URL 路径组件只解码一次，保留字面的编码字符并拒绝编码分隔符。
- 修复文件页下载中文文件或中文目录 ZIP 时出现的 404／500，文件与备份下载共用支持 UTF-8 文件名的响应头构造。

### 邮件与飞书通知

- 邮件转发处理 IMAP 连接错误与断线，避免单个邮箱异常退出整个服务或让监控停在失效连接上；停止后，旧抓取或解析任务不能再发起新的转发。
- 首次邮件快照中断时重新建立快照，避免把尚未记录的历史邮件误当作新邮件发送；连接恢复时保留当前运行周期内已成功转发的去重记录。
- 积压的历史未读、过滤不匹配或禁用事件邮件不再阻塞后续新邮件；读取完成后再标记已读，避免 IMAP 流式抓取与标记命令互相等待。处理中收到的新邮件通知会合并补查。
- 邮件历史排除与可清理的发送缓存分离，修复初始未读超过 5,000 封后误转发历史邮件的问题；同一邮箱标识下重连保留基线，邮箱重建后重新建立基线，不自动补发历史邮件。
- 飞书 Webhook 的异常 JSON、响应读取失败或错误字段类型会返回明确的失败结果，避免测试消息出现未处理异常，或邮件转发绕过原有失败计数；客户端不会因此自动重发请求。

### Harness、Bridge 与编码集成

- Harness 调度器关停时停止推进未开始的排队请求，等待已进入会话创建流程的请求保存结果，避免提前关闭 Bot 与数据库；不自动取消或重建远端会话。
- 修复 Lody Bridge 密钥变化后仍复用旧凭据的问题：新客户端按实际密钥失效缓存，短缺密钥继续本地拒绝，不自动重发已有请求。
- 校验 Bridge 执行响应字段，避免格式异常被误判为确定失败或成功；保留未知结果处理及合法扩展字段兼容。
- Bridge 输出限制统一按 UTF-8 字节计算，修复中文和 emoji 按字符数检查时可能绕过客户端上限的问题，保持超限结果分类。
- 修复 Lody 命令输出与等待模式错误提示在 UTF-8 字符跨数据块时出现乱码的问题，保留输出上限和超时分类。
- 统一本地与 Bridge 等待模式的控制行长度校验，修复超长行因输出分块不同而被误识别为完成事件的问题。
- 修复 Bridge 守护进程监控在 CLI 启动失败时遗留超时定时器的问题，保持原有恢复周期。
- Bridge 认证拒绝和等待池拒绝响应也及时释放未使用正文，释放失败不覆盖原有错误分类或等待模式回退规则。
- Lody Bridge 执行接口及时关闭 HTTP 错误的未使用正文，保留未知执行结果判定，不因收尾失败自动重发请求。
- Pi 编码 worker 的空响应或非法 HTTP 状态不再触发服务未捕获异常；响应中途断开会及时返回失败。已接受的任务仍要求新的 worker 启动身份，不自动重发任务。
- 断开 GitHub App 连接后，旧令牌或连接状态刷新不能重新写入缓存，也不会被后续请求复用；保留已开始请求的原调用结果，不把缓存清理等同于远端操作撤销。

### 图片与媒体处理

- 腾讯转写查询返回业务限流时继续轮询原任务，不再提前判定转写失败；只重试已有任务查询，付费提交、配额错误及识别终态失败仍不自动重试。
- 旧版 PixAI 图片存储与清理校验本地文件路径，拒绝任务 ID 中的目录跳转或非法路径，避免越出生成目录；正常任务文件名保持不变。
- 旧版 PixAI 生成图片下载遇到 HTTP 错误时释放未使用的响应正文，保留同批其他图片下载和原有失败日志，不自动重试失败请求。
- yt-dlp 桥接退出时校验 UTF-8 解码尾部，避免完整结果后的不完整字节被忽略；正常分块字幕解码、超时和失败回退规则不变。
- 音频暂存即使遇到目标文件关闭失败，也会继续关闭源文件，避免异常路径遗留文件描述符。
- 通用图片下载及时关闭重定向和被拒绝的响应，避免错误状态、无效类型或超限声明的正文继续占用连接和带宽；正常图片下载与校验保持不变。
- 通用图片下载在 DNS 解析等待期间也能及时响应取消或超时；统一媒体 HTTP 与语音识别的取消等待逻辑，接住底层操作的迟到失败并清理监听。此行为只结束本地等待，不代表远端任务或系统 DNS 已停止。
- 云端转录成功后先保存结果，再清理签名音频；删除失败通过持久清理待办重试，不再把成功转录误报为失败。恢复中的供应商任务继续保留所需音频，旧 attempt 不清理新任务音频。

### 日志与内部结构

- 旧头像请求迟到失败时保留新档案的刷新间隔，避免档案重建并成功刷新后，下一条消息再次发起重复头像请求；当前失败请求的五分钟重试规则不变。
- 历史重复记忆清理按完整创建时间复核保留项，修复同毫秒内微秒时间与 ID 顺序相反时，预览可见但执行持续报冲突的问题；保留向量优先和原有加锁顺序。
- 记忆去重确认与编辑共用数据库单调递增版本，避免应用时钟回退或快速连续更新恢复旧编辑版本，保留内容与向量。
- 提示词记忆列表复用现有记忆检索的权限过滤，移除重复条件；用户与聊天隔离、有效期、排序和数量限制保持不变。
- Embedding 供应商响应逐请求校验数量、索引和维度；乱序结果按索引归位，无效结果按生成失败降级，避免 SDK 分批拼接造成文本与向量错配。保留全部省略索引的兼容响应，不新增自动重试。
