# v0.20.1 — 运行可靠性与架构维护（待发布）

> 待发布草稿：记录当前候选改动，版本号以正式发布为准，不代表已发布或已部署。

## 功能补齐

- **全局定时群总结生效**：按 Bot 总结时区的设定时间，为未设逐群配置且近 24 小时内至少有 5 条符合角色过滤消息的已知群执行总结（排除私聊、频道、退群与迁移旧群）。逐群配置（含关闭）仍优先。
- 全局调度通过独立持久记录共享 23 小时冷却，跨重启与多实例去重，失败不自动补发，关停时等待已接纳任务完成。

## 修复

### Bot 交互、权限与模型能力

- 系统提示注入文件改为逐项容错，单个文件不可读不再清空其余内容，且不缓存不完整结果，文件恢复后下次自动重读。
- AI 选择按钮校验原聊天、原消息和选项索引，拒绝跨消息或非法回调且不消耗原选择。
- 定时器取消按钮复核点击者管理员身份；AI 取消工具限定当前聊天（跨聊天管理仍用 `/timers`），并等待数据库持久化成功后再报成功，避免与触发竞态。
- 定时群总结按聊天隔离配置读取与执行异常，单群失败不阻断同批其他群。
- 修复模型能力目录解析层级与同名回退，图片能力优先依据输入模态；HTTP 错误或空目录及时释放响应体并保留上次有效缓存。
- Telegram 头像下载按分块执行 5 MB 上限，超限或报错立即中止，防止低报 `Content-Length` 撑爆内存。
- Bot 关闭时不再触发已登记但尚未执行的管理员确认回调，并统一 AI 任务与管理员动作的限时收尾。

### MCP 连接与授权

- 通用 MCP 连接失败按指数退避最多自动重试 10 次，握手与发现限时 30 秒；停用或删除后，迟到连接不会重新激活服务。
- MCP 请求取消或超时区分未发送、明确失败与结果未知；若写操作可能已执行，本轮对话停止向该服务自动发起后续写入（允许只读核对），并保留脱敏远端错误。
- 图片 MCP 断开或重新授权后，旧 OAuth 回调与令牌刷新不能再回写凭据或覆盖新状态。
- MCP 配置变更引起的延迟重启绑定当前实例并合并连续修改，停止、显式重启或关停时及时收尾。

> 以上通用 MCP 规则仅用于面板添加的服务；取消不代表远端已回滚，结果未知时需人工核对。

### 正常关停与后台维护

- Bot Run 后台事件或终态写入失败改由入口捕获并写脱敏日志，不再因未处理拒绝导致进程退出。
- 修复 Bot Run 取消竞态：已完成或已删除的运行不再被迟到取消覆盖或误报成功；取消检查改用轻量状态查询。
- 日志与 Bot Run 实时流在认证等待或连接建立后断开时立即中止查询与推送，不再滞留后台读取。
- `SIGINT` 与 `SIGTERM` 合并为同一次关停流程；单项清理失败仍继续清理其余资源，全部收尾后记录脱敏日志并以非零码退出。
- 定时提醒、插件、群聊总结、RSS、图片生成（含管理员删除）、记忆整合及各类定期清理任务均完善关停等待：停止接纳新任务，等待在途查询、模型调用、投递与持久化完成后再关闭数据库与依赖。
- 清理器与调度器重复启动不再遗留定时器；过期额度回收、RSS 定时摘要、过期图片清理与记忆整理均按单条/单集合隔离异常，存储或清理失败时保留记录待下次重试，RSS 清理失败不再误入 24 小时冷却。

### 备份与文件管理

- 面板单文件/批量删除及 AI 文件工具统一按解析后路径保护注入文件，修复相对路径或重复分隔符绕过，同时避免误拦截其他目录的同名文件。
- Bot 模板初始化改用独占创建，防止覆盖并发写入的新文件且不写入符号链接；AI 删除工具以目标删除结果为准，不受父目录清理失败影响。
- 文件预览、下载与 AI 读取按实际读取字节执行大小限制；文件列表跳过读取期间消失的条目，避免整目录显示为空。
- 文件编辑接口对 `null` 等无效 JSON 返回明确 400；修复文件名含 `%`、`#`、`?` 或中文字符时的读取、编辑、删除与 ZIP 下载 404/500 问题。
- 数据库备份改用流式导出，移除 512 MiB 输出缓存上限，失败时回收子进程并清理残余文件；保留策略清理异常不再把已完成备份误标为失败，本地删除遇存储错误时保留记录供重试。
- 备份前缀禁止路径分隔符与控制字符；WebDAV 正确编码文件名中的 `#`、`?`、`%` 并及时释放响应体与文件流。
- 备份与目录 ZIP 下载在认证、扫描或传输中断时立即关闭文件句柄并停止打开后续文件。

### 邮件与飞书通知

- 邮件转发补齐 IMAP 断线与错误处理，防止单邮箱异常拖垮服务；停止后旧任务不再发起转发。
- 首次快照中断时重新建立快照，避免误发历史邮件；分离历史基线与发送缓存，解决初始未读超 5,000 封时误发旧邮件的问题。
- 积压未读与不匹配邮件不再阻塞新邮件；改为读取完成后再标记已读，避免 IMAP 流式抓取死锁。
- 飞书 Webhook 异常 JSON 或错误字段返回明确失败，不再抛出未处理异常或绕过失败计数。

### Harness、Bridge 与编码集成

- Harness 关停时停止推进新排队请求，等待已在创建会话中的请求落库。
- 修复 Lody Bridge 密钥变更后复用旧缓存的问题；校验执行响应字段，避免格式异常误判结果。
- Bridge 输出上限改按 UTF-8 字节计算，修复跨块 UTF-8 乱码，并统一本地与 Bridge 等待模式的控制行长度校验。
- 修复 Bridge 守护进程启动失败时遗留超时定时器；认证、等待池及执行接口的 HTTP 错误响应均及时释放正文。
- Pi 编码 worker 空响应、非法状态或中途断开及时返回失败，不再触发未捕获异常；断开 GitHub App 后旧令牌与状态刷新不再回写缓存。

### 图片与媒体处理

- 腾讯转写轮询遇业务限流时继续重试原任务（不自动重试付费提交或终态失败）。
- 旧版 PixAI 校验本地路径防目录跳转，HTTP 错误及时释放响应体；yt-dlp 退出时校验 UTF-8 尾部字节；音频暂存确保异常时也关闭源文件。
- 通用图片下载及时关闭重定向和被拒响应，并支持在 DNS 解析等待期间响应取消/超时。
- 云端转录改为先保存结果再清理签名音频，删除失败入持久待办重试，避免成功转录被误报失败。

### 日志与内部结构

- 修复旧头像请求迟到失败破坏新档案刷新间隔的问题。
- 记忆去重与编辑共用数据库单调递增版本，修复历史重复清理在微秒级时间与 ID 逆序时的持续冲突；提示词记忆列表复用既有权限过滤。
- Embedding 响应逐批校验数量、索引与维度，乱序归位、异常降级；群聊消息更新识别内容时清除旧向量并按完整内容校验写入。
- 历史 Embedding 回填改用固定 ID 上界与游标推进，失败不卡死同批，单批设 5 分钟上限，仅补向量时保留编辑版本与排序。
- 收敛转写客户端、音频存储、视频缓存、Bot 生命周期队列及运行中任务登记的内部冗余实现；分离共享文件常量与 Node 路径工具，消除面板构建警告。
- 全局未捕获异常与未处理拒绝在输出前脱敏并确保以退出码 1 结束；结构化诊断与工具日志在截断前完成密钥脱敏，正确摘要二进制对象，修复含空格或转义引号的凭据脱敏不完整问题。

## 使用与升级

- **数据库迁移**：新增迁移 `0069_hard_harpoon.sql`（全局总结执行记录表，不影响已有逐群配置），启动前需完成迁移。
- **注意：全局定时总结将开始生效。** 升级前请检查各 Bot 的总结开关、时间与时区；不希望自动发送请先关闭总结或清空全局时间，详见[全局定时总结](/docs/guides/automation#全局定时总结)。
- **密钥与备份**：所有环境均需显式配置 `ENCRYPTION_KEY`，升级与恢复须保留原密钥并同时备份数据库与文件卷，详见[备份与升级](/docs/self-hosting/backup-upgrade)。新增的部署验证脚本支持指定旧版 Git SHA 离线验证升级与恢复。
- **备份前缀与 WebDAV**：备份前缀不能含路径分隔符或控制字符，已有不合规配置需先修改；旧 WebDAV 文件名含 `#`、`?`、`%` 时请核对远端实际对象名，本次不自动重命名或补删。
- 公开指南已补充 Bridge 故障排查及各后台服务的正常关停等待范围。
