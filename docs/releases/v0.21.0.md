# v0.21.0 — 插件、生图与自动化更新

本版汇总 v0.19.1 以来的全部功能与修复（含此前 v0.20.0 阶段记录与 v0.20.1 候选内容）；升级请以本页为准。

## 插件与媒体

- **网页插件市场**：按 Bot 安装、配置、启停与测试内置或可信第三方插件，支持固定提交 SHA 与回滚。凭据加密存储且不回显；第三方插件具有宿主进程权限，安装前需确认信任。
- **统一检索**：新增 `search` 与 `read_reference`，先返回摘要再按权限读取正文，不会隐式下载、转录或发消息。
- **内置媒体插件**：Bilibili 与网易云音乐支持网页扫码登录；Bilibili 支持元数据、分 P、字幕与受限下载，网易云支持歌曲/专辑/歌单与歌词，并补齐 yt-dlp 字幕提取与扫码兼容修复。
- **后台 ASR**：补齐共享 ASR 配置、腾讯转写与逐任务管理员确认；支持状态查询、取消与供应商任务恢复，改善长任务、限流轮询、字幕摘要及清理失败处理，不会在结果未知时自动重提交付费任务。

使用说明：[插件管理](/docs/guides/plugins)、[统一检索](/docs/guides/search)。

## 生图与图片投递

- GPT、Gemini 与 PixAI 可分别连接，按动漫/通用用途设置默认供应商与预设；单次指定供应商不改默认配置。
- GPT / Gemini 当前仅支持文生图（不含参考图、负面提示词与 seed）；未连接的供应商不会被静默替换，原有通用后端配置继续兼容。
- 生图任务记录恢复信息、连接快照与投递回执，明确区分生成完成、投递成功与结果未知，避免误判或重复发送。
- 恢复并补齐出站图片 NSFW 检查，批量相册与单图保持一致的逐图剧透策略。

使用说明：[生图配置](/docs/self-hosting/configuration)、[生成记录](/docs/guides/generation-records)。

## 自动化、GitHub 与运行诊断

- **全局定时群总结生效**：按 Bot 设定的时间与时区为符合条件的已知群自动总结，逐群配置（含关闭）优先；执行记录持久化并跨实例共享冷却，失败不自动补发。
- **GitHub Issue 确认持久化**：待确认提案不再仅存临时会话，支持并发安全领取、授权校验与结果核对。
- **聊天内运行诊断**：Bot 管理员可在当前聊天只读查询运行状态、有效配置、请求链路、近期错误与脱敏事件，全程审计。修复诊断空参数与并发审计排队，调整工具执行预算与模型流超时处理。

使用说明：[自动化](/docs/guides/automation)、[运行诊断](/docs/reference/runtime-diagnostics)。

## 可靠性与维护

- MCP 连接失败按上限指数退避重试；停用、断连或重授权后，旧连接与令牌不再覆盖新状态；写操作结果未知时停止同轮后续写入。
- 定时器、群总结、RSS、生图、插件、记忆与用量维护补齐正常关停等待，减少数据库先关闭、迟到回调与未处理拒绝引发的异常。
- Bot Run 已完成状态不被旧取消请求覆盖；实时流断开后停止迟到推送。
- 修复 Embedding 响应校验、回填推进与旧向量覆盖；记忆去重改用数据库单调版本。
- 加强备份路径、WebDAV 文件名、媒体下载上限与取消处理；改进日志与诊断中的凭据脱敏和二进制摘要。
- 完善 IMAP、飞书通知、Lody Bridge、Harness 及编码 worker 的异常、取消与资源释放。

更细的修复记录见 [v0.20.1 候选记录](/docs/changelog/v0.20.1)。

## 升级注意事项

1. **数据库迁移**：从 v0.19.1 升级需执行 `0058`–`0069` 共 12 个迁移（涵盖插件、媒体转录/下载、图片供应商及全局总结记录）。升级前请备份数据库、文件卷与密钥，保持 `ENCRYPTION_KEY`、Compose 项目名和持久卷不变；回退需配套备份。
2. **全局定时总结将生效**：升级前请检查 Bot 的总结开关、时间、时区与逐群配置；不想自动发送请关闭总结或清空全局时间。
3. **可选媒体处理**：需启用 `media` profile 并配置独立 `MEDIA_WORKER_SECRET`；Cookie、ASR 凭据、外传许可与预算按 Bot 配置。
4. **GPT / Gemini 生图**：需分别配置 `OPENAI_IMAGE_MCP_URL` / `GEMINI_IMAGE_MCP_URL` 并授权；更换默认供应商不影响旧任务连接。
5. **Dokploy 部署**：更新时保留数据库容器与持久卷，切勿通过 `down -v` 或重建卷排错；关闭会破坏 worker 隔离的 Isolated Deployment 设置。
6. **备份与 WebDAV**：先修正不合规的备份前缀；旧 WebDAV 文件名含 `#`、`?`、`%` 时请核对远端对象名，本版不自动重命名或补删。

详见[Docker 部署](/docs/self-hosting/docker)和[备份与升级](/docs/self-hosting/backup-upgrade)。健康检查版本字段继续使用完整 Git SHA。
