# v0.21.0 — 插件、生图与自动化更新

本版统一收录上一正式发行版 v0.19.1 之后的功能和修复，包括此前 v0.20.0 阶段记录与 v0.20.1 候选中的内容。升级请以本页为入口；旧版本页面保留其原始记录，不代表这些阶段已经分别发布。

## 插件与媒体

- 新增网页插件市场：按 Bot 安装、配置、启停和测试内置或可信第三方插件，支持固定提交版本及回滚。秘密加密保存，网页不回显。第三方插件具有宿主进程权限，安装前需要确认信任。
- 新增统一 `search` 与 `read_reference` 入口，先检索摘要，再按权限读取引用正文；检索不会隐式下载音频、启动转录或发送消息。
- Bilibili 与网易云音乐插件支持扫码登录。Bilibili 支持视频信息、分 P、字幕读取及受限视频下载；网易云支持歌曲、专辑、歌单与歌词读取。修复二维码登录兼容问题，并补充 yt-dlp 字幕提取路径。
- 补齐共享 ASR 服务配置、腾讯转写与逐任务管理员确认。转录支持状态查询、取消和供应商任务恢复；长任务、限流查询、字幕摘要和成功后清理失败的处理更可靠。不会因结果未知自动重新提交付费任务。
- 转录时长、次数与预算使用管理员配置；视频下载保留大小、权限和投递边界。平台内容和账号权限仍受原服务限制。

使用说明：[插件管理](/docs/guides/plugins)、[统一检索](/docs/guides/search)。

## 生图与图片投递

- GPT、Gemini 与 PixAI 可分别连接，并按动漫图、通用图用途选择默认供应商与预设；面板根据供应商提供对应参数。明确指定供应商只覆盖当前请求，不修改持久默认值。
- GPT / Gemini 当前支持文生图；不接收参考图、负面提示词或 seed。未连接的供应商不会被静默替换，已有通用后端配置继续沿用旧路径，直到管理员明确切换。
- 图片任务保存恢复信息、供应商连接快照和投递回执，区分生成完成、投递成功与投递结果未知。恢复和后续选择会报告实际结果，避免把不确定状态当作成功或直接重复发送。
- 恢复并补齐出站图片 NSFW 检查；批量照片同样遵循逐图剧透决策，修复相册路径与单图行为不一致的问题。

使用说明：[生图配置](/docs/self-hosting/configuration)、[生成记录](/docs/guides/generation-records)。

## 自动化、GitHub 与运行诊断

- 全局定时群总结开始生效：按 Bot 的时间和时区为符合条件的已知群生成总结；逐群配置（包括关闭）优先。执行记录持久化，多个实例和重启共享冷却，失败不自动补发。
- GitHub Issue 创建确认持久化，待确认提案不再仅依赖临时会话；恢复领取隔离并发操作，保留明确授权与执行结果核对。
- 管理员可以在当前聊天查询 Bot 运行状态、有效配置、请求链路、近期错误和脱敏诊断事件。诊断只读、限定 Bot 与聊天，并记录审计。
- 修复诊断空参数和并发审计排队；插件与 MCP 工具执行预算更符合实际任务耗时，模型流异常及时结束，配置的模型流期限正确生效。

使用说明：[自动化](/docs/guides/automation)、[运行诊断](/docs/reference/runtime-diagnostics)。

## 可靠性与维护

- MCP 连接失败按上限退避重试；停用、断连和重新授权后，旧连接及令牌结果不会覆盖新状态。写请求结果未知时停止同轮后续写操作，允许只读核对。
- 定时器、群总结、RSS、生图、插件、记忆与用量维护补齐关停等待，降低数据库先关闭、迟到回调和未处理拒绝导致的异常。
- Bot Run 已完成状态不会被旧取消请求覆盖；实时连接断开后停止迟到查询结果推送，后台持久化错误被记录。
- 修复 Embedding 响应数量、索引和维度校验、回填推进与旧结果覆盖；记忆去重使用数据库版本，改善并发编辑及时间精度边界。
- 加强备份路径、WebDAV 文件名、媒体下载上限与取消处理；日志和诊断输出改进凭据脱敏，二进制内容只保留摘要。
- IMAP、飞书通知、Lody Bridge、Harness 与隔离编码 worker 补齐异常、取消和资源释放处理。

更细的修复与历史验证记录保留在 [v0.20.1 候选记录](/docs/changelog/v0.20.1)，本次发行不把其中的历史测试重新描述为当前候选的执行结果。

## 品牌与公开文档

- 采用 Hanori · 花织的经纬 Warp 标识，更新 favicon、应用图标和分享卡；网页标识支持轻微交互，并尊重减少动态效果设置。

## 升级注意事项

1. **从 v0.19.1 升级需执行 `0058`–`0069` 共 12 个增量迁移。** 内容覆盖插件、媒体转录、视频下载与清理、转录确认、图片供应商配置及全局总结执行记录。使用项目现有迁移流程，不跳号、不手改已部署迁移。
2. 升级前备份数据库、持久文件卷及密钥；保留原 `ENCRYPTION_KEY`、Compose 项目名和卷。迁移后的回退需要配套备份，不能只换回旧镜像。
3. **已有全局总结时间会开始生效。** 检查 Bot 总结开关、时间、时区及逐群配置；不希望自动发送时，升级前关闭总结或清空全局时间。
4. 可选媒体处理需启用 `media` profile 和独立 `MEDIA_WORKER_SECRET`。Cookie、ASR 凭据、外传许可与预算按 Bot 配置；任务确认不等于取消后可退款。
5. GPT / Gemini 生图需分别配置 `OPENAI_IMAGE_MCP_URL` / `GEMINI_IMAGE_MCP_URL` 并连接授权；改变默认供应商不改变旧任务连接，恢复旧任务可能需要保留原端点。
6. Dokploy 更新应用时保留数据库容器与持久卷；不要通过 `down -v`、重命名项目或重建数据卷解决更新问题。核对代理网络和 worker 隔离，关闭会破坏隔离的 Isolated Deployment 设置。
7. 不安全的备份前缀需先更正；旧 WebDAV 文件名含 `#`、`?` 或百分号时需核对远端对象，本版不自动重命名或猜测清理路径。

详见[Docker 部署](/docs/self-hosting/docker)和[备份与升级](/docs/self-hosting/backup-upgrade)。部署健康版本字段继续使用实际构建的完整 Git SHA。
