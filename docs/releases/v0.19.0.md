# v0.19.0 — 自动发现模型与显式配置

AI 设置支持自动拉取服务商的新模型，保留已有配置与手动移除记录；自托管配置移除内置默认加密密钥和硬编码图片 MCP 地址，并提供离线配置迁移工具。

## 新功能

- **模型自动发现**：进入「服务商与模型」页面自动拉取各已配置服务商的模型列表并加入草稿，也可点击「刷新模型」手动重试。
- **草稿保护**：保留已有模型的名称、能力、参数与默认项。单个服务商拉取失败不影响其余服务商；切换 Bot、离开页面或修改连接后，过期响应不会污染当前草稿。
- **删除记录**：按服务商记住手动删除或改名的模型 ID，后续自动发现不再重复加回；手动重新添加同名 ID 可恢复。目录与排除记录在点击「保存」后生效。
- **离线升级工具 `pnpm upgrade:env`**：从已核实的旧部署提交与原配置生成权限 `0600` 的新配置，保留原加密密钥并可选恢复历史图片 MCP 地址。全程不联网、不改原文件、不自动启用输出。

## 改进与修复

- 所有环境强制要求显式配置非空 `ENCRYPTION_KEY`，移除源码内置默认值，同步更新 `.env.example`、启动校验与升级文档。
- 图片 MCP 改为显式配置 `PIXAI_MCP_URL`，移除源码中的硬编码地址；未配置时自动关闭该集成。
- OAuth token、客户端注册、发现结果及回调状态绑定到完整 MCP 地址并在事务中校验，防止切换服务后误用旧授权。
- 公开源码导出纳入升级工具及相关测试，收紧清单哈希豁免范围并改用非私有测试数据。

## 使用与升级

- 无新增数据库迁移。保留原有数据库、文件卷、Lody 持久卷和 Compose 项目名。
- **升级前务必保留原 `ENCRYPTION_KEY`**，切勿重新生成，否则已有 Bot 与 API 凭据将无法解密。此前依赖内置默认值的旧实例，请先按[备份与升级](/docs/self-hosting/backup-upgrade)恢复并显式写入原值。
- 继续使用图片 MCP 的实例需显式填写完整 HTTPS 地址，升级后由 owner 重新授权一次（旧授权缺少地址绑定不会复用）。更换地址前请等待在途生图任务完成。
- 未配置发现路径或 API Key 的服务商仍支持手动添加模型。旧版本未记录删除历史，首次升级后如有不需要的自动发现模型，手动移除并保存一次即可。
- 保留 v0.18.0 的 Lody CLI 更新与模型刷新入口；远程执行机仍需在对应机器更新。

## 验证边界

已通过仓库例行检查及加密兼容、OAuth 地址隔离、模型草稿与过期响应测试。升级工具与 OAuth 使用隔离数据验证，未对真实用户凭据执行密钥轮换，也未进行付费生图或真实 Telegram WebView 验收。
