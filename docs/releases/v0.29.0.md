# v0.29.0 — 模型重试与备用模型

## 新增

- **模型恢复策略**：AI 设置新增全局重试与备用模型配置，并支持群聊独立覆盖。每轮额外重试预算 0–2 次（默认 1 次）；备用 Provider 与模型默认留空。
- **自动重试与回退**：可恢复的上游解析、限流、服务端与网络错误在预算内重试；预算耗尽后切换一次已配置的备用模型（同 Provider 同模型不循环回退）。
- **工具安全**：工具参数修复与请求重试共享整轮预算，修复阶段仅生成参数、不执行工具；已执行过的工具不会因恢复流程重复调用。
- **恢复日志**：单独记录有界且脱敏的状态码、错误码、请求 ID、Provider、模型与阶段信息，防止被大请求体挤掉。

## 使用与升级

在 Bot AI 设置中配置重试次数或从已配置目录选择备用模型，保存即生效；群聊未启用覆盖时继承全局设置，也可单独关闭备用模型。

无新增数据库迁移。升级不会改动主模型或自动启用备用模型；将重试次数设为 0 且留空备用模型即可关闭恢复。

## 边界与验证

权限、配置或确定性 schema 错误不盲目重试；取消或已输出内容后的流中断会直接终止，避免重复输出或工具副作用。重试与备用调用仍受原回合超时限制，且可能增加上游费用。

已通过可控 Provider 与浏览器测试覆盖重试、共享预算、取消、部分流、工具副作用及桌面/移动端配置保存；线上故障恢复效果需在实际部署后观察。
