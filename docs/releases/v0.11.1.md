# v0.11.1 — 生成记录读取与删除恢复

生成记录页面明确区分加载失败、没有记录和可能过期的内容；删除时显示操作状态，并提供只读核对，避免重复删除。

## 修复与改进

- 初次读取失败显示错误和重试，不再显示正常空态或未经确认的零条记录；同条件刷新失败保留旧内容并标明可能过期。
- 搜索、来源、分页和 Bot 切换隔离请求，晚到的旧响应不能覆盖当前条件的结果。
- 删除与核对期间禁用重复操作；删除结果未知和已删除但刷新失败分别说明，恢复动作只重新读取，不自动重发删除。
- 详情页区分读取失败与记录不存在，显示活动任务删除冲突；同一任务进行中的删除在列表和详情之间共用请求。
- 重试或核对成功后将键盘焦点移到标题，核对失败时留在操作提示，手机上也能直接看到恢复入口。
- 新增生成记录使用指南，并同步管理面板和素材库的文档入口。

## 使用与升级

从 v0.11.0 升级无需数据库迁移或新增配置。搜索字段、来源兼容、生成任务生命周期及服务端权限规则保持原有契约。GitHub Release 与文档构建不代表生产实例已经部署。

## 验证范围

桌面1440×900、手机390×844的中英文生产预览覆盖读取失败、旧响应隔离、未知删除、成功后刷新失败、活动冲突、浏览器返回与焦点恢复。检查使用合成API夹具，没有访问或删除真实生成记录，也没有调用模型或发送Telegram消息。
