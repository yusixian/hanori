# v0.11.1 — 生成记录读取与删除恢复

明确区分生成记录页的加载失败、空列表与过期内容，并在删除异常时提供只读核对，防止重复删除。

## 修复与改进

- **区分失败与空态**：首次读取失败展示错误与重试，不再误显空列表或零条记录；同条件刷新失败保留旧数据并标明可能过期。
- **隔离旧请求**：搜索、来源、分页和切 Bot 均丢弃迟到响应，避免旧结果覆盖当前视图。
- **可核对的删除流程**：删除与核对期间禁用重复点击；分别提示「删除结果未知」与「已删除但刷新失败」，恢复操作只重新拉取，不重发删除。
- **详情页与并发去重**：区分读取失败与记录不存在，提示活动任务删除冲突；同一任务进行中的删除在列表与详情间复用请求。
- **焦点与移动端体验**：重试或核对成功后焦点移至标题，核对失败时停留在操作提示，手机端直接可见恢复入口。
- **文档补充**：新增「生成记录」使用指南，并补充管理面板与素材库的跳转入口。

## 使用与升级

- 无需数据库迁移或新增配置；搜索字段、来源兼容、生成任务生命周期及权限规则不变。
- 文档站需随应用重新构建部署。

## 验证范围

已通过 13 项浏览器回归、桌面／移动端中英文模拟 API 预览、类型／静态检查、Panel 构建与公开文档检查，完整门禁见对应提交 CI。未涉及真实生成记录删除、模型调用或生产故障恢复。
