# v0.17.0 — 一键让停下的会话继续

Dev Harness 发现 Lody 会话停下却还没有交付 PR 时，提醒上新增「继续」按钮：点一下即可让会话接着完成任务，不必再手动回复。

## 新功能

- 「⏸ 会话已停下」提醒带有「▶️ 继续」按钮。点击后替你发送一句继续完成任务的指令，流程与回复这条提醒相同：先写进 GitHub 评论，再发给会话；发送后按钮消失，避免重复发送。会话已恢复或已结束时，按钮会提示当前状态；想提具体要求仍可直接回复提醒。

## 改进

- Bot 没有 AI 服务商或「AI 回复」已停用时，话题里的普通消息会明确回复「话题助手未启用」和开启方式，不再只显示一段命令说明。

## 使用与升级

- 无配置或数据库迁移。仅影响 Dev Harness 话题群，其他 Bot 与群聊不变。

## 验证边界

单元测试、类型检查和格式检查已通过。「继续」按钮与新的提示文案尚未在真实 Telegram 与 Lody 会话上验收。
