# v0.17.0 — 一键让停下的会话继续

Dev Harness 检测到 Lody 会话停下且未交付 PR 时，提醒卡片新增「继续」按钮，点一下即可让会话接着跑，不用手动回复。

## 新功能

- **一键继续**：「⏸ 会话已停下」提醒新增「▶️ 继续」按钮。点击后自动发出继续指令，流程与手动回复一致（先写 GitHub 评论再转给会话），发送后移除按钮防重复；会话已恢复或结束时提示当前状态，需要补充具体要求仍可直接回复提醒。

## 改进

- Bot 未配置 AI 服务商或停用「AI 回复」时，话题里的普通消息改为明确提示「话题助手未启用」及开启路径，不再只回一段命令说明。

## 使用与升级

- 无需配置或数据库迁移，仅影响 Dev Harness 话题群，其余 Bot 与群聊不变。

## 验证边界

单测、类型与格式检查已通过；「继续」按钮与新提示文案尚未在真实 Telegram 与 Lody 会话上验收。
