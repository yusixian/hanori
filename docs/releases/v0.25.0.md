# v0.25.0 — 定时任务手动运行与协议兼容

涵盖 v0.24.0 之后的全部变更，修复 #192 的模型协议兼容问题，并补齐已批准任务的手动运行与状态查看。

## 功能与修复

- **立即运行一次**：已批准任务支持手动触发，复用执行锁且不影响既定周期、下次运行时间与失败计数；待批准版本仍单独试跑与确认。
- **侧栏与详情优化**：Bot 侧栏可直达定时任务；列表展示近期结果与失败原因，详情页每 3 秒自动刷新，时间按计划时区显示，并记录手动运行类型与 Telegram 消息回执。
- **模型协议回退**：修复任务 Agent 未传递实际模型配置的问题。遇到上游 HTTP 400 明确拒绝 Chat Completions 推理 + 工具组合时，在单次模型请求层切换至同服务商 Responses 接口并保留已完成工具结果，不重跑整轮或静默关闭推理。
- **预算与边界**：不臆测转换供应商专属 thinking 预算，无法映射的显式参数直接报错；非协议兼容错误不触发切换。

## 升级与兼容

- 新增数据库迁移 `0075`，为执行记录补充 `manual` 与 `message_ids` 字段（保留原有 `trial` 语义，无回执的历史记录显示未记录）。
- 如需回退旧版程序，请等待所有手动运行结束，以免旧版重启恢复逻辑将其误判为周期任务；新增字段可保留。

## 验证边界

已通过本地合成 HTTP/SDK 回归、隔离 PostgreSQL 迁移与并发测试及浏览器测试；真实群聊投递需发布后单独验收。
