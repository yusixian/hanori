# v0.25.0 — 定时任务手动运行与协议兼容

本说明覆盖 v0.24.0 到本版本候选的全部变更，修复 #192 的模型接口故障，并完善已批准任务的手动运行与状态观察。发布、生产部署和真实群聊投递分别核验。

## 功能与修复

- 已批准任务新增“立即运行一次”，共用执行锁，保留周期、下次执行和周期失败计数；待批准版本仍单独试跑与确认。
- Bot 侧栏可直达自己的定时任务。列表展示最近失败/结果，执行详情每 3 秒刷新，时间明确使用计划时区；记录手动类型和 Telegram 消息回执。
- 修正任务 Agent 未传递实际模型设置的问题。针对上游明确拒绝 Chat Completions 推理工具组合的 HTTP 400，在单个模型请求层切换到同服务商 Responses，保留已完成工具结果；不重跑整轮任务或静默关闭推理。
- 供应商专属 thinking 预算不臆测转换；不可映射的显式设置仍明确失败。非兼容性错误不触发协议切换。

## 升级与兼容

升级需执行新增迁移 0075，为历史记录增加 manual 和 message_ids，旧 trial 语义保留。历史记录没有 Telegram 回执时显示未记录，不补造消息 ID。

回退至旧程序前，应等待所有手动运行结束。旧版本不认识手动运行标记，其重启恢复逻辑可能把未结束的手动运行当作周期执行处理。新增数据库字段可保留，无需删除运行记录。

## 验证边界

本地合成 HTTP/SDK 回归和隔离 PostgreSQL 验证协议、并发及迁移；浏览器截图使用合成数据。真实群聊投递由发布后的独立验收确认，不能用这些测试替代。
