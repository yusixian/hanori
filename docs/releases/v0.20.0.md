# v0.20.0 — 插件市场、统一检索与 Bot 运行诊断

新增网页插件市场和统一检索入口，支持按 Bot 配置可信插件及可选的 Bilibili 后台音频转录；Bot 管理员可在聊天中直接排查“上一条消息为何没有回复”。

## 新功能

### 插件市场与统一检索

- **插件市场**：所有者和管理员可在网页安装内置插件或可信第三方插件，按 Bot 配置、启停与测试。第三方源固定到公开 GitHub 仓库的 40 位完整提交 SHA，支持更新与回滚；发布包须预构建，服务端不执行依赖安装或构建脚本。插件运行在宿主进程内，并非沙箱，安装前需明确确认信任。
- **凭据与会话**：Cookie、Token、API Key 等密钥按 Bot 加密存储，网页不回显明文。配置变更后需重新审核保存；停用、更新或卸载会取消旧会话，卸载保留加密配置草稿。
- **扫码登录**：Bilibili 和网易云音乐支持网页扫码登录，确认并校验后自动加密保存 Cookie（第三方插件也可接入统一扫码接口）。写入开始前可取消、过期可重试；写入启动后关闭窗口不会撤销，结果不明时刷新配置核对。登录不自动启用插件，也不提供 Cookie 自动续期。
- **统一检索**：`search` 聚合已有来源并返回有界摘要，再由 `read_reference` 按需读取正文。引用限定当前回复或委派任务，遵守原有权限边界，不会隐式发消息、写资产、下载音频或启动转录。该功能默认开启，可在 AI 设置中关闭以恢复独立搜索工具（已启用插件的检索仍走统一入口）。新增插件开发契约与预构建示例。

### 媒体读取与后台转录

- **内置媒体插件**：Bilibili 支持链接查询、分 P 元数据与平台字幕；网易云音乐支持歌曲、专辑、歌单元数据及原文/翻译/罗马音歌词。正文支持分页和关键词检索，区分不可用与截断；不提供付费、DRM 或权限绕过。
- **可选 Bilibili ASR**：默认关闭。仅当管理员明确请求，且已配置有效 Cookie、音频外传许可、单一 ASR 服务及每用户预算，并确认无平台字幕时才创建后台任务。支持进度查询、取消、有限恢复与网页管理；转码在无网络独立 worker 内执行（不构成插件沙箱，也不会自动切换供应商/模型）。
- **配额与保留**：时长、每日任务数与预算可在网页自由配置，取消固定上限，但仍受单文件体积与处理超时限制，暂不支持长音频自动分段。转录正文保留 24 小时，完成通知仅含任务 ID 与状态；网页分页上限 40 条/4,000 字符，SRT/VTT 导出需先开启开关并逐任务确认权限。配置变更会撤销旧结果的读取资格。

### 聊天内运行诊断

- 新增 5 个只读 AI 诊断工具，区分排队、模型超时、工具失败、空回复与 Telegram 投递失败，支持回查自己的上一条消息。
- 严格限定当前 Bot 与当前聊天，仅真实 Telegram 消息中的 Bot 管理员可用；输出走白名单，不暴露凭据、完整提示词或原始消息正文。
- 每次查询（含拒绝与未命中）均写审计日志，受频控、分页与响应大小限制；审计写入失败则拒绝返回诊断数据。

## 修复

- 运行状态与有效配置工具移除无用筛选参数；链路、日志和错误查询兼容 `null` 及空白 ID，避免空 `toolCallId` 触发 `invalid_request`。
- 五工具并发调用时，超出 4 个审计写入槽位的请求进入有界等待队列（与写入共享 1 秒超时），避免数据库正常时误报 `Diagnostic audit unavailable`。
- 稳定共享 CI runner 上的子进程测试，减少并发竞争导致的偶发失败。

## 使用与升级

- **数据库迁移**：新增 7 个迁移（`0058`–`0064`），涵盖插件配置、安装记录、转录任务、清理状态、费用精度及解除固定时长约束（已部署插件市场的实例仍需执行 `0064`）。升级前请备份数据库和持久卷，保持原 `ENCRYPTION_KEY` 不变。
- **可选音频转录**：启用 Compose `media` profile 并配置独立 `MEDIA_WORKER_SECRET`（同时使用编码 worker 时设 `COMPOSE_PROFILES=coding,media`）。Cookie、ASR 密钥、服务地址、模型、外传许可与预算均在网页按 Bot 配置。
- **Dokploy 部署**：关闭 **Advanced → Enable Isolated Deployment**，防止破坏 worker 网络隔离；仅让 app 接入代理网络并设置对应的 `TRAEFIK_DOCKER_NETWORK`（默认 Domains 配置为 `dokploy-network`），部署前检查 Preview Compose 并保留原项目名与数据卷。
- **预算与数据边界**：转录预算按 Bot、用户和 UTC 日期保守预留完整时长，取消或失败不退还当天预留，也不撤销已计费的外部请求；进入转录阶段后中断不自动重试。Bot JSON 导出不含插件密钥和临时任务，但完整数据库备份包含密文与未过期正文，请妥善保管。
- **诊断链路**：升级重启后生效。请求链路常驻内存（默认保留 1 小时，最多 500 条），重启前的历史链路不会补录，不影响状态与配置查询。详见公开文档[插件管理](/docs/guides/plugins)、[统一检索](/docs/guides/search)与[AI 运行诊断](/docs/reference/runtime-diagnostics)。

## 验证边界

已通过仓库例行检查、生产构建及公开文档桌面/移动端浏览器验证。诊断工具并发、审计排队、权限隔离与参数边界均由回归与集成测试覆盖；插件、扫码竞态、检索权限、转录租约及无网络转码使用本地合成数据与隔离库验证。

两平台扫码已联调匿名建码与过期流程，但手机确认后的真实 Cookie 写入、音频下载、外部 ASR 端到端链路以及修复后的真实 Telegram 模型调用仍需升级后实测。GitHub Release 发布不会自动更新运行实例或静态文档站。
