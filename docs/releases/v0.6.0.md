# v0.6.0 — AI 设置保存状态与草稿保护

本版本让 AI 设置的保存结果、阻塞原因和离开行为更明确，减少重复操作和意外丢失输入。

## 更新内容

- **持续显示保存状态**：桌面和手机都能看到已保存、未保存、保存中及失败反馈；没有更改时禁用保存，并就近显示不可保存的原因。
- **撤销当前选择草稿**：试选服务商、模型或展示方式后，可以恢复已保存选择，保留其他配置草稿。
- **站内离开确认**：未保存时跳转到其他页面或主动退出登录，会先提示保留输入或放弃并离开；搜索设置和切换分类继续保留草稿。
- **保留失败恢复流程**：普通保存失败保留输入；配置已保存但应用失败时仍可重试；保持原有并发版本检查与选择同步行为。

详细操作见文档站「AI 对话与模型」中的「保存设置与保留草稿」。

## 升级说明

- 从 v0.5.1 升级无需数据库迁移或新增配置。
- 保持现有账号权限、AI 配置接口和 Mini App 入口规则。
- 草稿保留在当前页面，不会自动保存，也不会写入分享链接。
- 文档站随应用构建部署；GitHub Release 发布不代表生产实例已经更新。
