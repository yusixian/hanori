# v0.27.1 — Telegram 内容接收补漏

## 修复

- 补齐 Story、付费媒体、投票、联系人、位置、地点、骰子、游戏、清单和富文本消息的上下文接收，保留可用文字、链接与元数据，支持历史、后续追问和局部引用。
- 富文本附件、Story 和付费媒体使用未解析标识；不自动下载、购买或理解媒体。实况照片保留已有静态图片处理，动态部分标为未解析。
- 入口日志通过有限类型白名单区分上述内容，避免全部记作 `other`；不记录群聊内容或原始更新。服务事件仍不进入 AI 聊天。

## 升级注意事项

无需数据库迁移或配置变更。群聊权限、隐私设置和话题隔离保持不变。旧版本已经跳过、未入历史的消息无法通过本次升级补回；旧日志的 `other` 不能证明具体消息类型。

本地行为回归覆盖接收、持久化、当前请求、引用、追问、服务事件拒绝和日志内容隔离。验证使用合成 Telegram 更新和模型 mock，不等同于真实客户端与模型验收。没有向真实群发送测试消息；历史中已丢弃消息的原始类型无法从旧日志恢复。发布与线上健康状态分别核验。
