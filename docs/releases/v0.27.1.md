# v0.27.1 — Telegram 内容接收补漏

## 修复

- 补齐 Story、付费媒体、投票、联系人、位置、地点、骰子、游戏、清单和富文本消息的上下文接收，保留可用文字、链接与元数据，支持历史记录、追问与局部引用。
- 富文本附件、Story 和付费媒体标记为未解析，不自动下载、购买或理解媒体；实况照片继续按静态图处理，动态部分标为未解析。
- 入口日志通过类型白名单细分上述内容（不再全部记为 `other`），不记录聊天正文或原始更新；服务事件仍不进入 AI 对话。

## 升级注意事项

无新增数据库迁移或配置变更。旧版本已跳过的消息无法补回，旧日志中的 `other` 也无法还原原始类型。

已通过本地行为回归测试（合成更新与模型替身），真实客户端与模型表现需部署后验收。
