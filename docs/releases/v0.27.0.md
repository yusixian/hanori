# v0.27.0 — 媒体上下文与局部引用

## 新增与修复

- **保留媒体上下文**：视频、动图、音频、语音和视频笔记不再直接丢弃，改为保留说明文字、转发来源及未解析媒体占位，进入近期缓冲与持久历史供后续追问。
- **局部划词引用**：优先呈现 Telegram 划词选中的片段，明确区分引用内容与当前输入，当前回合、群聊历史与连续消息合并采用统一格式；缺少原消息时不猜作者。引用媒体说明文字时仍标注媒体未解析，不会自动下载或播放。
- **历史与话题修复**：修复旧式仅追加历史回调在触发回复时重复保存的问题；论坛群的近期缓冲与持久历史严格按话题隔离，不再把全群混合摘要注入单个话题。

## 升级注意事项

无新增数据库迁移。主话题只读取明确标记为主话题的记录，无标记的旧记录不猜归属；全群压缩摘要不含话题信息，论坛请求仅使用同话题尚存的原始记录。

媒体说明文字仍遵守既有触发、群聊准入与隐私规则，无文字媒体不代表已理解内容。已通过 handler 回归与隔离 PostgreSQL 话题筛选测试，真实客户端与模型表现需部署后验收。
