# v0.27.0 — 媒体上下文与局部引用

## 新增与修复

- 视频、动图、音频、语音和视频笔记不再直接作为不支持内容丢弃。保留说明文字、转发来源及诚实的未解析媒体占位，进入近期群聊上下文与已启用的持久历史，供后续追问读取。
- Telegram 局部划词引用优先呈现选中的片段，明确区分引用数据与当前输入。当前回合、群聊历史和连续消息合并使用同一格式；缺少原消息时不猜作者，无局部引用时沿用原行为。
- 局部引用媒体说明文字时，仍保留未解析媒体提示；不会自动下载、观看或收听媒体。现有图片、文档、贴纸处理保持不变。
- 修复旧式仅追加历史回调在触发回复时重复保存的问题。论坛的近期缓冲和持久历史按话题隔离，不将全群混合摘要注入单个话题。

## 升级注意事项

无新增数据库迁移。主话题只接收明确标注为主话题的记录；旧记录缺少话题标记时不猜归属。全群压缩摘要没有话题信息，因此论坛请求使用同话题仍保留的原始记录，已清理内容无法据此恢复。

说明文字仍遵守现有触发、群聊准入和隐私规则；没有文字的媒体不代表已完成媒体理解。验证覆盖真实 handler 的请求、缓冲、持久历史与连续消息路径，以及隔离 PostgreSQL 的话题筛选。合成 Telegram 更新与模型 mock 不替代真实客户端和模型验收；发布与线上健康状态分别核验。
