# v0.28.1 — 语录父预览与布局

## 修复

- 当 Telegram 嵌套回复缺少父指针时，`/q r` 从同 Bot、聊天与话题的本地记录补全父关系，保留当前正文与选段。
- 新 AI 文本回复持久化实际发送结果的父消息 ID（覆盖分片、等待消息编辑与指定消息回复）。
- 父关系未保存或内容不可读时明确提示，不再静默忽略 `r`（仍遵守隐私、保护内容与话题边界）。
- 加宽长句正文区并优化头像与字号比例；父预览以细竖线区分，同作者合并时保留各条预览。

## 使用与升级

回复目标消息发送 `/q r`（可组合如 `/q 3 r purple`）；编辑已发送的 `/q` 不会重新生成，需重发命令。

无新增数据库迁移，升级需同步重建 app 与 `quote-worker`。此前未记录父关系的旧消息无法追溯补全。

## 验证边界

已覆盖本地父关系补全、发送目标记录、作用域隔离、隐私限制、缺失提示及中文/Emoji 渲染样图测试；未向生产群发送测试消息。
