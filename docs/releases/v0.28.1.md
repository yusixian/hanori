# v0.28.1 — 语录父预览与布局

## 修复

- `/q r` 在 Telegram 嵌套回复没有提供父指针时，从同一 Bot、聊天和话题的本地记录补全关系，保留当前正文与选段。
- 新 AI 文本回复保存实际发送结果中的父消息 ID，覆盖分片、等待消息编辑和指定消息回复。
- 父关系未保存或父内容不可读取时给出提示，不再静默忽略 `r`。父消息仍受隐私、保护内容和话题边界约束。
- 加宽长句正文区域，调整头像与字号比例；父预览以细竖线区分，同作者合并保留各条预览。

## 使用与升级

回复目标消息发送 `/q r`；可组合 `/q 3 r purple`。编辑已经发送的 `/q` 命令不会重新生成贴纸，需要重新发送命令。

无需数据库迁移。升级需同步重建应用与 `quote-worker`；默认 Compose 构建包含两者。旧消息若从未保存父关系，无法追溯恢复，不会根据邻近消息猜测父内容。

## 验证边界

覆盖本地父关系补全、实际发送目标记录、同 Bot/chat/topic 隔离、隐私限制、缺失提示和真实中文/Emoji 渲染。样图使用虚构消息；未向生产群补发语录。历史截图对应消息的完整父关系未取得独立持久化证据，不宣称所有旧消息都能恢复。
