# v0.11.0 — 按 Chat ID 或参与者查找会话

对话页新增搜索，按完整 Chat ID 或历史参与者名称检索当前 Bot 的全部会话，不用逐页翻找。

## 功能与改进

- **搜索规则**：输入完整 Chat ID 或名称片段后回车／点击搜索；Chat ID 精确匹配（支持负数群聊 ID），名称忽略大小写，特殊字符按字面处理。
- **全量覆盖**：检索当前 Bot 的全部会话并按最近活动分页；命中某位参与者时，仍展示该会话完整的消息数、参与者、最近消息与摘要。
- **状态清晰**：已生效条件与输入草稿分开显示；改条件自动回第 1 页，清空恢复全量列表；无结果、加载失败和过期数据分别提示。
- **删除核对兼容**：搜索切换继续拦截旧请求；存在待核对删除时，切走搜索仍会核对原删除范围与当前页，核对只读不重删。
- **全量清空提示**：全部删除改标为 **清空此 Bot 的全部对话**，确认框明确提示会波及当前搜索结果外的记录。

## 使用与升级

- 名称取自已保存聊天记录中的历史显示名或当时记录的 username，不额外查群名、当前 username 或人物档案，也不搜消息正文；纯数字也会同时匹配名称片段。搜索条件仅留在当前页，刷新或切 Bot 后重置。
- 无需数据库迁移或新增配置；列表 API 新增可选 `search` 参数（去首尾空白后最长 100 字符），不传时保持原有分页行为。权限、保留规则与系统／工具消息开关不变。
- 文档站需随应用重新构建部署。

## 验证范围

已通过会话搜索与恢复浏览器回归、17 项列表路由测试、45 项会话存储回归及 3 项隔离 PostgreSQL 17 SQL 测试（含 25 条匹配分页、Bot 隔离、字面特殊字符与大整数边界；该 3 项需显式测试库配置，默认 CI 跳过），以及桌面／移动端模拟 API 与公开文档检查。未覆盖生产规模性能、真实 Telegram 会话或物理手机。
