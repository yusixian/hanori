# v0.7.0 — Bot 列表与管理入口

精简 Bot 列表与概览入口，补齐完整分页，并区分查询失败与空列表状态。

## 更新内容

- **紧凑的 Bot 列表**：集中展示名称、状态、运行时长与启停按钮，减少重复信息与手机端滚动。
- **完整分页与真实总数**：按创建顺序分页浏览全部 Bot，不再截断在前 100 项，总数以服务端返回为准。
- **区分失败与空态**：列表和概览请求失败时提示错误并提供重试；后台刷新失败保留现有内容并标出状态，不再误显「还没有 Bot」或「未找到」。
- **概览快捷入口**：按 Bot 平台提供 AI 设置、对话、编辑或日志等常用入口，手机端同样直达。

详见文档站「管理面板导航 — 浏览与管理 Bot」。

## 升级说明

- 无需数据库迁移或新增配置；权限、生命周期接口与平台边界不变。
- 导航搜索仅用于查页面，本版本未新增 Bot 名称搜索或状态筛选。
- 文档站需随应用重新构建部署。

## 验证范围

已验证分页与总数、加载／失败／空态、刷新失败恢复、平台快捷入口、桌面／移动端布局及公开文档，完整门禁由 CI 执行。浏览器测试使用模拟 API，未触发真实 Bot 启停、删除或生产数据。
