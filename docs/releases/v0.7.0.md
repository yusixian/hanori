# v0.7.0 — Bot 列表与管理入口

本版本缩短从列表找到 Bot、查看状态和进入常用页面的路径，并让查询失败与空数据有明确区别。

## 更新内容

- **更紧凑的 Bot 列表**：集中显示名称、状态、运行时长与启停操作，减少重复信息和手机滚动。
- **完整分页与准确总数**：按创建顺序分页浏览所有 Bot，不再固定停留在前 100 项；列表总数使用服务端结果。
- **明确的失败与重试**：列表和概览查询失败时显示错误及重试入口；后台刷新失败保留已有内容并提示状态，避免误显示“还没有 Bot”或“未找到”。
- **概览常用入口**：按 Bot 平台提供 AI 设置、对话、编辑或日志等适用链接，手机上也可直接进入。

操作说明见文档站「管理面板导航」中的「浏览与管理 Bot」。

## 升级说明

- 从 v0.6.0 升级无需数据库迁移或新增配置。
- 保持现有账号权限、Bot 生命周期接口与平台边界。
- 导航搜索用于查找页面；本版不新增 Bot 名称搜索或状态筛选。
- 文档站随应用构建部署；GitHub Release 发布不代表生产实例已更新。

## 验证范围

发布前验证列表分页与总数、加载/失败/空状态、刷新失败后恢复、平台快捷入口，以及桌面和手机布局。同步验证公开指南和版本页，完整仓库门禁由 CI 执行。浏览器使用模拟 API，不涉及真实 Bot 启停、删除或生产数据。
