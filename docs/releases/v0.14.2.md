# v0.14.2 — 手机日志更容易阅读

手机上的全局日志与 Bot 日志将级别和展开入口放在首行，让消息正文与关联信息使用卡片宽度，减少短行换行，方便排查错误。

## 改进

- 窄屏日志记录先显示级别和展开入口，消息与时间、关联信息显示在下方。
- 桌面布局、日志筛选、实时更新、展开详情和复制 JSON 的操作保持原有方式。

## 使用与升级

- 无配置或数据库迁移。更新面板后，从全局或 Bot 工作区的 **日志** 页面查看记录。
- 回滚到上一版本的应用构建即可；日志数据和服务端接口不变。

## 验证边界

桌面和手机浏览器检查使用合成日志与模拟 API。没有读取或删除生产日志，也没有执行生产部署。文档构建与 GitHub Release 不会自动更新运行中的实例。
