# 未发布 — 持久定时任务与管理员审批

本说明记录开发候选，尚未发布，不表示已经通过生产功能验收。

## 功能

- 群友用自然语言提案，Bot 展示完整计划卡；管理员确认创建、试跑、修改和取消，卡片绑定计划版本、消息和有效期。
- 一次性、固定间隔与指定时区的周/月/季日历调度持久化，不再有一天或七天的远期上限。月末取有效日期，夏令时缺失时间顺延、重复时间选第一次。
- 任务使用独立 Agent 配置，复用既有子代理；支持限定源聊天/话题的数据范围、发送目标和执行限制。
- 聊天及面板可管理任务和执行记录。重启后恢复调度，漏过多个周期只补最近一期；中断执行保留记录且不自动重放，避免重复副作用。
- 连续三次周期失败自动暂停；管理员可查看错误并恢复。任务配置补充对话不受普通接话冷却阻断。

## 升级与兼容

新增任务及执行记录数据库结构，需要运行随版本提供的数据库迁移。保留旧定时器及其管理入口，不自动将旧任务转换为新计划。

启用持久任务服务后，`set_timer` 改为生成待审批的一次性计划；创建工具返回不代表已经启用。新的周期或一次性任务通过计划卡批准后生效。

源话题数据依赖消息持久化中的真实话题标记，升级前缺少该标记的历史不会被推测为属于某个话题。配置默认值在执行时继承，执行记录保存当次实际配置。

## 验证边界

本地完整单元测试 4679 项通过（227 项跳过），Chromium 浏览器测试 490 项通过，公开文档桌面/移动端匿名访问测试 42 项通过；类型、lint、翻译与生产构建已验证。隔离 PostgreSQL 验证新增调度迁移、批准后重启补跑且不重复、中断记录恢复，以及 4 项隐私/话题历史范围隔离测试。本机缺少 pgvector，未在此环境验证完整历史迁移链。

真实 Telegram 投递和生产功能验收仍需单独核验；本地浏览器截图使用测试数据，不代表生产运行结果。
