# v0.15.0 — 长期记忆与对话摘要可维护

长期记忆支持更新、停用与来源核对，对话压缩摘要支持编辑当前版本并按预览分批清理旧版本。

## 新功能

- **长期记忆可维护**：Agent 可新增、更新和停用长期记忆；用户明确要求遗忘个人记忆时可删除对应记录。缺少来源字段的旧记忆不会靠猜测绑定到某个聊天。
- **后台自动整理**：AI 与记忆均开启时，后台按有界批次从已完成对话中提炼长期记忆；群聊共同经历与约定限定在该群，并保留参与者与来源证据。所有者与管理员可只读预览历史消息批次，也可在记忆页手动增删改或停用（暂不支持手动触发指定批次整理）。
- **记忆核对与去重**：记忆页展示类型、聊天范围、来源、有效期与停用状态；历史完全重复的记忆需先预览再逐批停用，不会自动合并语义相近条目。
- **摘要版本维护**：对话页支持将编辑后的当前摘要存为新版本、查看历史版本，并在预览保留范围后逐批清理旧摘要；压缩冲突会重读候选，不把失败压缩记作成功。

## 使用与升级

- 升级前请备份数据库并执行 `0052`、`0053` 迁移。既有记忆、消息与摘要保持可读，升级不会自动清理历史重复记忆或旧摘要。
- 隔离模式不会读取范围未知的旧个人记忆，也不会从正文推断聊天范围；普通原始消息到期不连带删除长期记忆，后者受有效期、停用与个人数据删除规则约束。
- `/privacy forget` 对共享群摘要的边界不变，无法从已形成的共享摘要中单人剔除；参与者关闭或隔离个人化后，相关自动群记忆停止召回，记录与来源证据留作核对。
- 摘要清理与重复记忆停用均需管理员预览并逐批确认；只读批次预览不调模型、不推进游标、不改数据。

详见[隐私、历史与记忆](/docs/guides/privacy-memory)。
