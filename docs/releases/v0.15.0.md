# v0.15.0 — 长期记忆与对话摘要可维护

Bot 的长期记忆现在可以更新、停用和核对来源；对话压缩摘要也可以编辑当前版本，并在预览后分批整理旧版本。

## 新功能

- Agent 可以新增、更新和停用长期记忆。明确要求遗忘个人记忆时，可删除对应记录；旧记忆不会因为缺少来源字段就被猜测为某个聊天的内容。
- 在 AI 与记忆功能均启用时，后台按有界批次从已完成的对话中整理长期记忆。多人群聊的共同经历和约定限定在该群聊，并保留参与者与来源证据。实例所有者和管理员可以只读预览历史消息批次，也可以在记忆页新增、编辑、停用或删除整理后的记忆；目前不能手动触发指定批次的整理。
- 记忆页可核对类型、聊天范围、来源、有效期和停用状态。历史完全重复的记忆需先预览、再逐批确认停用；不会自动合并措辞相近的内容。
- 对话页可将当前摘要的编辑保存为新版本，查看历史版本，并在预览保留范围后逐批清理旧摘要。压缩冲突会重新读取候选，避免将失败的压缩当作成功。

## 使用与升级

- 升级前备份数据库，并按常规流程应用 0052、0053 两个数据库迁移。既有记忆、消息历史和摘要仍可读取；升级不会自动执行历史重复记忆或旧摘要的批量清理。
- 隔离模式不会读取聊天范围未知的旧个人记忆，也不会从记忆正文推断范围。普通原始消息到期不会连带删除已提炼的长期记忆；长期记忆仍受有效期、停用与个人数据删除规则约束。
- `/privacy forget` 对共享群摘要的现有边界保持不变，不能从已形成的共享摘要中选择性删除一人的内容。参与者关闭或隔离个人化时，相关自动群记忆会停止召回，记录和来源证据保留供核对。
- 摘要清理与历史完全重复记忆整理都需要管理员预览和逐批确认。只读历史批次预览不会调用模型、推进整理游标或修改数据。

详细使用方式与权限见[隐私、历史与记忆](/docs/guides/privacy-memory)。

## 验证边界

相关服务、路由、数据库和面板行为经过聚焦测试与代码审查；合入主改版后的 main CI 已通过。版本候选提交仍需完成 CI 核对。本次开发没有对生产数据执行迁移或清理，没有向真实 Telegram 聊天发送消息，也没有部署或发布此版本。
