# v0.5.0 — 更快找到 AI 设置

为 AI 设置页加入搜索、精准定位与链接分享，不用再一层层展开翻找。

## 更新内容

- **设置搜索**：按名称或描述检索回复行为、记忆、工具、权限与群组下的设置项，支持中英文及键盘选择。
- **自动展开定位**：选中搜索结果后自动切换分类、展开目标项并将键盘焦点移至对应控件。
- **可分享的设置链接**：URL 记录当前分类与设置位置，复制链接、刷新或浏览器前进后退都能恢复；慢速加载完成后同样会自动定位。
- **移动端摘要**：小屏下折叠项直接展示当前开关、模式和数量摘要，方便快速巡检。

详见文档站「AI 对话与模型 — 查找和分享某个设置」。

## 升级说明

- 无需数据库迁移或新增配置。
- 原有分类链接继续有效，访问设置链接仍受登录与账号权限约束。
- 搜索与链接定位不触发自动保存，原有保存与应用流程不变。
- 文档站需随应用重新构建部署。

## 验证范围

已验证设置搜索、链接恢复、键盘焦点、桌面／移动端布局、类型、i18n、生产构建与公开文档，完整门禁由 CI 执行。浏览器测试使用模拟 API，未覆盖真实 Telegram 与生产环境。
