# v0.5.0 — 更快找到 AI 设置

本版本改进 AI 设置页的查找和浏览体验，减少逐个分类、逐项展开的操作。

## 更新内容

- **设置搜索**：按名称或描述查找回复行为、记忆、工具、权限与群组中的设置，支持中英文界面与键盘选择。
- **准确定位**：选择搜索结果后自动切换分类、展开目标并定位，键盘焦点跟随目标设置。
- **设置链接**：地址保留当前分类和设置位置，复制链接、刷新或前进后退后可恢复；慢速加载完成后也会定位到目标。
- **手机摘要**：折叠设置在小屏幕上显示已有的开关、模式和数量摘要，方便巡检。

详细操作见文档站「AI 对话与模型」中的「查找和分享某个设置」。

## 升级说明

- 从 v0.4.0 升级无需数据库迁移或新增配置。
- 已有分类链接继续可用；访问设置链接仍受原有登录和账号权限限制。
- 本轮保持现有保存和应用流程，查找或分享位置不会自动保存配置。
- 文档站随应用构建部署；GitHub Release 发布不代表生产实例已经更新。

## 验证范围

发布前验证设置搜索、链接恢复、键盘焦点、桌面和手机布局，以及相关类型、翻译、生产构建和公开文档；仓库完整门禁由 CI 执行。浏览器使用模拟 API，不代表真实 Telegram 或生产验证。
