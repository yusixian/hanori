# v0.5.1 — 日志筛选与清理反馈

修复历史日志与实时日志筛选不一致的问题，收紧筛选栏布局，明确清空范围与失败反馈。

## 更新内容

- **历史与实时筛选对齐**：群聊 ID 和关联 ID 正确传入历史查询，与实时日志条件一致；支持负群聊 ID，自动忽略搜索词与关联 ID 首尾空格。
- **更紧凑的筛选栏**：宽屏单行排布，窄屏自动换行，手机端占满全宽。
- **明确清理范围**：全局日志选中单个 Bot 后，清空确认框直接显示该 Bot 名称。
- **修正失败反馈**：清空请求被拒或网络异常时保留当前列表并提示错误，不再误报成功。

详见文档站「管理面板导航 — 检索和清理日志」。

## 升级说明

- 无需数据库迁移或新增配置；原有权限、保留期、导出与实时连接规则不变。
- 清空仍按所选 Bot 或全部 Bot 执行，不会只删除当前筛选条件命中的日志。
- 文档站需随应用重新构建部署。

## 验证范围

已验证历史查询、实时筛选、中文输入、清理确认与失败反馈、桌面／移动端布局、类型、i18n 与公开文档，完整门禁由 CI 执行。浏览器测试使用模拟 API，未涉及真实日志删除或生产 Bot。
