# v0.5.1 — 日志筛选与清理反馈

本版本修复日志筛选不一致的问题，并压缩筛选区域，让排查过程更连贯。

## 更新内容

- **筛选结果一致**：群聊 ID、关联 ID 正确传递给历史查询，历史记录与实时日志使用相同条件；支持负群聊 ID，忽略搜索和关联 ID 的首尾空格。
- **更紧凑的布局**：宽屏筛选项排列在一行，窄屏自动分栏，手机上使用完整宽度。
- **清理范围明确**：全局日志选择某个 Bot 后，清空确认会显示 Bot 名称。
- **失败反馈准确**：清空请求被拒绝或发生网络错误时保留当前列表并显示错误，不再误呈现清空成功。

详细操作见文档站「管理面板导航」中的「检索和清理日志」。

## 升级说明

- 从 v0.5.0 升级无需数据库迁移或新增配置。
- 保持原有日志权限、保留期、导出和实时连接规则。
- 清空操作仍按所选 Bot 或全部 Bot 执行，不按文本、级别、群聊 ID 或关联 ID 筛选结果删除。
- 文档站随应用构建部署；GitHub Release 发布不代表生产实例已经更新。

## 验证范围

发布前验证历史请求、实时筛选、中文输入、清理确认与失败反馈，以及桌面和手机布局、相关类型与翻译、公开文档。仓库完整门禁由 CI 执行。浏览器使用模拟 API，没有删除真实日志或连接生产 Bot。
