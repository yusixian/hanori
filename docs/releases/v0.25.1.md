# v0.25.1 — 修复干净环境声明构建

本版本在 v0.25.0 基础上修复生产镜像构建失败。v0.25.0 已发布，但首次自动部署在构建阶段失败，运行中的旧版本未被替换。

## 修复

- shared 的 JavaScript 打包与 TypeScript 声明生成分开执行，避免旧声明插件在类型模块加载超过 200 毫秒时提前读取尚未生成的声明文件。
- 保留声明产物与类型检查，增加受控慢加载回归；CI 在类型检查之前执行完整生产构建，覆盖干净环境。

## 升级与验证

从 v0.24.0 升级时包含 v0.25.0 的任务运行修复和新增迁移 0075，详见该版本说明。回退旧版本前等待手动运行结束，保留数据库记录。

发布、自动部署和真实任务投递分别验收；构建成功不能替代 Telegram 回执。
