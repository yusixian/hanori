# v0.25.1 — 修复干净环境声明构建

修复 v0.25.0 在干净环境中首次自动部署时生产镜像构建失败的问题。

## 修复

- 将 `shared` 的 JS 打包与 TypeScript 声明生成拆分执行，避免旧声明插件在类型模块加载超过 200ms 时提前读取尚未生成的 `.d.ts` 文件。
- 补充受控慢加载回归测试；CI 调整为在类型检查前先跑完整生产构建，覆盖干净构建环境。

从 v0.24.0 升级时包含 v0.25.0 的任务运行修复与迁移 `0075`（详见 v0.25.0 说明）；回退旧版前等待手动运行结束。真实任务投递需在部署后单独核验。
