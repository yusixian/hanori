# v0.24.0 — 提示词版本与回合快照

涵盖 v0.23.0 之后的全部变更，实现提示词版本管理（#195）。

## 功能

- **版本管理**：支持 Bot 提示词草稿编辑、保存版本、对比、启用/恢复、另存与删除；保存与启用分离，当前启用版本不可删除。
- **完整快照**：快照涵盖通用/群聊/系统提示词、文件正文及注入状态、Skills 正文/参考资源及启用状态，并支持新增不常驻注入的参考文件。
- **回合隔离**：每个执行回合锁定启动时的提示词版本；运行中的对话与续写不会中途读到新版文件或 Skills，定时任务同样固定版本。
- **版本对比与预览**：记录保存时的应用 SHA 与预览估算（不等于实际请求 token 用量），并支持在当前程序规则下对比两版。
- **边界清晰**：恢复版本不改动模型、凭据、工具权限或动态记忆；程序生成的工具规则始终来自当前应用。移除上下文中重复的长期记忆工具列表。

## 升级与兼容

升级需执行迁移 `0074_supreme_captain_flint.sql`（新增版本表与 Bot 当前版本指针）。未启用版本的 Bot 继续使用工作副本，无需迁移现有人格；启用版本不覆盖磁盘文件，可随时切回。如需回退旧版程序，请先切回工作副本。

## 验证边界

本地通过 lint、格式、类型、i18n、生产构建、单元测试（4,691 通过，231 跳过）、面板浏览器测试（491 通过）及公开文档浏览器测试（42 通过）。隔离 PostgreSQL 验证了 `0074` 迁移、版本恢复、Bot 隔离及启用/删除并发；因本机缺少 pgvector，未验证完整历史迁移链。线上 Bot 实际对话效果需部署后核验。
