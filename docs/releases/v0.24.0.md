# v0.24.0 — 提示词版本与回合快照

本说明覆盖 v0.23.0 到本版本候选的全部变更，实现 #195 的提示词版本管理。版本发布、生产部署和真实个人配置验证分别记录；版本准备提交不表示已上线。

## 功能

- 新增 Bot 提示词草稿、保存版本、比较、启用／恢复、另存和删除。保存与启用分离，当前启用版本不能删除。
- 快照保存通用／群聊／系统提示词、文件实际内容和注入状态、Skills 正文／参考资源和启用状态。可新增不常驻注入的参考文件。
- 每个实际执行回合固定提示词版本；新回合读取当前版本，运行中的聊天与继续对话不会中途读取新版文件或 Skills，定时任务的 Skills 同样固定。任务原有私有文件／记忆隔离保持不变。
- 版本记录保存时的应用 SHA 和预览，也可在当前程序规则下比较两版。预览估算不等于完整请求 token 用量。
- 恢复不改变模型、凭据、工具权限或动态记忆；程序生成的工具规则始终来自当前应用。
- 去除上下文中重复的长期记忆工具列表，保留完整操作规则及实际工具权限。

## 升级与兼容

升级需执行迁移 `0074_supreme_captain_flint.sql`，新增版本表和 Bot 当前版本指针。未启用版本的 Bot 继续使用工作副本，无需迁移现有人格内容。启用版本不会覆盖磁盘文件；可切回工作副本或历史版本。回退旧程序前应先切回工作副本，否则旧程序不认识版本指针。

## 验证边界

本地单元测试 4691 项通过（231 项跳过），Chromium 浏览器测试 491 项通过，公开文档桌面/移动端匿名访问测试 42 项通过；lint、格式、类型、翻译与生产构建已验证。隔离 PostgreSQL 通过 3 项测试，验证实际新增迁移、版本恢复、Bot 隔离和启用/删除并发。本机缺少 pgvector，未在此环境验证完整历史迁移链。

浏览器流程及截图使用合成配置；真实个人提示词内容不进入公开代码和文档。生产 Bot 的候选配置和聊天效果需单独核验，静态场景审查不等同于真实模型评估。
