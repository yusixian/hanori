# v0.19.1 — 授权期间保留 MCP 连接状态

修复图片 MCP 重新授权时，后台任务查询失败覆盖授权状态、导致 owner 回调被拒绝的问题。

## 修复

- owner 正在授权时，后台能力或结果查询失败不会再将连接改成错误状态；数据库条件写入保护仍在进行的授权。
- 非授权期间的连接诊断以及真正的 OAuth 回调失败仍正常报告，授权成功后清除旧错误。

## 使用与升级

- 无数据库迁移；保留现有环境变量、加密密钥和持久卷。
- 曾遇到授权回调失败的 owner，升级后可从「用量与生图」重新连接 MCP。权限与 v0.19.0 一致。

## 验证边界

回归测试复现授权期间的后台查询失败，并验证后续 owner 回调成功；同时覆盖非授权状态和真实回调失败。发布前执行仓库检查与文档浏览器验证，未执行付费生图。
