# v0.4.0 — 更清晰的工作区导航

重构管理面板侧栏结构与搜索能力，让 Bot 配置、内容管理和运维入口更顺手。

## 更新内容

- **按任务分组**：Bot 工作区改为按「常用」「内容与记忆」「自动化」「管理与诊断」归类，告别长菜单逐项翻找。
- **导航搜索**：按页面名称即时过滤入口，在 Bot 工作区内也能直接搜到全局管理页面并标明所属范围。
- **全局入口直达**：在 Bot 工作区即可展开全局管理，跳转用量、MCP、定时任务、数据与备份等页面。
- **更紧凑的侧栏**：收紧固定页头与页脚占比，保留文档、更新说明、语言、设置与退出入口。
- **键盘与移动端适配**：补齐当前页标识与抽屉焦点管理，兼顾桌面折叠与手机完整菜单。
- **文档补充**：新增「管理面板导航」指南，并补全角色库、人物绑定与提示词资产的操作教程。

详见文档站「管理面板导航」。

## 升级说明

- 无需数据库迁移，已有配置、路由地址与账号权限不变。
- 更新后刷新管理面板即可生效；线上文档站需随应用重新构建部署。

## 验证范围

已通过导航浏览器回归（测试数据）、桌面／移动端布局、类型、i18n、文档构建与公开版本页检查，完整门禁由 CI 执行。未覆盖真实 Telegram 与生产环境。
