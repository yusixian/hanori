# v0.4.0 — 更清晰的工作区导航

本版本改进管理面板的导航效率，让 Bot 设置、内容和运维入口更容易找到。

## 更新内容

- **按任务分组**：Bot 工作区按常用、内容与记忆、自动化、管理与诊断组织入口，减少在长菜单中逐项查找。
- **导航搜索**：输入页面名称即可筛选入口，在 Bot 内也能查找全局管理页面，并区分所属范围。
- **全局入口直达**：Bot 工作区可以直接展开全局管理，进入用量、MCP、定时任务、数据和备份等页面。
- **更紧凑的侧栏**：减少固定页头和页脚占用，保留文档、更新说明、语言、设置和退出登录入口。
- **键盘与手机导航**：补充当前页面标识和抽屉焦点行为，兼顾桌面折叠与手机完整菜单。
- **操作指南**：新增管理面板导航指南，并补充角色库、人物绑定与提示词资产的完整操作教程。

详细操作见文档站「管理面板导航」。

## 升级说明

- 从 v0.3.0 升级无需新增数据库迁移，已有配置、页面地址和账号权限保持不变。
- 更新应用后重新加载管理面板即可使用新导航。
- 文档站需随本版本构建部署，GitHub Release 发布不代表线上实例已经更新。

## 验证范围

发布前验证导航浏览器回归、桌面与手机界面、相关类型和翻译、文档构建与公开版本页；CI 运行仓库完整门禁。浏览器导航验证使用测试数据，不代表真实 Telegram 或生产部署验证。
