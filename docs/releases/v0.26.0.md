# v0.26.0 — 范围受限的总结工具与预览

## 新增

- 聊天 Agent 可调用 `summarize_chat`，定时任务可调用 `summarize_task_history`，复用 `/summary` 的独立模型、提示词、用量记录和服务端分块归并。工具只返回摘要，由调用方投递，避免重复发送。
- Bot 的群聊总结页面增加不发送消息的预览，支持时间范围、话题、数量上限和自定义要求，展示实际查询范围、条数与截断状态。预览会产生模型用量和总结记录，不修改任务计划或手动总结冷却。

## 修复与边界

- 修复任务历史始终报告不完整的问题。查询多取一条判断数量截断；读完当前获准范围内可用数据库记录时返回完整，采集与保留覆盖未知单独标注。
- 总结读取统一执行 Bot、聊天、话题和当前用户隐私过滤。无法确定话题归属的旧记录不跨话题读取；助手回复只在来源及隐私可核实时纳入配置允许的范围。
- 长消息不再静默裁掉尾部；超过输入预算时分块处理，分层归并保留输入预算，取消信号贯穿模型调用。
- 定时任务总结固定在已批准的时间与数量范围，继承总结配置的较小上限。显式工具白名单不会自动扩展；默认任务工具集包含总结工具。

## 升级注意事项

本版本无新增数据库迁移。已有 `/summary` 命令保留投递行为；模型、权限和总结功能启用状态沿用现有配置。回退应用版本不需要删除数据。

数据库读取、分块归并、权限和单次投递由回归测试验证；桌面与手机预览使用合成数据进行浏览器验证。生产验收使用不发送的总结预览，不重复向群投递日报。当前可用数据库记录读完不代表已收集 Telegram 的全部历史。
