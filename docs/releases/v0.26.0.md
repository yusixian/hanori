# v0.26.0 — 范围受限的总结工具与预览

## 新增

- **总结工具**：聊天 Agent 可调用 `summarize_chat`，定时任务可调用 `summarize_task_history`，复用 `/summary` 的独立模型、提示词、用量统计与服务端分块归并。工具仅返回摘要正文，由调用方投递，避免重复发送。
- **总结预览**：Bot 群聊总结页新增不发消息的预览功能，支持按时间范围、话题、数量上限与自定义要求试跑，展示实际查询范围、条数与截断状态（会计入模型用量和总结记录，不影响计划或手动冷却）。

## 修复与边界

- 修复任务历史始终报“不完整”的问题：多取一条判断数量截断，读完获准范围内的可用数据库记录即视为完整，采集与保留覆盖未知单独标注。
- 统一按 Bot、聊天、话题和当前用户执行隐私过滤：无话题标记的旧记录不跨话题读取，助手回复仅在来源与隐私可核实时纳入。
- 超长消息改为分块处理与分层归并，不再静默截断尾部，取消信号贯穿模型调用。
- 定时任务总结锁定已批准的时间与数量上限（取与总结配置的较小值）；显式工具白名单不自动放宽，默认任务工具集包含总结工具。

## 升级注意事项

无新增数据库迁移，沿用现有 `/summary` 投递行为与配置，回退无需清理数据。

读取、分块归并、权限与预览已通过回归及合成数据浏览器测试；数据库记录读完不代表已采集 Telegram 全量历史。
