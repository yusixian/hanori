# v0.9.0 — 用量概览与统计范围

用量页按「查看总量、定位来源、深入诊断」组织内容，更快看到近期趋势，并明确时间和 Bot 筛选对各区域的影响。

## 更新内容

- 核心指标和用量趋势前置，随后查看模型与 Bot 明细；缓存指标和趋势集中在缓存诊断区域，年度活跃度保留在页面后方。
- 明确汇总、趋势、模型明细与缓存诊断使用所选时间和 Bot；全部 Bot 对比只跟随时间，年度活跃度固定最近 365 天并跟随 Bot。
- 修复 Bot 筛选只读取前 100 项的问题，按服务端分页读取完整选项；分页失败可重试，避免显示不完整列表。
- 修复年度热力图在周日到周五遗漏当前周（含今天）的问题，今天的活跃记录可以正常显示。
- 保留已有加载、错误重试与过期响应保护，以及缓存未知值和零值的区别。

使用方式见文档站「管理面板导航」中的「查看用量与统计范围」。

## 升级说明

- 从 v0.8.0 升级无需数据库迁移或新增配置。
- 统计口径、权限和用量 API 保持不变，历史记录不会回填。
- GitHub Release 与文档构建不代表生产实例已部署。

## 验证范围

验证用量页的筛选范围、超过 100 个 Bot 的选项加载、失败重试与请求切换、热力图本周和跨年日期边界，以及桌面和手机布局。浏览器使用模拟 API 数据；没有访问生产用量、调用真实模型或发送 Telegram 消息。同步检查文档构建、匿名访问、搜索和版本页。
