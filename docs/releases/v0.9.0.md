# v0.9.0 — 用量概览与统计范围

重组用量页信息层级，明确时间与 Bot 筛选对各模块的生效范围，修复 Bot 下拉截断与热力图漏掉本周的问题。

## 更新内容

- **信息层级调整**：核心指标与用量趋势前置，接着是模型与 Bot 明细；缓存指标集中到缓存诊断区，年度活跃度移至页面后方。
- **明确筛选范围**：汇总、趋势、模型明细与缓存诊断同时受时间与 Bot 筛选控制；全部 Bot 对比仅随时间变化；年度活跃度固定为近 365 天并随 Bot 变化。
- **完整 Bot 筛选列表**：修复只拉取前 100 项的问题，改为按服务端分页加载全量选项，分页失败可重试。
- **修复热力图本周缺失**：修复周日至周五期间遗漏当前周（含今天）活跃记录的问题。
- **保留已有保护**：维持加载／失败重试、过期响应拦截，以及缓存「未知」与「0」的区分。

详见文档站「管理面板导航 — 查看用量与统计范围」。

## 升级说明

- 无需数据库迁移或新增配置；统计口径、权限与 API 不变，历史记录不回填。
- 文档站需随应用重新构建部署。

## 验证范围

已验证筛选范围、超 100 个 Bot 分页加载、失败重试、请求切换、热力图本周与跨年边界、桌面／移动端布局及公开文档。浏览器使用模拟 API，未接入生产用量或真实 Telegram。
