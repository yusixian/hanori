# v0.28.0 — 语录贴纸与配色

## 新增

- 回复消息发送 `/q`，无需调用模型即可生成语录贴纸。支持 Telegram 局部选段、`/q N` 与 `/q -N` 的 1–10 条本地连引、`r` 一层父预览、同作者合并、图片及静态贴纸。
- `/qcolor ai|purple|dark|light|blue|#RRGGBB` 保存当前聊天的默认配色，`reset` 恢复默认；群内修改默认值需要管理员权限。`/q purple` 等单次配色不修改聊天设置。
- AI 可通过 `create_quote_sticker` 引用本轮可见的真实消息，选段必须是原文子串，每回合最多发送一次。不可借父预览或历史查询扩大本轮可见范围。
- 离线 Pango/Cairo 渲染支持中文、日文、彩色 Emoji 和 UTF-16 格式。优先输出最长边 512px 的 WebP；缩小后字号过小则发送可读 PNG 文件。

## 隐私与使用边界

语录来源按 Bot、聊天和话题隔离。隐私关闭用户不保留语录元数据，关闭或遗忘后会清除已有语录元数据并持久记录失效边界；既有公共聊天正文策略不变。保护内容拒绝生成，剧透在进入渲染器前隐藏，隐藏转发只显示署名。生成的语录使用持久回执防止再次套娃。

单条回复可以直接读取当前 Telegram 更新。连引只读取本地可用记录，不抓取 Telegram 全历史；不足所需条数时会说明实际数量。旧记录没有语录元数据时不能用于连引。发送结果未知时不会自动重发。

## 升级注意事项

无需数据库迁移。配色、失效边界和发送回执复用现有 settings 存储。

必须同步更新 Compose 并重建应用与默认启用的 `quote-worker`，不能只更新 app 镜像。渲染容器包含所需字体，使用非 root、只读文件系统、无网络、512 MiB 内存上限与受限临时空间；只与 app 共享 Unix socket，不接收模型或数据库凭据。无需新增 Secret。

上线后核对 `/api/health/ready` 的完整 Git SHA 与 `quoteRenderer: true`。未配置渲染器的源码部署不会提供 AI 语录工具；服务暂时离线时命令返回明确错误。Dokploy 应保留仓库网络设置，不向离线 worker 追加网络。

## 验证范围

已进行真实 Alpine 中文/Emoji 渲染、长文 PNG、图片和父预览目检，验证超时取消后的子进程与临时文件回收；行为测试覆盖权限、隐私、话题、选段、防伪造、单次发送和失败路径。隔离 PostgreSQL 回归验证持久化、隐私切换和服务重建后的失效边界。命令帮助已在桌面与手机尺寸的浏览器检查。

此前授权的专用测试群已通过 Telegram API 接收虚构 WebP 与 PNG 样图。该证据不等于真实 Telegram 客户端显示或生产群内完整命令/模型联调；未向生产群发送示例，也未修改人格或日报计划。发布、生产版本和渲染服务健康分别核验。
