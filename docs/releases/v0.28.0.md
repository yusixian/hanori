# v0.28.0 — 语录贴纸与配色

## 新增

- **`/q` 语录贴纸**：回复消息发送 `/q` 即可免模型生成语录贴纸。支持 Telegram 局部选段、`/q N` / `/q -N`（1–10 条本地连引）、`r` 一层父预览、同作者合并、图片及静态贴纸。
- **配色管理**：`/qcolor ai|purple|dark|light|blue|#RRGGBB` 设置当前聊天默认配色（`reset` 恢复默认，群内修改需管理员权限）；`/q purple` 等单次配色不改动默认值。
- **AI 语录工具**：AI 可调用 `create_quote_sticker` 引用本轮可见的真实消息（选段必须为原文子串，每回合最多发送一次），无法借父预览或历史查询越权扩大范围。
- **离线渲染**：基于 Pango/Cairo 渲染，支持中文、日文、彩色 Emoji 与 UTF-16 格式；优先输出最长边 512px 的 WebP，缩小后字号过小则改为发送可读 PNG 文件。

## 隐私与使用边界

- 语录来源严格按 Bot、聊天与话题隔离。关闭隐私的用户不保存语录元数据，关闭或遗忘后立即清除并持久化失效边界；受保护内容拒绝生成，剧透内容在渲染前遮罩，隐藏转发只显示署名，生成的语录带持久回执防止套娃。
- 单条回复直接读取当前更新；连引仅使用本地已有且含语录元数据的记录，不足条数时如实说明。发送结果未知时不自动重发。

## 升级注意事项

- 无新增数据库迁移（配色、失效边界与发送回执复用既有 settings 存储）。
- **需同步更新 Compose 并重建 app 与默认启用的 `quote-worker`**（不可只更新 app 镜像）。渲染容器内置字体，以非 root、只读文件系统、无网络、512 MiB 内存上限运行，仅通过 Unix socket 与 app 通信，无需新增 Secret。Dokploy 部署请保留仓库网络配置，勿向离线 worker 追加网络。
- 上线后请核对 `/api/health/ready` 的完整 Git SHA 及 `quoteRenderer: true`。未配置渲染器的源码部署不启用 AI 语录工具；服务离线时命令返回明确报错。

## 验证边界

已完成 Alpine 环境中文/Emoji、长文 PNG、图片、父预览目检及超时进程/临时文件回收验证，并通过权限、隐私、话题隔离、持久化及浏览器帮助页测试；专用测试群已通过 Telegram API 接收虚构 WebP/PNG 样图。真实客户端显示与线上完整联调需部署后核验。
