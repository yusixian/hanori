# v0.3.0 — 接话决策与评估

拆解群聊接话判断逻辑并新增批量评估工作台，上线角色与提示词资产库、公开文档站，修复用量统计与筛选问题。

## 更新内容

- **接话判断拆分**：将「是否回复」与「参与方式」分开判定，并把参与上下文带入回复生成。（#74、#75）
- **批量评估工作台**：支持对 JEV 决策样本进行筛选、批量标注与复核。（#79）
- **公开文档站**：上线公开使用文档与版本更新页面。（#77）
- **Telegram Reader 指南**：补充独立 Reader 的配置与验证说明。（#78）
- **角色与提示词资产库**：支持 Danbooru 角色沉淀、原创角色、人物代表形象绑定及提示词资产管理，生图时可按配置注入；数据按 Bot 隔离，自动注入与 NSFW 默认关闭。（#83）
- **用量页可靠性**：防止慢请求结果覆盖新筛选，图表与热力图加载失败时展示错误并支持重试。（#81）
- **整轮 token 与缓存统计**：普通回复与续聊改为按整轮累计 token，与逐步缓存统计对齐；支持 DeepSeek 缓存读取字段，明确区分「0」与「未知」。（#82）

## 升级说明

- 从 v0.2.0 升级包含 `0048`–`0050` 三个迁移（角色与绑定、提示词资产与配置、使用账本），升级前请备份数据库并按序执行。
- 资产库自动注入建议先保持关闭，确认数据无误后再对测试 Bot 开启；关闭自动注入会回退到纯提示词流程，不删除已有数据。
- 历史 token 记录不回填，旧多步记录可能偏低；新统计不代表真实缓存命中率或省费幅度已实测验证。
- JEV 仍建议先用 `shadow` 观察评估，再切 `active`。
- 文档站需随本版本重新构建部署，仅发 GitHub Release 不会更新线上文档。

## 验证范围

功能提交已通过仓库 CI，文档站完成类型检查、构建及桌面／手机浏览器验证。真实群聊表现、生图供应商链路、生产迁移及实际缓存命中率需另行验证。
