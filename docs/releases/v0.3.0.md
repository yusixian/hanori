# v0.3.0 — 接话决策与评估

本版本改进群聊接话的判断、上下文和人工评估，新增角色与提示词资产库，修复用量统计与筛选，并提供公开使用文档。

## 更新内容

- **更清晰的接话判断**：将是否回复与参与方式分开判断，并按参与上下文指导回复。#74、#75
- **批量评估工作台**：支持筛选、批量标注和复核 JEV 接话决策样本。#79
- **公开文档站**：新增公开使用文档和版本更新页面。#77
- **Telegram Reader 指南**：新增配置与验证说明，帮助完成独立 Reader 的接入准备。#78
- **角色与提示词资产库**：支持 Danbooru 角色沉淀、原创角色、人物代表形象绑定，以及提示词资产管理和生成时按配置注入。记录按 Bot 隔离，自动注入与 NSFW 默认关闭。#83
- **用量页可靠性**：防止迟到请求覆盖新筛选结果，加载失败时显示错误并支持重试，覆盖统计图表和热力图。#81
- **整轮 token 与缓存统计**：普通回复和续聊按整轮累计 token，与逐步缓存统计保持一致；支持 DeepSeek 缓存读取字段，并保留明确零与未知的区别。#82

## 升级说明

- 从 v0.2.0 升级包含新增迁移 0048–0050，分别创建角色与绑定、提示词资产与配置、成功使用账本。升级前备份数据库，按现有部署流程顺序应用迁移。
- 资产库自动注入建议先保持关闭，验证角色与资产管理后再为测试 Bot 启用；关闭自动注入可恢复原有纯提示词流程，不删除库中数据。
- 历史 token 用量不回填；旧多步记录可能低估总用量。新统计不代表真实缓存命中率或费用收益已经验证。
- JEV 建议先以 shadow 模式观察和评估，再启用 active。
- 发布 GitHub Release 不会自动更新文档站；文档需随本版本构建并部署后才会在线更新。
