# v0.14.0 — 更紧凑的侧栏账户入口

管理面板侧栏底部改为一个账户入口。点击头像区域，可打开设置、切换语言、查看文档和更新说明，或退出登录。手机上常驻底部区域更短，页面导航有更多可滚动空间。

## 改进

- 将原来常驻底部的语言选择器和四个入口收进账户菜单。
- 保留桌面折叠侧栏和手机抽屉的键盘操作、导航搜索与当前页面标记。
- 退出登录继续经过未保存草稿确认；失败时保留当前编辑内容。

## 使用与升级

- 无配置或数据库迁移。更新面板后，在侧栏底部点击账户入口即可找到设置、语言、文档、更新说明和退出登录。
- 回滚到上一版本的应用构建即可；服务端认证和权限接口没有改变。

## 验证边界

桌面和手机浏览器检查使用合成账户与本地界面。没有对生产账户执行退出登录，也没有执行生产部署。文档构建与 GitHub Release 不会自动更新运行中的实例。
