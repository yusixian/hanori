# v0.14.0 — 更紧凑的侧栏账户入口

侧栏底部收拢为单个账户入口，点开头像区域即可进入设置、切换语言、看文档与更新说明或退出登录，腾出更多移动端导航空间。

## 改进

- 将原先常驻底部的语言选择器与四个快捷入口收纳进账户菜单。
- 保留桌面折叠侧栏与手机抽屉的键盘操作、导航搜索与当前页标识。
- 退出登录继续走未保存草稿确认流程，退出失败时保留当前编辑内容。

## 使用与升级

- 无需配置或数据库迁移，更新面板后点击侧栏底部账户入口即可。
- 回滚切回上一版应用构建即可，认证与权限接口不变。

## 验证边界

桌面与移动端浏览器测试使用合成账户与本地界面，未执行生产账户退出或线上部署。
