## 静态候选，尚待复现

Sol先使用CodeGraph定位，再阅读当前源码；以下不等同于已验证缺陷：

- `packages/panel/src/pages/bots/conversations/index.tsx` 的 `loadMessages`、`loadSummaries` 与列表类似，失败主要写控制台；切会话会清空详情，可能显示“没有消息/没有压缩摘要”。需覆盖HTTP/业务/网络错误、换chat/page过期响应和恢复。
- 单条消息/摘要删除对网络/JSON异常或ok:false缺少可见反馈；二次确认在请求发出前清除。需复现无法确认的删除、保留记录、刷新核对、重试与慢请求。整会话/全部删除已有错误对话框，不先扩大其重构范围。
- 列表仅有page/limit，找旧会话需逐页翻；`messages-pane.tsx` 的system/tool可见性过滤仅作用已取回的当前50条。先明确实际旅程和筛选含义，列表搜索与服务端角色过滤可另作效率迭代，不与读取/删除故障恢复混作同一问题。
