# JEV 接话调参与决策诊断交付

## 范围与授权

用户要求基于决策记录分析全面优化 JEV 配置与诊断，经 review 修复后提 PR、发版并同步文档站更新说明。允许本轮实现、验证、提交/push、PR 合入、tag/Release；不包含生产部署、线上策略写入或真实模型/Telegram 调用。

基线：`94a11dfe45fa793403753637c846e9e3631c7498`。分支：`feat/jev-tuning-diagnostics`。拟发布 v0.12.0，前一版本 v0.11.1。

## 验收契约

- 回复判断、参与方式与实际准入分别解释；两个参与门槛及续聊窗口可在 Bot/群配置管理。
- 新字段缺失时保持原行为，旧客户端保存不抹掉已配置的新值；0 窗口明确关闭延续冷却豁免。
- 接话偏好示例只在显式应用时修改草稿，保留原有默认策略与生产配置。
- 记录原始参与建议与 provider 置信度；历史缺失不推算。人工评估按当前两阶段/历史三分类分开，支持精确配置版本筛选。
- 维持权限、隐私、故障回退、群/话题隔离及治理契约。
- 聚焦单元/浏览器检查、真实浏览器桌面与 390px 验收、隔离数据库迁移与查询、文档匿名访问/深链/搜索/新旧版本页；全量交 CI。
